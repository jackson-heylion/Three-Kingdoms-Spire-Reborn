# 第082回《孙权降魏受九锡 先主征吴赏六军》固定单底本全文核读

固定小说底本：[维基文库第082回 oldid=2568044](https://zh.wikisource.org/w/index.php?title=三國演義/第082回&oldid=2568044)，正文 L119–142；2026-10-27 从章武元年八月白帝城接使至黄忠出阵悬念逐段核读。**单底本通读，不等于史料全回或第二底本校勘。**

| 固定行位 | 因果、责任、时序与知情边界 |
| --- | --- |
| L119–120 | 承081诸葛瑾奉使，刘备先拒见，黄权劝召；诸葛瑾提出送孙夫人、交还荆州、共同讨魏等**吴方和谈主张**，并将关羽之死推给吕蒙。刘备拒绝，不能写成吴已实际归还荆州或孙夫人已回蜀。 |
| L121 | 张昭疑诸葛瑾借使投蜀，孙权相信其忠；诸葛瑾返回证明未叛。赵咨请赴魏求缓解蜀军压力，东吴由谈和失败转向权宜称臣。 |
| L122–123 | 赵咨面曹丕答吴国实力；曹丕明知称臣为退蜀兵，仍封孙权吴王、加九锡。刘晔主张趁吴蜀相攻出兵，曹丕拒绝，选择坐观。**魏吴册封不等于吴国永久臣属或魏援军已到**。 |
| L124–125 | 孙权受封，徐盛痛哭反对；前线蜀军至秭归，吴任孙桓、朱然水陆拒蜀。吴王受魏爵而魏不援，形成孤军防守的战略负担。 |
| L126–128 | 关兴张苞与孙桓部将交锋，谭雄冷箭射张苞坐骑、关兴救人，随后擒谭雄；孙桓失将退守，吴班先察朱然水寨未损，蜀军设假降诱救与山谷伏击。不可把孙桓已死或朱然已降写入游戏。 |
| L129–133 | 崔禹代朱然出援被擒，朱然水军后退，孙桓退彝陵城被围；孙权再命韩当周泰潘璋凌统甘宁抵御，甘宁带病出征。刘备轻言老将无用，黄忠因而出战；**黄忠的结局留083**。 |
| L134–142（回末） | 两位后辈被派去支援黄忠，黄忠已离营，悬念接083。不可提前将黄忠之死计为本回既成事件。 |

跨回：081拒伐吴谏与诸葛瑾出使→082议和被拒、孙权权宜受魏封、夷陵前线两路攻防→083黄忠中伏、吴改任陆逊。游戏孙氏视角仅作吴国军报复核，魏廷可作曹操死后的**后继朝廷档案**，不能让曹操本人参与。

未校：第二小说底本、九锡礼制细节、赵咨问答逐字史证、孙桓及朱然战役细节、出师兵数。局部对照见史料文件。
