# 第018回：安众两追、十胜十败与小沛密书

- 审读日期：2026-10-26。
- 固定底本：维基文库《三國演義》第018回，`oldid=2567980`，https://zh.wikisource.org/w/index.php?title=三國演義/第018回&oldid=2567980 。
- 核读范围：从贾诩识破曹操宛城攻法，到吕布与高顺、张辽分兵夹攻刘备、关羽、张飞三寨的回末。只完成**单底本全回叙事与因果通读**，不声称逐字异本校勘、正史核证或原文重印。下述均为小说叙事，不能自动当作历史事实。

## 按正文先后核对

1. **宛城反伏击（开篇）**：第017回末贾诩已识破曹操西北佯攻、东南潜入之计；本回他将精兵藏在东南屋内、让百姓假扮守军在西北虚张声势。曹军夜入东南反中伏击。不能倒写成曹操成功攻破张绣后才遇伏。
2. **刘表与张绣截归路**：贾诩劝张绣联络刘表；蒯良因孙策在湖口的牵制仍主张趁曹操新败截击。曹操经过淯水先祭典韦、曹昂等阵亡者，再收到荀彧告警刘表、张绣已扼安众退路。祭奠与安众伏兵并非同一事件。
3. **安众脱困**：曹军在险道夜间开路并伏奇兵，刘表、张绣误以为曹军退走而追击，反被击败。曹操解释“退无归路必死战”，是对当时险道形势的判断，不能概括为曹军从此战无不胜。
4. **两次追击判断相反**：袁绍欲攻许都的情报促使曹操急回。贾诩第一次劝张绣不要追，刘表坚持追，遭曹军强将殿后击败；贾诩随即劝第二次追击，张绣单独再追却获胜，因为曹操急于回许都，胜后轻装疾行，不再严密设防。**第一次“不追”和第二次“追”的判断均有具体敌情条件，不是前后自相矛盾。**
5. **李通接应与郭嘉十胜十败**：张绣追击后李通自汝南来援，曹操返许都；郭嘉提出曹袁“十胜十败”说，又建议趁袁绍北征公孙瓒，先除徐州吕布以免腹背受敌。十胜十败属于郭嘉在小说中的论证与劝策，不是现代可验证的十项战力测量。
6. **密书与吕布决裂**：曹操先写信约刘备夹击吕布；刘备因兵少回信表示须待曹军先动。陈宫在小沛附近截到回信并交吕布，吕布读后杀使、分兵袭刘备。密使被杀发生在吕布获悉联曹计划**之后**，并非第017回七路军反戈期间。
7. **小沛守城与张辽**：刘备命孙乾、关羽、张飞等分守城门；高顺攻城、张辽攻西门，关羽劝张辽而未出战；张辽转东门后张飞欲追，关羽制止。此处张辽撤走不是被张飞打败。
8. **夏侯惇中箭啖睛与回末**：简雍赴许都告急，曹操遣夏侯惇等先援。夏侯惇与高顺交战追击，曹性暗箭射中其左目；小说写夏侯惇拔矢啖睛、刺死曹性，但高顺随后率兵击败曹军。吕布与张辽、高顺夹攻刘备、关羽、张飞三寨，回末尚未交代最终胜负，须留待第019回。
