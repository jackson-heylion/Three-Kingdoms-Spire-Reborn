# 第046回《用奇谋孔明借箭 献密计黄盖受刑》单底本全文核读

| 位置 | 因果与人物知情、责任 |
|---|---|
| L119–124 | 承045蔡张被误杀，孔明识周瑜反间；鲁肃将其判断告周瑜，周瑜更忌孔明，以十日造十万箭为由设杀局，孔明立三日军令状。周瑜暗令工匠拖延，不能写成公正的造箭比赛。 |
| L125–127 | 孔明向鲁肃私借二十草船、每船三十军士，嘱不可告周瑜；鲁肃对周瑜只说不用常规材料。第三日四更雾起，鲁肃随船赴北岸，船只及人力来自江东，不是凭空变箭。 |
| L128–158 | 《大雾垂江赋》是文学铺陈，不能当气象观测或史实。 |
| L159–174 | 曹操因雾疑伏，命弓弩手隔江放箭并调陆寨援射；孔明转船两面受箭，取得十余万枝。周瑜收箭后服其计；周瑜孔明各写一“火”字，火攻尚未发动。须分清“借箭成功”与“赤壁火攻成功”的时间。 |
| L175–179 | 荀攸荐蔡中蔡和诈降；周瑜看出二蔡未携家眷，暗令甘宁防范并将计就计。鲁肃一度不知周瑜已识破，孔明后来说明。双方情报并非全知。 |
| L180–193 | 黄盖自荐火攻苦肉计，周瑜与黄盖事先商定。帐前黄盖故意言降，甘宁劝阻受责，黄盖实受五十杖、另五十暂记；鲁肃后来才悟，阚泽察觉并受托送诈降书。回末阚泽尚未渡江见曹操，须留047。 |
