# 第097回《讨魏国武侯再上表 破曹兵姜维诈献书》固定单底本全文核读

固定底本：[维基文库第097回 oldid=2568059](https://zh.wikisource.org/w/index.php?title=三國演義/第097回&oldid=2568059)，正文 L119–175；2026-10-27从回首至回末逐段核读。**单底本全文通读；第二小说底本与史料全回对校未完成。**

| 正文位置 | 叙事因果、人物责任、时序与边界 |
| --- | --- |
| L119–120（回首） | 承096石亭战败，曹休归洛阳病亡；吴使告捷并请求蜀出兵，诸葛亮闻报议军，赵统、赵广到军中报赵云病亡，蜀廷追祭。小说将赵云死讯置于建兴六年，史传记建兴七年卒，不能混用。 |
| L125–151 | 杨仪奉后出师表，诸葛亮列六个不能坐待的理由，强调胜败不可预知与兵疲粮费；不是宣称北伐必胜。该表的传世层次为《三国志》裴注引张俨《默记》，并明说诸葛亮集所无，真伪有争议。 |
| L153–155 | 刘禅准再伐，诸葛亮以魏延先锋走陈仓；曹叡命曹真统军，王双为前锋。战机来自石亭之后魏方分心，但魏守备并未撤空。 |
| L156–158 | 蜀军发现郝昭已筑陈仓城；鄞祥两度劝降失败，郝昭明言各事其主。劝降失败后才转攻城，不可把郝昭说成因私人怨恨拒降。 |
| L159–160 | 云梯遭火箭焚毁、冲车被石击破、地道被横壕截断，围城二十余日不克；王双来援，谢雄龚起阵亡，张嶷受伤，姜维劝改道祁山，诸葛亮布王平李恢守街亭小路、魏延守陈仓口。军需损失与转向是实际后果。 |
| L161–167 | 曹真收到伪称姜维投魏的密书；费耀虽疑诈仍代曹真出战，魏军遭蜀军多路诱退与火攻，费耀自刎，姜维表明真正目标是曹真。假降书属于小说计谋，不可与093姜维真正归蜀颠倒。 |
| L168–175（回末） | 曹真损将后奏急，曹叡再问司马懿，司马懿声称有不用交战即可迫蜀军撤退之计，悬念转098魏方坚守与粮道。 |

跨回：096石亭告捷使蜀有外交窗口→097赵云死讯、后出师表、陈仓守城与费耀败亡→098魏方固守、蜀军粮尽退却、王双被杀；石亭与北伐是相互牵制，不是单一胜负自动决定另一战场。
