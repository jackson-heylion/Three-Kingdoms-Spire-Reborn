# 第105回《武侯预伏锦囊计 魏主拆取承露盘》单底本全文通读

固定来源：[维基文库第105回 oldid=2602415](https://zh.wikisource.org/w/index.php?title=三國演義/第105回&oldid=2602415)，正文 L119–178。2026-10-28逐段从回首核至回末。状态：**单底本全文通读**；第二小说底本异文与史料全回校勘未完成。

| 正文锚点 | 责任、时序与知情边界 |
| --- | --- |
| L119–129（回首） | 承104栈阁截路：魏延先烧绝栈道，杨仪与姜维改走槎山。成都先接李福死讯，后分别收到魏延、杨仪互控奏章；蒋琬、董允保杨仪，刘禅命董允劝解。**两方奏章是冲突证词，不能直接当事实裁断**。 |
| L131–139 | 何平劝散魏延军，魏延与马岱进南郑。小说魏延曾口议投魏，马岱劝其自图；杨仪拆锦囊，马岱阵前斩魏延。小说此时才写魏延死，不得提前放入104。陈寿《魏延传》明言魏延本意非北降魏、而欲除杨仪，且记马岱追斩，不是小说锦囊口号。 |
| L139–162 | 后主迎诸葛亮灵柩、定军山薄葬；宗预使吴核实巴丘增兵与白帝防务，孙权解释为防魏、重申联盟。蒋琬、费祎承政；杨仪因怨言被废后自尽。此处吴方使节与成都继任在魏延事件之后，不可倒置。 |
| L164–171 | 叙事转魏廷：曹叡大兴宫室，董寻、张茂、杨阜进谏；马钧奉命拆长安承露盘，小说写铜人泪与坠台死者。劳役伤亡应区分小说夸饰、史传宫室征役与原创账目。 |
| L172–178（回末） | 毛皇后因郭夫人宴游泄密而被赐死；幽州毌丘俭急报公孙渊称燕王，曹叡召臣商讨，**第106回才发兵辽东**。铜人泪、天象均非可确证史实。 |

跨回因果：104魏延截栈道→105双表争令、马岱杀魏延→定军山安葬与蜀吴复盟→曹魏宫室徭役与公孙渊急报→106辽东征伐。游戏只提供**后继军府/吴廷/魏廷档案**互斥记账，不复活诸葛亮或孙夫人。
