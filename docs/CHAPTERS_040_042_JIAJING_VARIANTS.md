## 局部异文与责任

1. **040 / 嘉靖079—080：谏曹、降荆与刘琦哀书。** 嘉靖079「孔融上言」段详记孔融借禁酒讥曹及郗虑罗织的言语；毛评040同段简述孔融与祢衡关系、郗虑告发。嘉靖079「王粲」段附家世、倒屣迎客及所谓裴松之批语；毛评040以较短传略引入劝降。嘉靖080「孤子劉琦謹獻哀言」至「建安十三年」完整呈书，毛评040在「伊籍曰」处转述哀书目的。两版都写蔡氏扶刘琮、宋忠送降书、刘备拒乘丧夺荆州、孔明撤民并火烧新野；不得把刘琦哀书当作历史实物，亦不得把嘉靖本附批当作已核实裴注。
2. **041 / 嘉靖081—082：追击交锋与预兆。** 嘉靖081开篇写张飞与许褚「不十余合」而许褚走脱；毛评041开篇仅写交锋、不记合数。嘉靖082「簡雍頗明陰陽」段写风尘遮日、简雍「袖傳一課」预言当夜大凶，毛评041对应长坂追击段不见此占课。两版保留徐庶奉曹命劝降又示警、刘备携民、襄阳魏延开门与文聘交战、赵云寻救糜夫人阿斗的责任线；占兆不能作为历史预警或随机战斗加成。
3. **042 / 嘉靖083—084：桥头落马者与史注署名。** 嘉靖083张飞三喝之后写「夏侯霸驚得肝膽碎裂」倒马；毛评042同段写「夏侯傑驚得肝膽碎裂」。这是人物异文，不能拼成两人都死，也不能从小说推断史传夏侯霸之死。嘉靖084关羽重提许田猎事后，另附「後來史官裴松之」评论刘备答语；毛评042只记刘备「投鼠忌器」而不附这段。署名的真实史注出处及电子录文待核，不能把小说插注当作《三国志》史证。

## 连续因果与可玩兑现

039博望剑印与迟谏 → 040刘备拒夺荆州、孔明撤民并火水拒敌 → 041徐庶警告、民众迁徙、赵云救主 → 042张飞断桥失算、关羽汉津护送、孔明与刘琦船援 → 043鲁肃邀孔明赴柴桑。人物在场与时序不得倒置：诸葛亮未亲历长坂乱军，关羽未在桥头三喝。

## 2026-11-02：毛评固定单底本第040—042回独立全文复核

本轮逐段阅读三回现行维基文库正文，从开篇至回末；每页页脚的固定链接分别指向 **oldid=2568003、2568004、2568005**，与本台账固定修订一致。页内行号为2026-11-02读取时的可复查定位，并非嘉靖原刻页码。此处是独立单底本全文核读；前述嘉靖079—084仍仅局部异文抽检，**不升级为全回异本校勘或史传核证**。

### 040 毛评 oldid=2568003，正文 L116—185

- **L116—131**：刘备先拒趁刘表病危取荆州；夏侯惇向曹操认博望败因，曹操分五队南征；孔融谏阻，郗虑告发，曹操杀孔融及二子。孔融被杀属于小说这一段的叙述，不把小说措辞直接等同于《三国志》史证。
- **L132—151**：刘表先托刘备，继欲令其辅佐刘琦；蔡夫人、蔡瑁、张允阻刘琦见父，刘表死后假遗命立刘琮。李珪劝迎刘琦而遭蔡瑁杀害；傅巽、蒯越、王粲等劝降，刘琮同意。伪诏责任不应推给刘琦或刘备。
- **L152—160**：宋忠向曹操递降书，回程被关羽截问，刘备因而先知荆州降曹；伊籍随后携刘琦哀书报丧。张飞主张杀宋忠，刘备放其离去；伊籍与孔明主张趁丧取州，刘备拒绝。孔明先张榜撤民、调船护眷，随后分派鹊尾疑兵、三门火攻留东门、关羽上游放水、张飞博陵渡截击。不能倒置「撤民」与「火攻」。
- **L161—185**：许褚见疑兵迟进，曹仁催进空城，赵云等在城外截击，关羽决水，张飞于渡口拦曹仁。回末只问曹仁性命，第041回开篇才明确曹仁退走；不可在040写其阵亡。

### 041 毛评 oldid=2568004，正文 L116—208

- **L116—130**：曹仁退走、徐庶奉曹操之命招降但私下告警，仍返曹营；刘备再次询民意，携民渡河，蔡瑁张允拒开襄阳，魏延开门与文聘交战，刘备怕伤百姓改走江陵。关羽先奉命往江夏求援，不能写作他始终随行长坂。
- **L139—155**：曹操因北军不熟水战暂用蔡瑁、张允；刘琮归降后曹操改授青州刺史，**曹操命于禁追杀刘琮与蔡夫人，王威护主而死**。此为小说人物责任，不是已核实史实。曹操派五千铁骑追逐携民队伍，孔明后随刘封往江夏，未亲见长坂失散。简雍占课是小说卜兆，不可化为游戏真实预知加成。
- **L156—175**：糜芳误疑赵云投曹，刘备明确不信；张飞布马尾扬尘疑兵。赵云先救简雍，再救甘夫人与糜竺并送回，继而独自回阵寻糜夫人与阿斗，斩夏侯恩得青釭剑。糜夫人重伤拒上马，将阿斗交赵云，投井而死；不是赵云弃她不救。
- **L176—208**：赵云掩井、抱阿斗突围，曹操命捉活的而禁放冷箭；第041回末钟缙钟绅拦路，尚未被杀，第042回开篇才交战。曹操禁冷箭与青釭神异均属小说叙述。

### 042 毛评 oldid=2568005，正文 L115—171

- **L115—135**：赵云杀钟缙钟绅、交还阿斗，刘备掷子是小说情节。张飞马尾扬尘、桥头三喝令曹军退；毛评记夏侯杰倒马，嘉靖083作夏侯霸，绝非两人都死。张飞随即拆桥，刘备指出此举暴露虚实，曹操果命架三座浮桥再追；不能把断桥写成没有代价的永久封锁。
- **L137—150**：关羽在汉津截曹军、护刘备登船，刘琦先以船援到，孔明随后另率船至并说明自己在江夏调度。孔明不在长坂桥亲自指挥三喝。关羽与刘备重提许田旧事，属于小说人物对话。
- **L152—171**：曹操计点八十三万而诈称百万，是小说兵数叙述，不能当历史人口或军力统计。鲁肃以吊丧为名实探军情，诸葛亮与刘备预设应对，最终鲁肃携孔明往柴桑，承接第043回舌战群儒。第042回末赤壁尚未开战。
