# 第047回《阚泽密献诈降书 庞统巧授连环计》单底本全文核读

2026-10-27 连续阅读维基文库固定修订 oldid=2568010：https://zh.wikisource.org/w/index.php?title=三國演義/第047回&oldid=2568010 。L 为该固定页面正文行号。**只计单底本通读；未做全回异本或史料校勘。**

| 位置 | 情节、人物责任及因果 |
|---|---|
| L119–126 | 承046黄盖受刑并托阚泽献书，阚泽当夜扮渔翁入曹营，交黄盖诈降书。书自称周瑜无端施刑、愿献粮船；这是吴方诈书，不是真实投降。 |
| L127–134 | 曹操识破“无定期”疑点欲杀阚泽；阚泽以临机不能预定时间辩解，曹操转而相信，另收到二蔡报告。阚泽拒金帛返回江东，与黄盖复盘，后访甘宁。曹操并非从始至终毫无怀疑。 |
| L135–140 | 甘宁阚泽佯作受辱欲降，诱蔡中蔡和自承曹营内应；二蔡报甘宁欲降，阚泽另书报黄盖船头青牙旗。曹操收到两封消息仍疑虑，蒋干请再渡江探虚实。 |
| L142–149 | 周瑜此前从鲁肃得知庞统火攻需先锁船，利用蒋干再来设计西山庵“偶遇”；庞统佯称不得志，由蒋干引入曹营，先赞曹军水寨。蒋干第二次来吴与第一次偷伪书不是同一事件。 |
| L150–161 | 庞统借北军晕船病情献连环船计，曹操下令打造铁环连船；庞统又求安民榜文，曹操签押。船病和连锁便利是说服手段，连船的火险在小说后续才兑现，不能提前写赤壁已败。 |
| L162–168 | 庞统离曹营遇道袍竹冠者，当场被指出黄盖苦肉、阚泽诈书及连环计，回末不揭其身份；不可提前认作某人或让庞统被捕。 |

回际：046黄盖托阚泽 → 047阚泽说曹、二蔡中计、庞统连船 → 048继续身份悬念与火攻部署。未核：另一小说底本逐字差异、陈寿正文与裴注对庞统连环计的史实边界。
