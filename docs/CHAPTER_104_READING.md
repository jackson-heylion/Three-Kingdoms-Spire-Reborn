# 第104回《陨大星汉丞相归天 见木像魏都督丧胆》单底本全文通读

固定来源：[维基文库第104回 oldid=2568066](https://zh.wikisource.org/w/index.php?title=三國演義/第104回&oldid=2568066)，正文 L116–174，2026-10-28逐段核对回首至回末。状态：单底本全文通读；第二小说底本及史料全回未校。

| 固定正文位置 | 情节、人物责任与知情边界 |
| --- | --- |
| L116（回首） | 接103回末姜维因魏延扑灭主灯拔剑，诸葛亮亲止，认命不责魏延，仍派其出击魏军。魏延未在此时叛变或被杀。 |
| L117–126 | 诸葛亮病重，将兵法与连弩图授姜维，阴平告诫、马岱密计、杨仪锦囊；召李福问安，嘱杨仪按序缓退并上遗表。小说遗表借用了史传自陈桑田资产文字，不能把全部临终对话当陈寿正文。 |
| L127–142 | 诸葛亮命秘不发丧、设木像与返旗之计；李福再问继任，答蒋琬、费祎后不答；建兴十二年八月卒。廖立、李严闻讯哀恸。陈寿正文确载234年军中病卒、年五十四，李严廖立见卷40；禳星、木像等需单列小说/裴注。 |
| L151–157 | 杨仪姜维秘丧整军，费祎探魏延意见；魏延不愿受杨仪节制并要继续伐魏，杨仪改姜维断后，魏延率本部南行。此处不能直接断言魏延投魏：卷40陈寿正文明确其意在除杨仪，非北降魏，裴注《魏略》另有争议叙述。 |
| L158–166 | 司马懿确认蜀军退，率军追击；姜维推出诸葛亮木像、返旗擂鼓，司马懿误以为诸葛亮仍在而撤，后由民间传闻知其已死。陈寿卷35裴注引《汉晋春秋》载返旗退敌和谚语，但未确证小说木像的所有动作。 |
| L168–174（回末） | 杨仪姜维率军缓退入栈阁、方发丧，忽见前方军队截路，身份未揭，留待105。**不能提前在104回写魏延已被斩**。 |

跨回：103灯灭→104制止姜维杀魏延→临终继任与秘丧→杨仪魏延军令冲突→木像疑兵掩护撤军→105栈道阻兵与魏延结局。原创选择仅是后继蜀廷/军府追录，不让已故诸葛亮亲自作后续决定。

未校：第二小说底本逐字异文；李福问答原始史源；木像、禳星具体来源；魏延杨仪双方书疏及裴注异说全量对勘。局部史证见 CHAPTERS_102_104_HISTORY_SPOTCHECK.md。
