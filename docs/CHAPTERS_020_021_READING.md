# 第020—021回：许田射鹿、衣带密诏与徐州城门——固定单底本逐回因果审读

核读日期：2026-10-26。固定来源：
- 第020回：维基文库《三國演義》第020回，oldid=8187289，https://zh.wikisource.org/w/index.php?title=三國演義/第020回&oldid=8187289
- 第021回：维基文库《三國演義》第021回，oldid=2567982，https://zh.wikisource.org/w/index.php?title=三國演義/第021回&oldid=2567982

两回均按上述**单一固定修订**从开篇到回末连续核读；下列定位是该版正文的段落起止语，不是异本对校或《三国志》史实核证。所述人物言行仅代表小说设定；玩家可改写的行动一律标注“架空”。

## 第020回连续段落与责任

1. 「話說曹操舉劍欲殺張遼」—「留玄德在相府左近宅院歇定」：直接兑现第019回张辽骂曹的悬念。刘备攀臂、关羽跪请，曹操释张辽；张辽招臧霸，臧霸再招孙观等人，昌豨未降。曹操让车胄权领徐州，不是刘备已重任徐州牧。
2. 「次日，獻帝設朝」—「自此人皆稱為劉皇叔」：刘备入朝、皇帝按宗谱认叔并封官；这是小说中的谱系叙述，未据此证明真实血缘。
3. 「曹操回府，荀彧等」—「以觀動靜」：曹操忧杨彪与袁氏亲缘，命人诬告；孔融谏后杨彪免官，赵彦上疏却被曹操杀害。两人结局不同，不能混成同案同刑。
4. 「於是揀選良馬」—「且宜秘之，不可輕言」：许田猎鹿，献帝三箭不中，曹操借天子金鈚箭射中后越位受贺；关羽欲杀曹，刘备因天子在旁、曹军环卫而摇头制止，关羽没有当场出刀。玩家“收刀记账”只改写残卷记载，不改原著结果。
5. 「卻說獻帝回宮」—「勿負朕意」：献帝向伏皇后诉苦，伏完提议暗诏董承；血诏由献帝亲书，伏皇后缝入玉带衬里，不能写成伏完写诏或传国玉玺内藏诏。
6. 「承會意」—「乃天子手書血字密詔也」：董承携袍带出宫遭曹操盘问、脱衣验看，但未被发现；董承归家反复查找，直到灯花烧破衬里才发现血诏。曹操并未在本回读到诏文。
7. 「董承覽畢」—「亦書名畢」：王子服先戏言告发再表忠，随后种辑、吴硕、吴子兰加入义状；区分王子服的试探与真实告密。
8. 「忽報西涼太守馬騰相探」—「且聽下文分解」：马腾因许田事愤怒，读诏后盟誓，回末仅提议邀请一位刘氏宗亲，**未在本回直接点名刘备**。第021回才揭晓。

## 第021回连续段落与责任

1. 「卻說董承等問馬騰曰」—「吾之學圃」：马腾点名刘备，董承夜访、刘备先试探再读诏签名；刘备后园种菜是韬晦，不是退隐务农。第020回衣带诏的秘密在此兑现。
2. 「一日，關、張不在」—「借懼雷以掩飾之耳」：许褚张辽请刘备赴曹府，曹操青梅煮酒点出两英雄；刘备失箸，借雷声遮掩惊惧，关张持剑闯园为护兄。不是曹操当场识破衣带诏。
3. 「操次日又請玄德」—「不復追玄德」：满宠报公孙瓒败死、袁术欲投袁绍，刘备请兵截袁术借机脱许；郭嘉程昱回营劝追，许褚领命追召，刘备以将令在外拒返，曹操最终不再追。两次主张有时序。
4. 「卻說玄德正行」—「時建安四年六月也」：刘备遇纪灵、袁术军，张飞刺纪灵，袁术败走、饥渴而死。第020回的许田围猎不能写在袁术死后。
5. 「袁術已死」—「此時玉璽歸操」：徐璆夺袁术遗族携带的玉玺献曹操；这是**第021回玉玺去向**，与第020回衣带血诏不是同一器物。
6. 「卻說玄德知袁術已喪」—「可寫書與車冑就內圖之」：刘备遣朱灵路昭回许，留兵徐州并招民复业；曹操命车胄暗中图刘备，不能把车胄行动写成独立私仇。
7. 「操從其計」—「眾等無罪，投降免死」：车胄与陈登议伏杀，陈登告父后先向关张示警；关羽扮张辽兵夜诱车胄出城并杀之，城上陈登射住车胄退路。属于反制谋杀，不是无缘无故攻城。
8. 「雲長將冑頭去迎玄德」—「且看下文分解」：张飞杀车胄全家，刘备忧曹军追责；陈登说有退敌之策，回末尚未揭晓。不能将张飞杀家属归给关羽，也不能把陈登之计提前写成已执行。
