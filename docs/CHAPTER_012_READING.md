# 第012回正文核读：濮阳火门、徐州让印与兖州守本

- 底本：维基文库《三國演義》第012回「陶恭祖三讓徐州 曹孟德大戰呂布」，[固定版本 oldid=2567974](https://zh.wikisource.org/w/index.php?title=三國演義/第012回&oldid=2567974)。
- 核读范围：从夏侯惇接应曹操至吕布退兵后再次集结、回末悬念，覆盖该版本整回正文；依据正文事件次序逐段核对。**仅此版本通读，尚未做毛评异本逐字对校、陈寿《三国志》或裴注逐段史料比对。**

## 原著事件链与可核查位置

1. **濮阳设局与救主**（正文前段，页面第117–127行）：陈宫建议田氏用「义」字旗诱曹军入城；刘晔、李典均曾劝慎，曹操仍亲入。张辽、臧霸等封路，典韦往返寻曹，曹操以指认他人骗过吕布并冒火逃出。责任不能简化成吕布独自布下伏击，也不能写成曹操未受损失的胜利。
2. **诈死反伏与粮荒停战**（第127–129行）：曹操佯称烧伤身死，吕布来攻遭伏；随后蝗灾使关东粮价暴涨，两军均因粮尽而暂退。这里是双向失误、反制与补给约束，不是一次战斗决定全部胜负。
3. **徐州权柄的三次推让**（第131–135行）：陶谦病重再让徐州，刘备以陶谦二子为由推辞；陶谦死后将领与百姓再请，刘备才权领徐州，孙乾、糜竺、陈登辅佐。曹操闻讯欲复仇，荀彧指出放弃兖州根基、再攻已有民心的徐州将腹背受敌。
4. **就粮、许褚与兖州回取**（第136–145行）：曹操听荀彧之议向汝颍黄巾余部用兵，获粮；典韦与许褚多次交锋，曹操以诈败、陷坑擒许褚，许褚率宗族归附。不可将许褚写成濮阳火门当晚的救主者。
5. **濮阳与定陶收束**（第146–158行）：许褚、典韦等六将夹攻吕布；田氏改向曹军，吕布离濮阳；曹操用林中旗帜与堤中伏兵反制吕布火攻，吕布退走但尚未被擒，章末仍留后续。

## 游戏改编与因果边界

新增曹操可选剧情 `puyang`，必须先在第十回 `xuzhou` 选择承担民命责任、取得 `xuzhou_debt` 才可出现。玩家选择固守粮道才取得 `puyang_supply`；逐利或旁观均不获得。它不改变原著史实：游戏允许玩家作不同抉择，属于原创反事实分支。

当 `xuzhou_debt → puyang_supply → xu_capital → guandu_grain` 四个旗标齐备时，解锁隐藏结局「兖州守本粮策」，兑现跨幕的粮道抉择。旧版 `xudu` 与 `guandu` 的原有解锁条件不变，旧存档无需新旗标便可继续；不把新支线误设为主线硬门槛。
