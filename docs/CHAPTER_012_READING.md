# 《三国演义》第012回单底本因果审读：濮阳攻守与徐州权领

审读日期：2026-10-22。底本：维基文库《三國演義》第012回固定修订 oldid=2567974，回目「陶恭祖三让徐州　曹孟德大战吕布」。从夏侯惇解围至吕布再战悬念逐段通读。本记录不是毛评异本逐字校勘或《三国志》史实核证。

1. 第011回曹操追击悬念由夏侯惇解围收束；曹操重赏典韦，许褚此时尚未登场。
2. 濮阳火攻由陈宫借田氏递送假情报，以「义」字白旗诱曹操入城。刘晔提醒有诈，李典劝曹操勿亲自入城，曹操仍中计。
3. 典韦数次返城寻找曹操；曹操用「前面骑黄马者」误导吕布。曹操被坠梁烧伤后，典韦、夏侯渊救其出城。
4. 曹操诈死并在马陵山伏击吕布，吕布仍突围据守濮阳，不能提前写成已被擒。
5. 蝗灾和严重粮荒迫使曹操、吕布各自移军就食，双方暂时停战，不是主动议和。
6. 陶谦病危第三次让徐州，刘备仍拒；陶谦死后军民劝请，刘备才「权领徐州事」，任孙乾、糜竺、陈登辅佐。
7. 曹操欲复攻徐州，荀彧以兖州根基、后方风险及粮荒劝止，转攻陈地与汝颍黄巾获取军粮；原文并未写曹操因悔恨屠民而弃复仇。
8. 许褚与典韦反复较量，曹操用诈败陷坑擒许褚，亲自解缚厚待后许褚率宗族归附。
9. 吕布濮阳失利，田氏拒开城门；陈宫护吕布家眷出走。定陶战中吕布再不听陈宫，中了曹操长堤伏击。
10. 本回末曹操已收复兖州，吕布仍与部将会合准备再战；不能提前写成白门楼败亡。
