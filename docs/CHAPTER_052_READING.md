# 第052回《诸葛亮智辞鲁肃 赵子龙计取桂阳》单底本全文因果核读

2026-10-27。固定小说底本：[维基文库 oldid=2568016](https://zh.wikisource.org/w/index.php?title=三國演義/第052回&oldid=2568016)。**从回首至回末连续核读**；仅单底本，不是第二小说底本异文全校。

| 正文位置 | 情节因果、人物责任与时序 |
|---|---|
| L119–125 | 周瑜因051失南郡怒，鲁肃反对吴刘内斗、亲索荆州；孔明请病中的刘琦现身，以其在世暂守，鲁肃追问死后归还，孔明答另议。不是永久割让。吴军受合肥战局牵制。 |
| L126–128 | 伊籍荐马良，马良建议安刘琦、取零陵武陵桂阳长沙筹粮；刘备任马良伊籍，张飞先锋赵云殿后，关羽留守。 |
| L129–135 | 邢道荣被擒后诈愿捉刘贤，实回营反设夜伏；孔明料其计，赵云杀邢、张飞擒刘贤，刘贤获释劝刘度献印，刘度仍任郡守。 |
| L137–141 | 赵云与张飞争桂阳，赵云抽中军令带三千兵；陈应拒降被擒放归，赵范献印并与赵云结同乡兄弟。 |
| L142–148 | 赵范欲以寡嫂樊氏联姻，赵云因结义与初降风险拒绝；陈应鲍隆诈降，赵云识破杀二将、保普通兵卒，赵范获释留任。裴注《云别传》有部分相似叙述，非陈寿正文。 |
| L150–156 | 张飞请取武陵，孔明提出条件，回末未言明；053开篇才明言军令状。 |
