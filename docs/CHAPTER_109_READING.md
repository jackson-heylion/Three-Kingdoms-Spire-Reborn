# 第109回《困司马汉将奇谋 废曹芳魏家果报》单底本全文通读

固定来源：[维基文库第109回 oldid=2568073](https://zh.wikisource.org/w/index.php?title=三國演義/第109回&oldid=2568073)，正文 L119–161。2026-10-28回首至回末核读。状态：**单底本全文通读**，第二小说底本与史料全回校勘未完成。

| 正文锚点 | 情节因果、责任与知情边界 |
| --- | --- |
| L119–122（回首） | 承108诸葛恪求蜀协攻：姜维以夏侯霸议先结羌王迷当，徐质、司马昭应魏廷军令抵御，蜀先败三十里。诸葛恪是否仍在位与此段出兵时序需区别于小说的回叙结构。 |
| L124–125 | 姜维以木牛流马粮车为饵，徐质分兵追逐中伏战死，夏侯霸利用魏军衣甲与旗号诈入营寨，司马昭被逼上铁笼山。战果依赖伏兵、缴获和假旗，不是蜀军全线无损。 |
| L128–136 | 小说写司马昭祷泉涌水、郭淮陈泰诈降羌军、俄何烧戈死、迷当转为魏军前导；姜维遭突袭，空弓接箭反射郭淮，蜀军最终败归汉中。祷泉神迹和接箭射杀为小说叙事，不能冒称陈寿正文。 |
| L137–143 | 魏廷司马师独揽政事，曹芳与李丰、夏侯玄、张缉谋反制；小说写龙凤汗衫血诏被搜出，三人遭诛、张皇后被绞。被搜到的小说诏书不等于史传原始诏令；供词、处决及株连须分别记录。 |
| L143–149 | 司马师以曹芳罪状推动废立，太后议定曹髦；曹芳被黜，曹髦入宫继位。不能提前写成曹魏国号终结，110回才接毌丘俭文钦以废主为名起兵。 |
| L151–161（回末） | 毌丘俭、文钦起兵消息传至司马师，留下下一回淮南军变悬念；本回没有文鸯单骑退兵，也没有司马师去世。 |

跨回：108诸葛恪请蜀→109铁笼山军粮与水源战→姜维败归→曹芳废立→110淮南举兵。游戏的魏廷、蜀军后继档案不让曹操、诸葛亮复生，不改变司马昭脱困或曹芳被废。

未校：嘉靖本等真实第二小说底本；铁笼山神迹、郭淮死因与时间的完整史证；曹芳血诏、皇后处置及曹髦迎立的逐条史料核对。
