# 第039—041回史料与第二小说文本局部对照（非全回校勘）

日期2026-10-27。小说固定修订：维基文库039 oldid=2567999、040 oldid=2568003、041 oldid=2568004。以下只核具体段落，不能把局部异文或局部史实当全回校勘。

1. 第039回 L143–168 将博望剑印、伏兵和火攻归诸葛亮统筹；《三国志·先主传》卷32 固定oldid=2583378（“使拒夏侯惇、于禁等於博望”附近）陈寿正文记刘备设伏、自烧屯伪遁、惇追击而败，**未将此战指挥归诸葛亮**。小说分兵细节不可冒充正史。
2. 第040回 L132–160 写刘表托孤、蔡氏伪诏立刘琮、宋忠降书、刘备拒夺州；《先主传》卷32同修订（“曹公南征表，會表卒”）陈寿正文记刘琮代立降曹、刘备不忍攻琮；裴注引《魏书》有刘表托国说，**裴松之明确质疑**。蔡氏伪诏不据此证明。
3. 第041回 L126–159 写十余万民众日行十余里、五千精骑追当阳；《先主传》卷32同修订（“比到當陽”）有相应陈寿正文记载，但小说魏延开门、刘琮母子被杀等尚无此处史证。
4. 第041回 L160–212 写糜芳误报、糜夫人投井、青釭剑、红光出坑及斩将五十余员；《三国志·赵云传》卷36 固定oldid=2583383（“及先主為曹公所追於當陽長阪”）陈寿正文只明确赵云抱幼主、护甘夫人脱险；裴注引《云别传》记有人误报赵云北去、刘备坚信不叛。不可将宝剑、神异、斩将数列为正史。
5. **真实第二小说文本片段异文**：数字三国网站标为《三国志通俗演义》“82.长阪坡赵云救主”，https://www.cne3online.com/library/view/11387232/1141023060857.shtml ，开篇“**一千余军马**”，而固定毛本第041回 L156 “**三千余军马**”；另前者“刘琦昔日感公之教”，后者“刘琦感公昔日之教”。该网站未给本次可固定的影印版次/修订号，故**仅登记可复查的第二网络小说文本片段**，不标记固定第二底本全回对校。
