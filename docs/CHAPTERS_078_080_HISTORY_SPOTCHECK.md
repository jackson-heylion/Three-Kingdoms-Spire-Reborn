# 第078—080回局部史料核证（不等于异本或史料全回校勘）

固定小说来源：078 oldid=2568040、079 oldid=2568043、080 oldid=7909161（详见三份逐段阅读证据）。以下史料仅逐点抽证，**全回第二小说底本异文对校0/120，全回史料穷尽校勘0/120**。

| 小说段落 | 史料原文定位 | 证据分层与未决 |
| --- | --- | --- |
| 078 L122–124 华佗剖头建议、被疑报关羽之仇，青囊书焚 | [《三国志》卷29《华佗传》](https://zh.wikisource.org/wiki/三國志/卷29)，陈寿正文载华佗为曹操治头风、因久留与妻病请归不返被收治，荀彧谏免而曹操不从；裴注与小说细节不得混同 | 史传的治疗、拒召、入狱与曹操后悔不同于小说剖脑复仇链。华佗《青囊书》被焚的具体过程不据此证实。 |
| 078 L143–145 曹操病卒、七十二疑冢 | [《三国志》卷01《武帝纪》](https://zh.wikisource.org/wiki/三國志/卷01)，陈寿正文建安二十五年正月洛阳病卒，遗令主张薄葬，二月葬高陵 | 史传不以小说七十二疑冢为确证，梦中神鬼亦非可验病因。 |
| 079 L146–161 刘封孟达拒援、叛降、刘封死 | [《三国志》卷40《刘封传》](https://zh.wikisource.org/wiki/三國志/卷40)，陈寿正文记不救关羽、孟达降魏、刘封败归，诸葛亮虑其刚猛难制，劝刘备除之，刘封自裁；裴注引《魏略》载孟达辞表 | 小说写刘备命推出斩、后悔；史传“赐死自裁”与建议动机有别，不能当同一原文。 |
| 079 L129–144 七步诗、曹植贬爵 | [《三国志》卷19《陈思王植传》](https://zh.wikisource.org/wiki/三國志/卷19) | 正文可核曹植与丁氏遭忌、封爵变动，但**本轮未找到陈寿正文支持七步作诗当庭经过**，只记小说，不作史实。 |
| 080 L143–160 魏受禅、蜀即位 | [《三国志》卷02《文帝纪》](https://zh.wikisource.org/wiki/三國志/卷02)、[卷32《先主传》](https://zh.wikisource.org/wiki/三國志/卷32)；另《后汉书·孝献帝纪》 | 曹丕220年受禅，献帝为山阳公，刘备221年称帝；小说蜀方“献帝遇害”只是谣传，献帝实际仍在世。受禅台神风与诸葛亮诈病属于小说，不当史实。 |
