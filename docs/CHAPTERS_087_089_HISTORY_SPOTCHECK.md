# 第087—089回《三国志》局部史料核证（非全回对校）

固定小说：087 [oldid=2568051](https://zh.wikisource.org/w/index.php?title=三國演義/第087回&oldid=2568051)，088 [oldid=2568052](https://zh.wikisource.org/w/index.php?title=三國演義/第088回&oldid=2568052)，089 [oldid=2646272](https://zh.wikisource.org/w/index.php?title=三國演義/第089回&oldid=2646272)。
固定史料：陈寿《三国志》[卷35 oldid=2115776](https://zh.wikisource.org/w/index.php?title=三國志/卷35&oldid=2115776)《诸葛亮传》，[卷43 oldid=2085132](https://zh.wikisource.org/w/index.php?title=三國志/卷43&oldid=2085132)《李恢传》《吕凯传》《马忠传》。仅以下条文局部核证；**第二小说底本异文全回对校及史料全回校勘仍为0/120**。

1. **087 L119–121 南征年代。** 卷35陈寿正文「三年春，亮率众南征，其秋悉平」，此前记先主崩后先遣使聘吴结盟；与小说086外交→087南征大方向相接。但小说五十万军、关索入军、王连劝谏原话均未由该句证成，不能把小说军数当史实。
2. **087 L123–131 雍闿之死是实质冲突。** 卷43《吕凯传》陈寿正文「亮南征讨闿，既发在道，而闿已为高定部曲所杀」，并记吕凯与王伉坚守永昌。小说则写诸葛亮释放鄂焕、设计反间，最终高定遣鄂焕杀雍闿朱褒。**史传的时间、直接行凶者与小说策划责任不同**，不得把小说军令冒充史证。卷43《李恢传》另载李恢分道向建宁、受围后突击，不能将所有战功都算给诸葛亮一人。
3. **087→089 攻心与七擒证据等级。** 卷35陈寿正文只记春征秋平；**裴松之注引《汉晋春秋》**才有募生致孟获、七纵七禽、孟获服从及不留外官/驻军的三条理由。小说把七次擒放展开为具体战术、对白、马谡攻心、泸水渡河、毒泉、孟节、杨锋等情节，不能说陈寿正文逐一记载，更不能把「攻心」小说对白误认作史传原文。
4. **087 王伉吕凯与吴的边政关系。** 卷43《吕凯传》陈寿正文记雍闿降吴、吴方遥授职，吕凯王伉守永昌；小说87回没有把吴廷边政档案展开。游戏孙尚香职业节点只能用**吴方后继档案视角**标明「史传背景+原创审计」，不能写孙夫人亲历南征，亦不得让吴方档案改变小说战果。
5. **088 L124 与089 L129–157 水源、瘴气。** 小说写泸水日渡伤亡、四毒泉、马援显圣、孟节药泉和祷告涌井；卷35/43上述条文不能证明具体毒理或神异。水源安全、军民医疗可作原创游戏机制，但不得将毒泉细节当作已核实自然科学。
6. **南征并非永久安定。** 卷43《李恢传》记「后军还，南夷复叛」，不能把小说后续「心服」视为永远无叛乱的史实；089回末只到第五擒，后续090、091仍待核读。

未校：真实第二小说底本逐字异文、裴注引书原貌、南中地理与族群叙事的完整考证；任何局部核证不得冒充全回完成。
