# P1 战斗资源权威事件（2026-10-24）

本增量在持久体力/金币事件之外，新增独立的 **战斗军令、护甲、回合** 事件归约。新战役从修订号0写入 `BattleResourceEvent::Started`，每个成功 `Game::apply` 写入一条 `Changed`，不依赖动作历史、RNG或战斗最近80条事件。日志随V2快照保存，旧存档缺少字段时保持 `None`，不伪造历史。

## 状态与边界

- `Idle`：成功动作发生时没有战斗。
- `Enter`：进入战斗，记录楼层、回合、军令、护甲基线。
- `Update`：同一场战斗记录军令/护甲有符号增量及回合前进量。
- `Exit`：结束战斗；下一场必须重新 `Enter`。
- 每条 `Changed` 带全局动作修订号，必须严格递增1；非法转场、跨战斗更新、负军令/护甲、回合回退、修订号缺口和整数溢出均拒绝。
- `BattleResourceProjector::push()` 校验候选态后提交，失败不改变投影；`project()` 共享同一规则。
- `Game::audit_battle_resources()` 只读对比事件归约与当前战斗资源及修订号；不改变快照或随机数。

**范围刻意有限。** 这是成功动作边界的资源账本，不记录单次卡牌结算中间态；也不恢复手牌、抽弃牌堆、敌军状态、技能监听器、随机数、完整Game。战斗在同一动作内开始又结束时，边界只能记录最终空闲态。日志和快照一起被修改仍可能伪造一致性，不能称为可信签名事件源。现阶段不将该审计自动设为旧V2存档拒绝条件，避免破坏兼容性。
