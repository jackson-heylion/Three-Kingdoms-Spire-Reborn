# 第107回《魏主政归司马氏 姜维兵败牛头山》单底本全文通读

固定来源：[维基文库第107回 oldid=2568071](https://zh.wikisource.org/w/index.php?title=三國演義/第107回&oldid=2568071)，正文 L119–166。2026-10-28从回首核至回末。状态：**单底本全文通读**；第二小说底本与史料全回校勘未完成。

| 正文锚点 | 责任、时序与知情边界 |
| --- | --- |
| L119–128（回首） | 承106曹爽携曹芳谒陵：司马懿占武库与洛水浮桥，郭太后被迫应诏；辛宪英劝弟辛敞守职，桓范出城劝曹爽挟天子赴许都。两派行动均发生在曹爽尚有兵权之时。 |
| L129–135 | 曹爽犹豫，信司马懿洛水誓约、交印回府；司马懿送粮令其误信免祸，随后张当供词引发何晏等案，曹爽兄弟及党羽被诛、籍没三族。**誓言与实际处置冲突**；不能把口供直接认定为全部被告事实。 |
| L135–153 | 夏侯令女拒改嫁、辛敞等旧臣获赦，小说插入管辂预言应验；预言、忠节故事与诛族后宽赦不是同一类证据。 |
| L154–156 | 夏侯霸惧司马氏清洗而投蜀，姜维验实后迎接；小说介绍钟会、邓艾后，姜维主张再伐，费祎劝保国治民。此处是后继蜀廷视角，不是已故诸葛亮亲征。 |
| L156–160 | 姜维以句安、李歆筑麴山两城，郭淮陈泰断水断粮，李歆负伤突围报急；姜维因等待羌援迟至，夏侯霸献袭牛头山解围策，陈泰预判并遣郭淮截洮水。 |
| L161–166（回末） | 姜维牛头山失利、粮道被截，撤至阳平关，司马师追来，蜀军以诸葛亮遗连弩守关。**108回才续写追兵与后事**，不可提前宣布反攻成功。 |

跨回：106诈病引出107高平陵政变→夏侯霸投蜀→姜维北伐麴山缺水→牛头山撤退→108追击悬念。玩家只处理**魏廷政变后责任档案/蜀军后继军报**，不改变曹爽被杀或麴山败退。
