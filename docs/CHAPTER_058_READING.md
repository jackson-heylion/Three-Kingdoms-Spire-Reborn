# 第058回《马孟起兴兵雪恨 曹阿瞒割须弃袍》单底本全文因果核读

2026-10-27。固定来源：[维基文库 oldid=7909160](https://zh.wikisource.org/w/index.php?title=三國演義/第058回&oldid=7909160)，正文 L119–161 开篇至回末连续核读。异本与史料全回校勘未完成。

| 正文位置 | 因果、责任、时序、信息边界 |
|---|---|
| L119–120 | 接057回末陈群献策，曹操欲逼孙刘联盟；孙权求鲁肃请刘备援助，孔明致书马超令曹西顾。马超起兵因父死是小说安排。 |
| L121–125 | 马超梦虎、庞德解梦、马岱报马腾父子死；刘备书至，韩遂拒曹操诱捕，八部将合兵围长安；庞德佯退，钟繇放军民出城取柴水，形成夜袭条件。 |
| L126–129 | 庞德夜破西门斩钟进，钟繇弃长安；曹操令曹洪徐晃守潼关十日，曹仁先警告曹洪躁进，徐晃反复劝守。 |
| L130–135 | 曹洪第九日受骂诱敌出关，徐晃救援未及，马岱马超庞德合围失潼关；曹操欲斩曹洪，众人劝免。失关不是徐晃主动出击。 |
| L135–144 | 马超追曹，曹操脱袍割髯、扯旗裹颈，曹洪挡马超救主，夏侯渊随后赶到；曹操赏曹洪并坚壁拒战。 |
| L145–148 | 徐晃朱灵先渡蒲阪津；曹操渡渭遭马超突袭，许褚护船并砍断攀船士卒之手，丁斐放牛马转移追兵。救主不能抹去舟卒伤亡。 |
| L149–161 | 韩遂庞德陷伏而庞德救出韩遂，马超夜袭，成宜三十骑先入虚营触伏被杀，马超庞德马岱随后突击；**回末尚未分胜负**，待059续写。 |

**相邻回**：057马腾案→058马超韩遂起兵；058夜袭→059混战冰城反间。原创玩法仅记失令与伤亡，不将割须弃袍视为已证史实。未验第二小说底本、全回史料与真人试玩。
