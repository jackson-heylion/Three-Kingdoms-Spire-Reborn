# 第072—074回：小说、陈寿正文、裴注与原创改编局部对勘

2026-10-27。仅为可追溯的**局部**史料核证，不是全回史料对勘，更不是第二小说底本异文校勘（累计0/120）。

固定小说底本：072 [oldid=2568036](https://zh.wikisource.org/w/index.php?title=三國演義/第072回&oldid=2568036) L119–150；073 [oldid=2568035](https://zh.wikisource.org/w/index.php?title=三國演義/第073回&oldid=2568035) L119–169；074 [oldid=2568037](https://zh.wikisource.org/w/index.php?title=三國演義/第074回&oldid=2568037) L119–146。

固定正史底本：《三国志》卷32《先主传》[oldid=2583378](https://zh.wikisource.org/w/index.php?title=三國志/卷32&oldid=2583378)；卷36《关羽传》《黄忠传》[oldid=2583383](https://zh.wikisource.org/w/index.php?title=三國志/卷36&oldid=2583383)；卷18《庞德传》[oldid=2579680](https://zh.wikisource.org/w/index.php?title=三國志/卷18&oldid=2579680)。各引文须辨陈寿正文与尖括号内裴松之所引书、裴松之案语。

| 议题 | 小说证据 | 史料证据与界限 |
|---|---|---|
| 汉中退军与鸡肋 | 072 L128–144 杨修解口令、被曹操杀，叙曹丕曹植争储积怨及魏延射伤曹操 | 《先主传》卷32汉中之争有曹操撤军事实；没有据此证明小说鸡肋、梦杀、魏延射曹的具体叙事。此处不把史料缺载说成绝无其事。 |
| 汉中王与称帝 | 073 L121–145 刘备先拒帝号、接受汉中王、表奏许都 | 卷32《先主传》记建安二十四年刘备为汉中王、后于章武元年称帝；两者相隔，小说“五虎大将军”作为集体官号不得由正史的各人官职直接推出。 |
| 婚使与关羽用人 | 073 L148–160 关羽辱诸葛瑾婚使、拒受黄忠同列、杖糜芳傅士仁、王甫谏潘濬 | 卷36《关羽传》陈寿正文记孙权为子索羽女遭辱、糜芳士仁因军资及轻慢心怀不安；《黄忠传》记诸葛亮预料关羽不悦、刘备称会解释。小说具体辱骂及火案细节不得直接归入史实。 |
| 七军水患 | 074 L130–136 关羽预备船筏、堵水口、放水，庞德死、于禁降 | 卷36《关羽传》陈寿正文明确「秋，大霖雨，漢水汎溢，禁所督七軍皆沒」，记禁降、德斩；**没有**写关羽人工决堤。游戏不得以小说「放水」伪称正史原因。 |
| 庞德射伤关羽 | 074 L126 小说庞德射左臂，L140 曹仁弩射右臂 | 卷18《庞德传》陈寿正文写庞德射羽中额；卷36《关羽传》另有旧日左臂流矢与刮骨，未把这两次箭伤混同。 |
| 庞德死与于禁降 | 074 L131–136 周仓擒庞德、庞德拒降被斩、于禁求降 | 卷18《庞德传》记德拒降遇害、于禁七军受水，卷36亦记于禁降；小说周仓擒人的细节不能从陈寿正文推出。 |

**原创玩法**：仅允许玩家选择是否保留撤军、婚使、粮损、预警、洪灾及俘虏处置的责任账；不允许改写小说人物生死、两次中箭、汉中王受封或于禁庞德结局。没有真实第二小说底本逐字比较，不填异本完成数；未检索到或未读取的史料条目不推断完成。
