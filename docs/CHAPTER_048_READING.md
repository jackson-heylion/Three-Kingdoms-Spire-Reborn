# 第048回《宴长江曹操赋诗 锁战船北军用武》单底本全文因果核读

2026-10-27；固定毛本网络修订：[维基文库 oldid=2568011](https://zh.wikisource.org/w/index.php?title=三國演義/第048回&oldid=2568011)。以下 L 为固定页面正文行号（繁体页面）；从 L119 开篇连续核至 L178 回末。**仅单底本；第二小说底本未对校。**

| 正文位置 | 因果、人物责任与信息边界 |
|---|---|
| L119–127 | 承047末道士揭穿连环计，048开篇揭示此人是徐庶。庞统以“西凉马腾韩遂叛乱”谣言帮徐庶脱身，徐庶请带三千兵守散关，曹操准其离营；谣言并非已经核实的叛乱，曹操也不知庞统与徐庶合谋。 |
| L129–136 | 曹操检水陆寨、长江夜宴、以统一江南自许，醉言二乔与铜雀台并横槊赋《短歌行》；此为小说宴会时序与对白，不能由诗的流传反证当夜具体言行。 |
| L156–158 | 刘馥谏诗“不吉”，曹操醉怒刺死；酒醒追悔厚葬，刘熙请尸归葬。**小说设定**；《三国志·刘馥传》只记建安十三年卒，不记被曹操杀，且记其治合肥之功。不可写成已证史实。 |
| L158–165 | 毛玠于禁报铁索船备齐，曹操部署水陆五色军阵；程昱警告连船惧火，曹操以冬季西北风反驳。焦触、张南自请小船试攻，曹操拨五百军与文聘接应。曹操并非无人预警火险。 |
| L166–171 | 韩当、周泰迎击，焦触张南阵亡，文聘接应败退；周瑜山顶见曹船密集，风掀旗角而忽然病倒，火攻仍未发生。 |
| L173–178 | 周瑜吐血昏厥，悬念留049回揭示病由与东风之计；不能在048回写已火烧赤壁。 |

跨回：047庞统连船与神秘人拦路 → 048徐庶借谣离曹、程昱警火、周瑜倒地 → 049东风与黄盖火船 → 050曹军溃退与华容。可玩只允许曹营事后补录被忽视的谏言与刘馥责任，不改徐庶离营、焦触张南战死或赤壁结局。

未验：真实第二小说底本逐字校异；《短歌行》具体写作时间；刘馥死亡原因（史传只记卒，不可据缺载断言病死）。局部正史证据另见 CHAPTERS_048_050_HISTORY_SPOTCHECK.md。
