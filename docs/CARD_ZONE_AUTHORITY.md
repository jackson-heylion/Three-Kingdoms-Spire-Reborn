# P1 卡牌区域权威事件日志（2026-10-24）

本增量记录永久牌组以及战斗中抽牌堆、手牌、弃牌堆、消耗堆的**有序卡牌状态**。从事件归约恢复卡牌位置、升级、附魔、任务进度及临时属性，不依赖动作重放、随机数或当前游戏快照。

## 契约

- 新战役 `Started(deck)` 固定永久牌组初始值；旧V2存档没有历史时继续保持 `None`，不伪造事件。
- 每个成功的 `Game::apply` 都写入 `Changed(revision)`。永久牌组未变化时只写 `None`，战斗牌区未变化时写 `Unchanged`；实际变化保留完整有序牌区。
- `Enter` 记录新战斗的四个区域；`Update` 必须保持楼层不变、回合不倒退；`Exit` 关闭战斗。再次进入的楼层必须严格递增。
- 归约器拒绝重复起点、修订号缺口、非法战斗转场、临时牌进入永久牌组；失败不推进修订号，不改变已提交状态。
- `Game::audit_card_zones()` 只读对比事件恢复结果与当前牌组及战斗牌区。旧存档缺历史时返回明确错误。

为使动作提交边界更易维护，将原 `lib.rs` 内 `Game::apply` 提取至 `src/action_commit.rs`，继续对所有日志及动作历史执行同一份草稿验证后原子提交。

这是**成功动作结束时的牌区快照事件**，不是抽牌、检索、弃牌、消耗、复制等单步事件的完整可逆因果链。无法从此日志独立恢复RNG、军略/动态监听器、敌军及完整Game；无法证明被恶意同步修改的快照和日志没有遭篡改。历史随成功动作增长，仍需后续检查点、压缩和可信事件链。旧V2保持兼容，存档版本不提升。
