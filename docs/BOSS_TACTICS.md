# 三国登塔录：六统帅战术与可预告敌方 AI

本文件记录游戏原创机制，而非宣称《三国演义》原著直接出现这些技能。六名统帅每三回合（第1、4、7……回合）的开场意图将显示专属招式；司马懿与左慈还会根据上一玩家回合打出卡牌数量改变下一轮意图。意图在上一轮结束时生成并与战斗快照一同保存，玩家在出牌前可以通过敌军状态阅读下一次行动。

| Boss | 游戏招式 | 玩家可观察结果 | 二阶段差异与应对 |
| --- | --- | --- | --- |
| 张角 | 雷咒 | 攻击并仅在真实生命受损时施加虚弱 | 二阶段雷咒更强；护甲/亲兵抵挡可阻止虚弱 |
| 孙坚 | 虎袭 | 连续两次攻击 | 二阶段三次攻击，优先考虑持续护甲与减弱敌军力量 |
| 董卓 | 暴政 | 攻击并从现有金币中扣除最多10金（第二阶段15金） | 半血触发暴虐，额外武勇；消费策略可能影响损失，但该机制不鼓励刻意理财作弊 |
| 袁绍 | 盟军列阵 | 所有存活敌人增加护甲 | 二阶段全军护甲强化，友军增加1武勇；穿透、中毒可绕过或消耗护甲 |
| 司马懿 | 暗度陈仓 | 下一个玩家回合军令减少1点，第二阶段最多减少2点；弃牌中追加军心涣散，上限4张在活动牌堆 | 若上一玩家回合打出4张及以上牌，下一次意图额外优先触发暗度陈仓；需平衡单回合连打收益与后续压力 |
| 左慈 | 幻身遁甲 | 回复体力（不超过血量上限），并获得部分护甲 | 二阶段回复更多；如果上一玩家回合打出5张及以上牌，下一次意图优先选择幻身遁甲，可考虑集中爆发 |

## 敌军协同

多个敌军同时存活时，校尉（`officer`）、谋士（`tactician`）及禁卫长（`royal_guard`）在第2、5、8……敌方回合优先为**其他存活同伴**布置护甲。若没有存活同伴，不会选择该协同意图；既存协同意图在同伴被消灭后执行时改为自保。协同护甲在生成当轮可以持续至下一次玩家行动。对该机制的反制是先清除支援角色、施加中毒或穿透防护。

## 结算与状态持久化

1. 玩家回合结束，处理未打出卡牌的保留/虚无/临时消耗和中毒结算；亲兵自动攻击。
2. 清除敌军上一轮护甲，然后检查是否进入仅触发一次的二阶段。二阶段刚获得的护甲会留存。
3. 每名存活敌军依照开局已经预告的意图行动，签名技能产生 `EnemyTechnique` 战斗事件。
4. 应用 `next_turn_energy_penalty`，并归零待生效减益；记录上一玩家回合的 `played_this_turn` 到 `last_turn_cards`，然后清空回合计数。
5. 生成下一次意图、补充手牌并记录新回合。即使高频出牌反制被触发，玩家也能提前看到相应意图。

`BossMove`、`Intent::Assist`、`last_turn_cards`、`played_this_turn`、`next_turn_energy_penalty` 通过 `serde` 持久化，其中新增状态字段对旧版V2快照使用零默认值。保留了原先的 `Game::apply` 草稿-验证-提交事务，不允许失败操作修改意图、牌堆、金币或随机数。

## 回归验收

- `cargo test --all-targets`：六 Boss 招式的预告类型、效果、虚弱触发条件、两段伤害、夺金下界、联盟护阵、延期军令压制、幻身血量上限、二阶段护甲保留、校尉协同以及中途快照同一回合重放；
- `cargo test --test bdd -- --nocapture`：`features/boss_tactics.feature` 八个 Given/When/Then 场景；
- GitHub Actions：macOS 与 Ubuntu 严格 Clippy、单测、独立 BDD、Release、终端存档恢复及每平台1000局随机种子模拟。

**仍未完成**：Boss 的完整多阶段剧本、敌军真正的动态召唤行为树、精英专属技能池、难度曲线实测、反制牌组的统计平衡。不得把本轮六招当作全部首领机制已经完成。

### 二阶段援军的先手优先级

三位可召援的Boss（张角、袁绍、左慈）在敌回合半血转阶段时召唤援军，援军只于**下一个玩家回合**获得可观察意图，下一个敌回合才行动。召唤当回合不可偷袭或凭空护卫；军阵满编时不产生单位，事件面板的 `FoeSummoned` 记录真实来源与位置。
