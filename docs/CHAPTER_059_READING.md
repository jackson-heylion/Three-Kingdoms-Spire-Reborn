# 第059回《许褚裸衣斗马超 曹操抹书间韩遂》单底本全文因果核读

2026-10-27。固定来源：[维基文库 oldid=2568022](https://zh.wikisource.org/w/index.php?title=三國演義/第059回&oldid=2568022)，正文 L119–159 连续核读。仅单底本全文阅读，异本史料全回校勘未完成。

| 正文位置 | 因果、责任、时序、信息边界 |
|---|---|
