## 可定位的真实异文及其叙事后果

**019 / 嘉靖037，逃出小沛的骑兵数量。** 毛评019开头写刘备「引數十騎奔回沛城」，嘉靖037首段写「引十數騎回沛城」。二者不是先后补兵，也不是史实兵额；双方都写吕布乘吊桥夺城、刘备弃家西逃、糜竺保眷、刘备与曹操会师。嘉靖037另写吕布给糜竺宝剑禁止伤眷，毛评019对应处没有赠剑细节。数字和道具不能直接决定游戏军力或给玩家真实宝剑奖励。

**019 / 嘉靖038，陈宫分兵之议与白门结果。** 嘉靖037回末停在吕布欲杀陈宫的悬念，038回首由高顺、张辽劝阻，吕布称「吾戲汝耳」，随后陈宫重述掎角之势。毛评019将该过程并入同一回。两版都保留严氏劝阻、袁术先索女儿、侯成受罚、宋宪魏续叛变、吕布白门受缚及陈宫拒降；不可把不同分则当成两次独立杀陈宫未遂。游戏记录拒谏和罚卒责任，不允许改写吕布生死。

**020 / 嘉靖039，貂蝉去向的小说异文。** 嘉靖039在张辽受赦后明确写曹操将「呂布妻小並貂蟬載回許都」，毛评020相同位置仅写「將呂布妻女載回許都」。毛评没有明说貂蝉随行，不等于确认她另有结局；嘉靖所述也不是《三国志》已证史实。039、040还跨分则叙许田越礼与献帝血诏，毛评020合在一回。不可从小说差异生成貂蝉历史身份或改写角色命运。

**021 / 嘉靖042，刘备推辞许褚追召的说辞。** 毛评021在许褚带五百军追至时，刘备只援「將在外，君命有所不受」，称已面君受命，许褚复命后曹操仍存疑。嘉靖042在同一位置额外写刘备指称程昱、郭嘉「累次問我取金帛」遭拒、因而在曹操前进谗；曹操还当面责问二谋士，二人否认并称又被刘备蒙蔽。这是**刘备在小说中的策略性指控**，并非已证两谋士实际索贿。两版都保留刘备脱许都、车胄伏杀军令、陈登预警、关羽斩车胄、张飞杀其家属，不能改变人物责任。
