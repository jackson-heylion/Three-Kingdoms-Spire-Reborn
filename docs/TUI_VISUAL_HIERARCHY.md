# 终端战术视图：信息层级与键盘操作

本改动仅调整 `tks --tui` 的展示和按键交互，不改变 `Game`、成功动作、RNG、存档格式、`--plain` 或命令解析逻辑。

## 默认战术视图

- **第一视线：** 武将生命、所在幕/层、军令/护甲/回合；生命按阈值提示，敌军选中目标与意图采用与其他内容不同的视觉状态。
- **第二视线：** 可选手牌/行动，焦点整行反色并保留 `▶`；不能支付军令的卡牌延续原来的 `×` 文字提示；结束回合与取消操作有单独标识。
- **第三视线：** 默认每张手牌只显示名称与费用，选中牌的完整说明在一行固定位置呈现；其他卡牌完整说明与调试资源在详细视图查看。
- **低优先级：** 最近战报、操作反馈保留独立标签，紧凑终端先保证状态、选项与底部帮助；不将长日志挤到决策菜单前。
- **状态按需展示：** 战意/谋略/连段/统御/怒气/反击中，默认只显示非零项；粮尽、反击等高风险提示主动展示。更多模式、战法、抽弃耗牌堆、持续军略等放在详细视图。

## 操作

```text
cargo run --bin tks -- --tui
↑ / ↓ 或 j / k     移动焦点
Enter / 1-9        执行动作（数字与原菜单索引一致）
t                  切换存活敌军目标
v                  战术视图 ↔ 详细视图（不消耗回合）
:                  输入原有高级命令
?                  原有命令帮助
q                  保存并退出
```

详细视图是会话内展示状态，不持久化到游戏存档，也不影响行动事件源。现有暗色、亮色、高对比度主题分别采用语义调色板；颜色关闭时仍以 `▶`、`×` 和文字说明传达焦点与限制。

## 验收与边界

`src/hud.rs` 的单元测试验证：28×16、40×20、80×24、120×38 中文宽字符边界、选中操作滚动到可视区、默认说明去重与详细视图恢复、ANSI 启停和三主题、失败动作与副选牌选择相关菜单文字保持可见。原有 HUD/TUI 回归测试继续保留。

```bash
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
cargo run --bin tks -- --tui
```

**仍需真人验收：** 真实 28×16/40×20 TTY、macOS/Linux 字宽和终端配色、键盘焦点与屏幕阅读器。此改动不代表完整无障碍、多语言或 P1 全部验收。
