# 第100回《汉兵劫寨破曹真 武侯斗阵辱仲达》固定单底本全文核读

固定底本：[维基文库第100回 oldid=2568063](https://zh.wikisource.org/w/index.php?title=三國演義/第100回&oldid=2568063)，正文 L119–149；2026-10-28从回首至回末逐段核读。**单底本全文通读；无第二小说底本全回对校。**

| 正文位置 | 叙事因果、人物责任、知情边界 |
| --- | --- |
| L119–121（回首） | 承099魏军霖雨退兵，诸葛亮判断司马懿必设伏而不追，改从箕谷、斜谷争祁山。曹真不信司马懿预判，两人打赌分守谷口；司马懿军中有士卒因久驻而怨，被斩以肃军纪。 |
| L122–125 | 邓芝传谨防伏兵军令，陈式嘲讽街亭失守、魏延重提子午谷。陈式擅率五千出箕谷中伏，魏延救回仅四五百带伤士卒；诸葛亮令邓芝抚慰并另分两谷设伏。**魏延救援不等于他曾下令陈式违令。** |
| L126–129 | 秦良追敌被伏杀，多数魏军降。蜀军借魏军衣甲假扮回营，曹真忽视司马懿预警而遭三面袭击；司马懿赶来接应曹真退到渭滨。俘虏、降卒与诈营需分开记账。 |
| L130–133 | 诸葛亮审陈式违令并处斩，未处斩魏延；又将讥讽书交给被放归的魏降卒带给曹真，小说写曹真读信后愤死。**曹真死因是小说情节，不可冒充《三国志》记载。** |
| L134–138 | 司马懿与诸葛亮阵前辩论并斗阵，魏将戴陵、张虎、乐琳入八卦阵被俘，诸葛亮释放但留下军器战马并墨面，司马懿随后遭关兴姜维夹击而退守。此处为小说战法，不能用来断言史传有同样斗阵。 |
| L139–143（回末） | 李严部下苟安迟运粮十日，诸葛亮欲斩，杨仪劝止，改杖八十。苟安投魏，司马懿使其回成都散布诸葛亮谋反谣言，刘禅召回诸葛亮；诸葛亮遵诏，借**每日增灶**阻魏追击。末尾悬念是回成都后如何解释召还，留待101。 |

跨回：099不追雨退魏军→100陈式违令惨败、劫曹真寨与小说愤死→苟安迟粮受罚、假消息召回→101核查宫中谣言与再出师。玩家可选择完整记录违令伤兵和降卒责任，不改变陈式或曹真结局。
