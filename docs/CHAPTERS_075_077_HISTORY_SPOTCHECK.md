# 第075—077回：固定小说与《三国志》局部核证

| 议题 | 小说（固定行） | 史料证据、层级与不能推出之处 |

| 刮骨疗毒 | 075 L119–124：樊城右臂箭伤，华佗手术，关羽与马良弈棋 | 卷36《关羽传》陈寿正文：旧日左臂流矢后阴雨骨痛，“医”刮骨，饮酒割炙，没有写华佗、马良、樊城右臂。卷29《华佗传》记其事曹操并遭杀，未据此证实小说同一手术。 |

| 关羽首级与葬礼 | 077 L151–152：张昭移祸、司马懿解计、曹操厚葬并见首级神异 | 卷36《关羽传》裴注引《吴历》记孙权送首曹操、以诸侯礼葬尸骸；未证实小说首级显灵及完整对话。 |
