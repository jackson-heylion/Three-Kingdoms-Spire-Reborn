# 第093回《姜伯约归降孔明 武乡侯骂死王朗》固定单底本正文核读

固定单底本：[维基文库第093回 oldid=2568056](https://zh.wikisource.org/w/index.php?title=三國演義/第093回&oldid=2568056)，正文 L119–145；2026-10-27从回首至回末核读。**单底本全文通读；第二小说底本全回异文及史料全回校勘均未完成。**

| 固定正文位置 | 因果、人物责任、时序及知情边界 |
| --- | --- |
| L119–120（回首） | 承092姜维识破伪信；姜维预判赵云诱守军离天水，马遵准其三千伏兵，梁绪尹赏留城。赵云误以为守备空虚进兵，姜维夹攻，张翼高翔接应赵云撤退。赵云初战不敌不等于已败尽北伐。 |
| L122–123 | 姜维分四路守天水，诸葛亮亲至又遇伏，关兴张苞护出；诸葛亮探知姜母在冀县、上邽为粮仓，令魏延佯攻冀县、赵云取上邽，迫姜维和梁虔分兵。 |
| L124–125 | 魏延诈败让姜维入冀县见母；诸葛亮释放夏侯楙并散布姜维降蜀假消息，夜间派貌似姜维的兵卒假扮攻天水。**此时真正姜维尚未降蜀**，天水误信是反间造成。 |
| L126 | 姜维出城劫粮遇张翼王平夹击，魏延已取冀县；天水马遵、上邽梁虔均因假降传言拒其入城。关兴截归路，诸葛亮出面劝降，姜维在走投无路后才下马归蜀。姜母下落和亲属离散不能因招贤叙事抹去。 |
| L127 | 姜维写两封密信，马遵疑梁绪尹赏为内应；二人恐被杀，开天水城门归蜀，梁虔随后献上邽。诸葛亮安民并任命三人；夏侯楙马遵逃走。小说的三城所得到此才兑现。 |
| L128–131 | 魏廷闻三郡失守，曹叡委曹真、郭淮、王朗率军。王朗以魏受禅为合法、诸葛亮以汉统为正统展开阵前论辩，小说写王朗被辱激死；**这不是《三国志》记载的死因**。 |
| L137–139（回末前） | 郭淮拟趁丧伏击，诸葛亮反用空寨与火号使曹遵朱赞、曹真郭淮军互相误攻，魏军退。责任链不能写成单靠骂阵取胜。 |
| L140–145（回末） | 曹真郭淮商议改向西方求援，悬念直接引出094郭淮求羌援军。 |

跨回：092姜维识诈信未降→093假降离间、冀县失守、归蜀及三城归附→094曹真郭淮求羌兵与新城孟达危局→095街亭退军。游戏只允许选择**原创新兵交接、民户与谣报证据**，不改姜维归降、王朗小说死法及魏军退败。
