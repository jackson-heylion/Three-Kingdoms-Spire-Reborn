# 第067回《曹操平定汉中地 张辽威震逍遥津》固定单底本全文因果核读

2026-10-27。固定底本：[维基文库 oldid=2568030](https://zh.wikisource.org/w/index.php?title=三國演義/第067回&oldid=2568030)，正文 L119–185 从开篇至回末核读。仅单底本通读，不是异本及史料全回对校。

| 原文位置 | 因果、人物责任、时序与信息边界 |
|---|---|
| L119–127 | 承066曹操决西征。张卫守阳平，杨昂杨任先夜袭夏侯渊张郃，曹军初败；曹操视险、许褚徐晃护驾；对峙五十余日后曹操假退，杨任劝杨昂勿追不从，雾中夏侯渊误入空寨，张郃夹击、杨昂死，张卫弃关。不是曹操无战损神机一举。 |
| L128–142 | 杨任战死，曹操欲收庞德，密使以金甲结杨松离间；庞德被张鲁怀疑、次战被曹操设陷擒获，因张鲁不信而降曹。须分清杨松诬告与庞德真实忠勇。 |
| L143–153 | 张卫欲焚库，张鲁拒烧而封藏；张鲁走巴中、杨松闭门，张鲁被迫降，曹操因封仓礼遇并斩杨松。司马懿刘晔劝趁势攻蜀，曹操以士卒疲劳不从。史传有封仓投降，雾袭及杨松细节需单独核。 |
| L154–164 | 刘备因汉中受压，孔明谋归三郡、遣伊籍促孙权攻合肥；张昭知是借吴牵曹仍支持攻合肥。吕蒙献先取皖城，甘宁先登，朱光死；凌统因甘宁杀父旧怨宴上舞剑，吕蒙居间阻止。此处两人**尚未和解**。 |
| L165–175 | 张辽收到曹操“贼来乃发”密匣，与李典乐进议先击；李典舍私怨。吴前军追乐进，张辽李典夹击，谷利教孙权跳断桥，凌统部众几尽而本人受伤脱险。不能将凌统写死。 |
| L176–185 | 张辽遣薛悌求援，曹操判断蜀已稍定，留夏侯渊张郃守汉中、转军濡须；下回才发生甘宁百骑夜袭与董袭风覆船。 |

跨回：066吴蜀荆州争议→067伊籍使吴；067皖城、逍遥津→068濡须。诸葛亮并未亲到合肥，孙尚香不在合肥军中，二者玩法只能采用后送使书/家簿。**未校**：第二底本全回异文、史料全回、真人试玩。
