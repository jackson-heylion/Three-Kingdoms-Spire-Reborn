# 第103回《上方谷司马受困 五丈原诸葛禳星》单底本全文通读

固定来源：[维基文库第103回 oldid=2568064](https://zh.wikisource.org/w/index.php?title=三國演義/第103回&oldid=2568064)，正文 L115–164，2026-10-28逐段核对回首至回末。状态：单底本全文通读，异本/史料全回未校。

| 固定正文位置 | 情节、人物责任与知情边界 |
| --- | --- |
| L115–117（回首） | 承102末张翼廖化截击，司马懿弃盔诱廖化误追，张嶷夺粮入营；廖化献盔得头功，魏延不平。魏廷因吴三路攻势下令司马懿坚守。 |
| L118–123 | 曹叡、满宠反制孙权三路攻势，满宠火烧吴军水寨；陆逊使者携表被魏截获，计划泄露，陆逊以种豆射戏稳军心、佯攻襄阳掩护有序撤退。吴军无功而返的消息稍后才传到诸葛亮，不得让前段蜀营提前知晓。 |
| L124–129 | 诸葛亮令蜀军与魏民相杂屯田，约军一分、民二分；司马懿坚持守营。马岱布上方谷火具、魏延诱敌、高翔以木牛流马作诱饵，夏侯惠和夏侯和夺车、俘蜀兵，司马懿释俘取人心；反复截粮使司马懿误信蜀军可乘。 |
| L131–139 | 司马懿令诸将攻祁山，自己赴上方谷；魏延诱其父子入谷，蜀军纵火，骤雨灭火，司马懿父子逃出。诸葛亮承认谋成败受天候限制。**小说骤雨救人不可作为史传确证，更不能在玩法中由玩家改写司马懿死活。** |
| L141–155 | 司马懿据渭北不出，诸葛亮驻五丈原，送巾帼激战；司马懿借请战奏章、辛毗持节压住将领。小说记使者报告诸葛亮食少事烦、杨顒劝其分劳。陈寿正文记五丈原屯田、病卒；巾帼与辛毗见裴注引《汉晋春秋》，食少事烦见裴注引《魏氏春秋》，不能混层。 |
| L156–159 | 费祎带回吴军败退，诸葛亮忧疾复发，姜维助设禳星灯；魏延因魏兵试探冲帐扑灭主灯，诸葛亮自认生死有命。禳星与主灯灭是小说仪式及象征，不是现代因果诊断。 |
| L159–164（回末） | 姜维拔剑欲杀魏延；诸葛亮尚未作答，留下104回开篇制止杀戮。不得在103回提前写诸葛亮已死、魏延已被处刑。 |

跨回：102运粮疑兵→103火计失效与魏军守势→吴盟失败军报→禳星灯灭→104诸葛亮制止姜维、遗命与退军。玩家选择记录屯田民权、火攻伤亡与军令，不得复活人物或改变骤雨。
