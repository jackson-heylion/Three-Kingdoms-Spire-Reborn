# P1 敌军棋盘权威状态日志（2026-10-24）

此前事件流已能恢复战斗统计、持久资源与军令/护甲/回合，却不能独立恢复敌军生命、护甲、减益、阶段和下一步意图。本增量新增 `foe_board_events`，在每次成功的 `Game::apply` 原子提交边界记录敌军棋盘完整状态；`FoeBoardProjector` 不执行动作、不调用 RNG，也不依赖游戏快照，即可重建最近一次已提交的敌军状态。

## 事件与验证契约

- `Started`：新战役初始空闲态。旧V2存档不补造历史。
- `Changed(revision, Idle)`：非战斗成功动作，保持空闲。
- `Enter(board)`：进入一场战斗，记录楼层、回合、1–4个敌军的身份、生命、护甲、力量、中毒、虚弱、易伤、阶段与已预告意图。
- `Update(board)`：同一场战斗成功动作后的完整敌军状态；可以包含召援与状态改变，但不得倒退回合或跨楼层伪装更新。
- `Exit`：战斗结束。下一场的楼层必须严格递增，不允许重开已结束的同一层战斗。

归约器拒绝缺少 `Started`、重复开头、修订号重复/缺口、非法敌军属性、空敌军列表、错误转场及重复楼层。任何拒绝都不改变上次成功状态和修订号。`Game::audit_foe_board()` 只读比较独立归约与当前存档中的敌军状态及全局修订号。它不对外部恶意同步篡改事件和快照提供密码学证明。

## 范围与代价

这是**动作提交边界的完整敌军状态快照事件**，不是每次受击的细粒度 `DamageDealt`，也不是完整Game的事件源重建。一次动作内先生成后消失的临时战斗无法通过边界状态恢复。保存量随成功动作数与敌军数线性增长（每战最多4个敌军）；后续需要考虑压缩、事件链完整性与可信检查点。现有V2字段不改版本号，老档缺日志时仍可玩，但不宣称具有历史敌军事件源。
