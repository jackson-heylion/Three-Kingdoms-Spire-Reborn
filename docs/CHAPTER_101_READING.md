# 第101回《出陇上诸葛妆神 奔剑阁张郃中计》固定单底本全文核读

固定底本：[维基文库第101回 oldid=2568067](https://zh.wikisource.org/w/index.php?title=三國演義/第101回&oldid=2568067)，正文 L119–161；2026-10-28从回首至回末逐段核读。**单底本全文通读，非异本或史实全回对校。**

| 正文位置 | 叙事因果、人物责任、知情边界 |
| --- | --- |
| L119–121（回首） | 承100增灶退军，诸葛亮回成都问刘禅为何召还，查苟安散谣并追究内廷责任；再到汉中，杨仪提出轮换军制，诸葛亮定每百日轮替。建兴九年曹真已死，司马懿奉曹叡命守西线。 |
| L122–125 | 李严粮运迟滞，诸葛亮谋割陇麦；他用数辆同样四轮车与姜维、马岱、魏延假扮、鼓阵引魏军反复追逐，借机割麦运到卤城。司马懿一度信神术，俘虏解释后方知假车。**神异是小说战术伪装与人物误判，不是历史魔法。** |
| L126–129 | 司马懿、郭淮夜围卤城，诸葛亮伏四角麦田并开城夹击，魏军败；郭淮提议袭剑阁断蜀粮道，孙礼引援，司马懿从正面进攻。 |
| L131–133 | 杨仪报告百日轮换期限已到，魏援又急至，众人建议暂留换班兵。诸葛亮坚持军令与归期，士卒自愿留下迎战。**自愿作战与强留过期兵有本质区别**，史料裴注郭冲故事被裴松之批评，不可当陈寿正文。 |
| L134–140 | 卤城得胜后李严密报东吴将与魏联兵伐蜀，诸葛亮为防东线变故下令撤军。玩家不得提前把传闻当真实吴军进攻；撤退后李严的矛盾说法尚待核查。 |
| L141–153 | 司马懿先拒追，张郃坚持追击；诸葛亮使魏延关兴轮番诱敌至木门道，杨仪马忠伏弩，张郃中伏而死。史传仅确认木门追击中箭，具体追击命令和中箭位置另有裴注异说。 |
| L154–155 | 费祎带来刘禅对撤军的质询，诸葛亮出示李严来信，查明粮运不继、两面误报。李严被贬庶人迁梓潼，其子李丰仍被任用；小说接着写休养积粮三年。 |
| L155–161（回末） | 建兴十二年诸葛亮再议北伐，刘禅问安享太平，谯周出班谏阻，**谏议尚未展开**，留待102。不能把102战局提前计入101。 |

跨回：100苟安谣言召还→101宫廷清查与百日轮换→割麦与卤城防线→李严误报导致撤军、张郃木门遇害→102谯周谏伐与新一轮出师。玩家只审军粮、家属轮换和误报责任，不更改小说人物结局。

未校：真实第二小说底本全回异文；李严前后书疏异文；张郃木门战术的多史源争议；具体卤城割麦数额。局部史证见 CHAPTERS_099_101_HISTORY_SPOTCHECK.md。
