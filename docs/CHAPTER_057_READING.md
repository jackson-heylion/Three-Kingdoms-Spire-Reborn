# 第057回《柴桑口卧龙吊丧 耒阳县凤雏理事》单底本全文因果核读

2026-10-27。固定来源：[维基文库 oldid=2568020](https://zh.wikisource.org/w/index.php?title=三國演義/第057回&oldid=2568020)。从开篇 L119 至回末 L211 连续核读，包含诗赞和回末悬念。**仅单底本全文，不是异本逐字对校或全回史实核证。**

| 正文位置 | 因果、责任、时序、信息边界 |
|---|---|
| L119–124 | 承056周瑜假途取蜀受挫，孙瑜来援，刘封关平截江；孔明书劝勿远征，周瑜病亡于巴丘。**死亡发生在057而非056**；小说归因孔明刺激，不能当作史实。 |
| L127–140 | 周瑜遗书举鲁肃继任，孙权从之；孔明先观星、再遣人核实，后偕赵云赴柴桑吊丧。星象预知属小说设定，孔明不曾在巴丘亲眼目睹死亡。 |
| L141–161 | 孔明祭文与哭祭使吴将改变看法；渡口见庞统，留荐书劝其投刘备。祭文真情或策略不能据一段表演断定。 |
| L163–165 | 鲁肃荐庞统于孙权，孙权因外貌与应答不悦拒用；鲁肃另写荐书劝其投刘。庞统佯称投曹，实际未投曹。 |
| L167–171 | 孔明巡四郡未归，庞统未出示两封荐书，刘备以貌取人授耒阳令；庞统百日不理案，张飞欲治罪，孙乾劝核实，庞统半日断积案。不可写成刘备一见即授军师，也不能抹去百日延误。 |
| L172–174 | 张飞携鲁肃书回报，孔明归来再荐，刘备请罪并授副军师中郎将；先复查、后双荐、再任命。 |
| L175–185 | 曹操因西凉顾虑假征南诏召马腾；马腾与黄奎谋在点兵时刺曹，黄奎醉向妾李春香泄密，苗泽告曹。泄密者与告发者责任分开。 |
| L186–203 | 曹洪等伏兵杀马铁、擒杀马腾马休黄奎；曹操处死苗泽春香及黄奎家属，马岱扮商逃脱。第058回马超闻讯兴兵，不得误记马岱已死。 |
| L203–211 | 曹操闻刘备将取西川再生顾虑，谋士献离间孙刘之策，回末未揭人名。 |
