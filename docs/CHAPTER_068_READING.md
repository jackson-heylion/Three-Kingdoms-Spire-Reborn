# 第068回《甘宁百骑劫魏营 左慈掷杯戏曹操》固定单底本全文因果核读

2026-10-27。固定底本：[维基文库 oldid=2568031](https://zh.wikisource.org/w/index.php?title=三國演義/第068回&oldid=2568031)，正文 L115–170 从开篇至回末连续核读。仅单底本通读，未完成异本文字全回校勘。

| 原文位置 | 因果、人物责任、时序与信息边界 |
|---|---|
| L115–126 | 承067曹操南援，凌统请三千哨战、甘宁请百骑；甘宁用鹅翎识别、夜劫魏营，未入曹操中军、全骑返吴；孙权赏赐。小说“无损”限百骑，不等于整场战争无伤亡。 |
| L127–128 | 凌统再战，曹休暗箭射其马，乐进将刺，甘宁射伤乐进救凌统；二人释父仇结生死之交。**与067宴上舞剑未和解的先后必须分清**。 |
| L129–137 | 曹军五路攻濡须，董袭守船遇风浪、严令不弃船而覆没；周泰多次入围救孙权及徐盛，陈武与庞德战死，陆逊援军到；孙权厚葬董袭陈武、宴赏周泰伤痕。不能提前把董袭死亡归入067。 |
| L138–141 | 孙权曹操久战议和，吴先撤军；曹操归许，崔琰反对进王遭诛。此为小说政治归责，正史崔琰死因需逐条核证。 |
| L149–151 | 曹操受魏王、曹丕曹植争嗣，贾诩借袁绍刘表家事答储位；不能把小说当作完整史传时间线。 |
| L152–159 | 左慈运橘空壳、龙肝、牡丹、松江鲈鱼、分杯化鸠皆属小说神异段落；玩家可记为传闻，不当作物理史实。 |
| L160–170 | 许褚追左慈、羊群异变、三四百同形者遭斩、尸首复起与风沙，回末曹操仍未死，悬念留069。 |

跨回：067逍遥津退守→068濡须救援及甘凌和解→069左慈余波。孙尚香仅可据江东家簿审读，不虚构其亲率百骑；曹操剧情应区分刑责、异闻与既成魏王册立。**未校**：第二底本、全回正史、自然地图多种子可达性、真人试玩。
