# 第089回《武乡侯四番用计 南蛮王五次遭擒》固定单底本正文核读

固定底本：[维基文库第089回 oldid=2646272](https://zh.wikisource.org/w/index.php?title=三國演義/第089回&oldid=2646272)，正文 L119–172。2026-10-27 按该固定修订从回首至回末核对。**单底本全文通读，第二小说底本及史料全回校勘未完成。**

| 正文锚点 | 连续因果、责任及信息边界 |
| --- | --- |
| L119–125（回首） | 承088孟获募众：诸葛亮借吕凯建议建西洱河竹桥，三寨拒战后撤、留灯火和辎重诱追，赵云魏延王平马忠等分路截击，魏延陷坑伏兵**第四次擒孟获**；先安抚放归洞丁，非全部被斩。 |
| L126–129 | 孟优先获释，孟获拒服后再次放还；孟获、孟优逃至朵思秃龙洞，封平坦东路、逼蜀军走西北险道。朵思讲四泉（哑、灭、黑、柔）与时辰瘴气，属于小说险地设定。 |
| L130–148 | 六月暑热，蒋琬主张退军未获准；王平前军误饮哑泉失声，诸葛亮到伏波马援庙求助，老人介绍毒泉与孟节居所。祈神显灵与毒泉性质不能据此认定为史实或医学结论。 |
| L149–157 | 诸葛亮寻孟节，孟节自称孟获之兄、与其决裂，指药泉与避瘴草；军士恢复，后诸葛亮掘井不得水，祷告后井水涌出。此处神异与具体药理均待独立核证。 |
| L164–172（回末） | 朵思惊蜀军不受毒泉，杨锋率洞兵佯援、席间命子侄擒孟获孟优朵思，形成**第五擒**；孟获仍不服，诸葛亮再放归，约下回三江再战。**第五擒不是七擒完成，更不可把089的水源问题视作090已平。** |

跨回：087初擒→088第二第三擒及地方洞主被杀→089第四第五擒、毒泉与孟节→090后续南中战事。原创剧情只改军民水源记录、地方合作信任与奖励，不改原著擒放次数。

未校：第二小说底本异文、孟节与杨锋史实身份、四泉医学证据、各地名方位、小说对南方族群的刻板叙述与史料的关系。局部史证见 CHAPTERS_087_089_HISTORY_SPOTCHECK.md。
