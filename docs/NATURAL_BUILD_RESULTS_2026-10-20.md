# P1 五职业十五构筑：正常起始牌成型与胜场基线（2026-10-20）

> **当前不能认定十五构筑成熟**：定向奖励策略133/165胜，普通战术选牌134/165胜；仅35/165局在终局集齐各构筑指定的4种关键牌。每套11个飞升等级各1固定种子，样本不足以估计可靠胜率。

## 实际来源与方法

- 代码：[PR #44](https://github.com/jackson-heylion/Three-Kingdoms-Spire-Reborn/pull/44)，合并提交 719c96aadf8d1e19bbdf0f77b25f3e41512bd7e9；运行的源分支提交 446d00466689847357b7c3e27db66b7db7fa88ff。
- [GitHub Actions #39361509603](https://github.com/jackson-heylion/Three-Kingdoms-Spire-Reborn/actions/runs/39361509603) 双平台成功，制品 tks-balance-ubuntu-latest（artifact ID 12237169295），其中 tks-natural-builds.json 是以下全部数值的直接来源；macOS逐字节校验相同。
- 可复算命令：cargo run --release --bin tks-sim -- --natural-builds 1 tks-natural-builds.json。15套 × 11飞升 × 每档1固定种子 × 两种策略 = 165对、330局游戏。从标准十张起始牌开始，不注入任何关键/支援卡。两种策略同初始种子与 tactical bot，但分歧后可改变RNG消耗及路线，不能视为完全相同对手的严格因果对照。
- “四核心齐全”仅指终局永久牌组拥有全部4个指定关键卡的不同ID；“二支援齐全”类似。目标奖励实际拾取率仅描述已经出现的可选奖励，不代表目标奖励自然出现率或全卡必定成型。

## 直接暴露的未通过事项

1. **构筑获取仍是瓶颈**。四核心只有35/165局收齐，关羽单骑爆发、诸葛七擒毒谋分别0/11。这是当前奖励规则、路线、战术机器人下的现象，不能只根据注入成型卡组的理想战绩宣布成熟。
2. **孙尚香飞羽弃换必须优先排查**：基线9/11胜、定向5/11胜、四核心1/11、二支援1/11。可能来自弃换次数/过牌/防御机会成本或策略执行问题，但终局聚合不能证明根因。需要逐次记录奖励候选、选牌、主动弃换、体力战损和遭遇敌军。
3. **曹操试验天花板**：三套普通与定向均11/11胜，不能区分强弱。扩增飞升8–10压力样本，记录Boss伤害、回合时长及军令循环，而不只是最终胜负。
4. **关羽群斩出现改善但不可推断稳定性**：8→11/11胜，四核心4/11；需要更多种子及配对置信区间。诸葛其他牌组也需要真实运营层面的成型与胜率验证。
5. **Boss反制未经正确对位检验**：未记录指定Boss遭遇分母、等价状态下对照敌人的胜率、逐Boss HP损失和行动意图；不能根据最终败在哪一个敌人推断真实克制作用。

每套需多策略机器人、大样本配对飞升分层、真实市场/奖励的获取率及成型楼层、慢局软锁/受伤、指定Boss对照实验及遭遇次数分母、置信区间、人工试玩。此增量只增加有源数据的诊断，不调整牌值，不改P1完成状态，不发正式1.0。
