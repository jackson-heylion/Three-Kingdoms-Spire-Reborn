# 第031回《曹操仓亭破本初 玄德荆州依刘表》单底本连续核读

核读日：2026-10-27。固定来源：维基文库《三國演義》第031回 oldid=2567992，https://zh.wikisource.org/w/index.php?title=三國演義/第031回&oldid=2567992 。从“卻說曹操乘袁紹之敗”至“未知勝負如何”连续核对。单修订全文因果核读，未做第二底本逐字对校及正史全回核证。

1. “卻說曹操乘袁紹之敗”→“乃自刎於獄中”：袁绍仅率残骑退黎阳，蒋义渠收拢溃兵；败卒怨未听田丰，袁绍羞悔；逢纪诬田丰嘲笑败绩，袁绍遣剑使，田丰料到必死并在狱自刎。第030回沮授被杀在前，本回田丰之死在后。
2. “田豐既死”→“立嗣之事再容後議”：袁绍欲立袁尚，审配逢纪拥尚，辛评郭图拥谭；郭图指出废长立幼将致内乱，袁绍当时未定。不能提前写成袁尚已正式继位。
3. “袁熙引兵六萬”→“如殺人之罪”：四州援军集结，曹操问民疾苦、下令军士不得杀乡民鸡犬；黄星真命之说出自小说父老转述，不是史实或天象已证。
4. “倉亭下寨”→“暫掌軍事”：史涣战袁尚遭回马箭射死；程昱献十面埋伏，曹军诱敌至河岸、十队逐次截杀；袁绍惨败吐血，遣袁谭、袁熙、高干回各州，留袁尚审配逢纪暂掌军政。
5. “操自倉亭大勝”→“往汝南來迎劉備”：曹操不立刻攻冀州，顾及秋收与审配守城；荀彧报刘备自汝南欲袭许都，曹操返师。这里的休兵、秋收与军粮是小说叙述，不能视作已核史实。
6. “玄德與關張趙雲”→“關張同回”：刘备初胜曹军，随后龚都粮队受围、汝南被袭，关羽张飞分路救援反被围；刘备夜撤遭曹军伏击，刘辟救主被高览斩，赵云杀高览，关羽等接应，龚都已死，刘备残军不足千。不能把关羽、张飞写成战场逃跑不救。
7. “前至一江”→“同入荊州”：刘备在汉江感叹困境，孙乾自请先见刘表；蔡瑁主张拒纳甚至杀孙乾，刘表斥退并亲迎刘备。刘表收容是小说中的主动决定，非曹操安排。
8. “操探知玄德已往荊州”→“未知勝負如何”：程昱劝曹操先防河北、暂不伐荆州；至建安八年春，曹操再进官渡，袁绍病中欲战、袁尚代领前军，征召三路援军。下一回开篇袁尚败回，不能把袁绍之死提前放在本回。
