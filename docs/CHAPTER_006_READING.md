# 《三国演义》第006回全回因果审读：迁都焚洛阳、救曹洪与藏玉玺

审读日：2026-10-20。单一底本：[维基文库《三國演義/第006回》固定修订 oldid=2567969](https://zh.wikisource.org/w/index.php?title=三國演義/第006回&oldid=2567969)，题为「焚金闕董卓行兇　匿玉璽孫堅背約」。核读范围从张飞关下遇箭退回，到孙坚被刘表部下合围、文本留待下回结束的全部正文段落。**这不是毛评、其他版本及《三国志》《后汉书》的逐字对校；文本归因只对该修订页负责，不把演义当史实。**

## 全章事件顺序与文本边界

1. 第005回张飞欲趁追吕布直接捉董卓，至本回实际因关上箭石密集而退，不是董卓被擒。孙坚责袁术听谗不拨粮，袁术不能答辩，斩进谗者以谢。随后董卓遣李傕以婚姻招纳孙氏，孙坚断然拒绝；断粮之责和拒婚的反董姿态须分别叙述。
2. 吕布新败，李儒依据街市童谣力劝董卓迁帝长安。杨彪、黄琬、荀爽分别反对废弃宗庙、迁都荒残与扰民，受黜；周毖、伍琼再谏反被董卓因早年保举袁绍追罪，立即杀害。此处**伍琼不是第004回行刺失败的伍孚**，也不能将两者归为同一事件。
3. 迁都不是“洛阳空城自然毁灭”。李儒提议籍没富户资财、董卓纵兵驱迁百姓并放火焚毁宫室与民居、掘前代陵寝。正文描写大规模强制迁徙与杀戮；游戏若只写金银财富转移，就删除了这一政权暴力的主要受害者。
4. 董卓撤后，赵岑献关，孙坚入洛阳先组织灭火，之后修复祭祀场所、祭祀汉室列圣；诸侯入城。袁绍称诸兵疲困拒绝立刻追董，曹操认为应追，独率曹家将领出击。**盟军没有共同发动追击**。
5. 董卓预设荥阳伏兵，先由吕布、李傕、郭汜三路对曹军形成压力，再由徐荣伏兵截退路。曹操肩中箭、马被击倒、被兵卒擒住，曹洪杀兵救曹，舍马并背曹渡河，后来夏侯惇击杀徐荣救险。不能把“曹洪舍身”误记成曹洪战死，亦不能写曹操独自无伤逃生。
6. 孙坚在洛阳祭祀后，夜见井中奇光，军士下井打捞宫女遗体；**锦囊包着金锁朱红小匣，内藏缺一角镶金玉玺**，并非“井里直接挖出金匣”或“董卓主动交玺”。刻文与玺传承由程普解释，属于该小说中的器物身世叙事；第003回确有“宫中玉玺失踪”的伏线，本回首度给出该底本中的寻回经过。
7. 程普据玉玺劝孙坚回江东另图大业；孙坚决定托疾离营、秘密保有此物。有一名袁绍同乡士卒潜报袁绍；袁绍在帐中要求交回朝廷宝物，孙坚否认、发誓并拔剑争执，双方险些武斗。此段兼有“公益归朝廷”与“争盟主控制权”的张力，非单一善恶判断。
8. 袁绍密信荆州刘表拦孙坚，刘表部将蒯越、蔡瑁与孙坚军交锋；黄盖击蔡瑁护心镜，孙坚初破拦截，却遭刘表及伏兵夹攻。**本回到包围为止，孙坚最终如何脱险留待下回**。不能提前借后回剧情写成本回孙坚战死。
9. 关东联盟在追董决策、玉玺归属、补给、粮借上继续分裂：刘岱因乔瑁不肯借粮而杀之、收其兵；曹操另投扬州，刘备三兄弟随公孙瓒北返。联盟败坏的根源不是一次虎牢关胜负，而是一系列内部政治、粮道与权力冲突。

## 两条真正相关的前后回链

**第003回缺玺→第006回井中取玺→第020回衣带诏→第120回晋室结局：**现有游戏 `imperial_jade` 旗 `jade_whisper` 已连向 `mandate` 和 `jin_unification`。本增量不修改两条前置条件，以免旧档或未出现玉玺事件的战役软锁；但改正第006回事件的器物、人物与因果文案。玩家选择“公开印匣来源”才立 `jade_whisper`，只是游戏虚构的历史改写抉择——原文孙坚实际秘藏而非公开。选择私藏或不介入不获得后续标志，不声称原著结局改变。

**第005回袁术扣粮→第006回孙坚责问袁术→第006回诸侯分裂：**损失是兵站政治的后果，而非孙坚本领不足。此前关羽 `wenjiu` 支线的“记下断粮责任”只能是跨人物主题呼应；它不能代替孙坚独立的家族、玉玺、战场权益线，也不能声称关羽在历史上决定了孙坚粮道。
