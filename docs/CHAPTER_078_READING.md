# 第078回《治风疾神医身死 传遗命奸雄数终》固定单底本全文核读

固定版本：维基文库 [第078回 oldid=2568040](https://zh.wikisource.org/w/index.php?title=三國演義/第078回&oldid=2568040)，正文 L119–164。2026-10-27 自回首连续核至回末；以下 L 为该固定网页行位，属于**单底本情节通读**，不是逐字异本校勘。

| 证据行位 | 因果、责任、时序与人物知情 |
| --- | --- |
| L119 | 接第077回成都闻关羽父子遇害；刘备悲恸欲立即伐吴，诸葛亮劝先发丧、静待魏吴互疑。此时蜀方已经得死讯，不可再写成传闻。 |
| L120–121 | 洛阳曹操因关羽之首而噩梦，造建始殿拟伐跃龙祠梨树；乡老谏阻，小说以神木流血、梦中神人解释头疾。神异不能列为史实。 |
| L122–124 | 华歆荐华佗；小说铺陈麻沸汤、陈登、异术；华佗建议剖头治疾，曹操疑其替关羽报仇，囚拷而死；吴押狱取《青囊书》却被妻焚。因果是疑忌→囚禁→医术失传的小说链，不等于《华佗传》死因全过程。 |
| L131–134 | 孙权遣表劝曹操称帝，曹操看出“炉火”之险，称宁为周文王；司马懿建议封赏孙权以牵制刘备。曹操在本回**未称帝**。 |
| L136–145 | 三马同槽、索命鬼影均为小说梦兆；曹操病重托曹洪等立曹丕，交代诸子、侍妾生计、铜雀台与疑冢七十二，建安二十五年正月死于洛阳。史传关于墓葬、遗令须独立核实。 |
| L157–164 | 丧报至邺，司马孚劝速定继嗣，陈矫断袖督促，华歆持汉帝诏命拥曹丕为魏王；曹彰率军来引出第079回。回末**曹丕已嗣魏王，但尚未受汉禅帝位**。 |

相邻因果：077关羽遇害及洛阳送首→078蜀中悼亡、曹操病卒、曹丕嗣王→079曹彰交兵、曹植受审与上庸责任→080曹丕受禅。原创游戏只能做后置案卷审查，不让曹操死后继续亲自主持朝政。
