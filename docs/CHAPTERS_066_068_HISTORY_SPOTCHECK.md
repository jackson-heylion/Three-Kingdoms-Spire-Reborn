# 第066—068回局部史料对勘：陈寿正文、裴注引书与小说分层

2026-10-27。小说固定底本：[066 oldid=2568029](https://zh.wikisource.org/w/index.php?title=三國演義/第066回&oldid=2568029)、[067 oldid=2568030](https://zh.wikisource.org/w/index.php?title=三國演義/第067回&oldid=2568030)、[068 oldid=2568031](https://zh.wikisource.org/w/index.php?title=三國演義/第068回&oldid=2568031)。

史料固定文本：
- [《三国志》卷54 oldid=2387393](https://zh.wikisource.org/w/index.php?title=三國志/卷54&oldid=2387393)，鲁肃传 L160–161：刘备得益州后，吴索三郡，鲁肃与关羽会面、双方各驻兵百步、仅将军单刀俱会，陈寿正文记鲁肃责关羽，裴注引《吴书》另有较长对话。小说突出关羽挽鲁肃脱身、吴伏刀斧，不能当作陈寿正文。
- [卷08 oldid=2086403](https://zh.wikisource.org/w/index.php?title=三國志/卷08&oldid=2086403)，张鲁传 L213–224：张鲁封藏仓库、归曹受礼见陈寿正文；裴注《魏名臣奏》《世语》对阳平胜利有不同归因，小说杨昂杨任、庞德陷坑与杨松卖主不等于史传一致记载。
- [卷17 oldid=2390639](https://zh.wikisource.org/w/index.php?title=三國志/卷17&oldid=2390639)，张辽传 L134–135：曹操密教“贼至乃发”、张辽八百勇士先击、吴退后追击险获孙权见陈寿正文。小说逍遥津跳断桥、谷利建议及具体兵数须另证，不可混同陈寿正文。
- [卷55 oldid=2603286](https://zh.wikisource.org/w/index.php?title=三國志/卷55&oldid=2603286)，甘宁传 L213–214：陈寿正文记濡须夜袭，**裴注引《江表传》**才详记百余人、鹿角、鼓吹、孙权赏絹千匹刀百口；董袭传 L204–205陈寿正文记濡须风覆船而死。小说凌统甘宁和解与左慈神异不可据此视作史实。
