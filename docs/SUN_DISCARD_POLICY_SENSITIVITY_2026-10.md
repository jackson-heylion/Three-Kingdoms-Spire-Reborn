# 孙尚香弃换构筑 × 左慈：策略敏感性复验（2026-10-24）

## 问题与控制变量

PR #75 的独立种子实验中，人工注入的 `sun_discard` 构筑在 `first_playable` 机器人下为0/32胜；但该机器人不会主动执行 `Action::Discard`，与构筑核心机制不匹配。不能据此加强卡牌或削弱Boss。

本实验在相同的32组飞升×种子条件（飞升0/10各16组）下，为**同一套人工注入的弃换牌组**分别执行两种策略：原 `first_playable` 与新增 `discard_aware`。保持英雄、Boss、初始牌组、战场夹具和随机种子不变，只调整行动选择。共64场完整Boss战。与PR #75 的原始牌组基线及另外两套孙尚香构筑分开统计。

`discard_aware` 优先弃换「策应飞矢」和不可出牌；若还有合法出牌，则先打牌（例如0费「借势回旋」），只有无法出牌且仍有弃换次数时才弃换剩余手牌。没有弃换次数时严格退回原策略。单元测试验证合法动作与优先级；不在本实验中修改游戏数值、卡牌或Boss规则。

## 可复验输出

```bash
TKS_DISCARD_POLICY_REPORT=/tmp/tks-discard-policy.json cargo test --test boss_build_duels sun_zuoci_discard_policy_sensitivity -- --ignored --nocapture
```

每个种子分别记录两种策略的胜负、毛承伤、二阶段、Boss战技、行动数、主动弃换次数和「飞羽随形」触发次数。CI严格校验32组条件唯一性、字段类型、旧策略零主动弃换和新策略至少一次真实弃换；macOS/Linux逐字节比较完整JSON。**不设置“弃换必须赢”的测试断言**，避免将平衡结论写死成回归目标。

这是机器人策略敏感性（policy sensitivity）实验，不是自然构筑成熟度证明。即使策略胜率改善，也不能排除策略与构筑的交互、样本选择及后续RNG分叉；若仍为低胜率，应继续检查弃换次数来源、牌序、飞羽随形实际触发和左慈回血节奏。真人试玩、完整事件源、120回史料异本校勘及完整国际化继续未验收。

这里的**可验证结论**是：同一人工注入的弃换牌组，在这32组左慈合成战斗条件下，对行动策略极其敏感。原先的0/32不应归咎于卡牌数值；仅替换机器人行动选择，胜场从0变为32，且弃换与被动触发有真实事件证据。**不要将32/32外推为自然构筑胜率、真人胜率或已成熟构筑**：策略改变会引起牌序和随机数路径分叉；种子取自有限固定区间，战场为单层120HP Boss夹具，且`discard_aware`是针对该机制手工设计的策略。毛承伤不是净失血，也不能直接替代通关率。

后续验证应先固定策略定义并新增独立保留种子；把策略适配扩展到另外14套构筑和更多Boss，按职业/飞升/敌军分层记录胜负与实际资源消耗；补充自然抽牌、卡牌获取与真人操作样本。**在这些证据出现前，不调整弃换构筑数值，也不把P1平衡验收标记完成。**
