# 第030回《战官渡本初败绩 劫乌巢孟德烧粮》单底本连续核读

核读日：2026-10-27。固定来源：维基文库《三國演義》第030回 oldid=2567996，https://zh.wikisource.org/w/index.php?title=三國演義/第030回&oldid=2567996 。从“卻說袁紹興兵”至“未知勝負如何”连续核对。仅为该修订的小说全文因果阅读，不代表毛评版系谱考证、第二底本异文对校或《三国志》全回核证。

1. “卻說袁紹興兵”→“拘禁軍中”：承第029回陈震回报孙权拒盟，袁绍进兵；田丰在狱中劝守，逢纪谮言，沮授劝凭粮久守而遭拘禁。不可把二人建议归作袁绍采纳。
2. “細作探知虛實”→“皆退至官渡”：荀攸判断曹军须速战；袁军张郃、高览迎战，审配弓弩伏阵使曹军败退。曹操、袁绍互引诏命是阵前政治主张，不等于史实核证。
3. “築成土山”→“空費軍力”：审配先筑土山射营，刘晔造发石车应对；袁军再掘地道，刘晔建议绕营掘长堑。两次防御先后不可倒置。
4. “曹操守官渡”→“分軍於寨前”：曹军八九月粮紧欲退，荀彧来信劝坚守；徐晃部将史涣获韩猛运粮情报，荀攸建议徐晃劫粮，张辽许褚救应，焚韩猛辎重。韩猛粮队不是乌巢屯粮本身。
5. “審配曰行軍以糧食為重”→“子姪下獄”：袁绍命淳于琼守乌巢；许攸获曹操催粮书，献袭许都之策，袁绍不信并据审配来书斥其家属贪赃。许攸投曹由拒谏、被疑与家属案共同促成，不是曹操事先安插。
6. “許攸暗步出營”→“操自引諸將居中”：曹操跣足迎许攸，数次虚报存粮，许攸出示被截书信、指出乌巢与淳于琼失备；曹操选五千精兵冒袁军蒋奇旗号，另留荀攸、贾诩、曹洪守寨并设左右伏军。不可把乌巢计归郭嘉。
7. “沮授被袁紹拘禁”→“糧草盡行燒絕”：沮授再谏乌巢防备遭拒；曹军冒名夜袭焚粮，曹操命先破屯粮再回击援军，擒淳于琼并残害遣返。沮授星象判断属于小说叙事，不能当成独立天文证据。
8. “袁紹在帳中”→“二人領本部兵馬”：郭图主张攻曹寨而张郃主张救乌巢；袁绍错配兵力，蒋奇遭假败军骗杀，张郃高览攻曹寨失败；郭图谗言及召罪促成二将降曹。不可简化为“二将无故背主”。
9. “許攸又勸曹操”→“盡焚之”：曹军散布两路攻邺、黎阳的假消息，袁绍分兵导致大溃；曹操获暗通袁绍书信后焚毁不究。小说另记大量战死与渡河溺亡，玩家的原创选择仅决定是否保存民命、情报责任账，不改战争结果。
10. “沮授因被囚禁”→“且看下文”：沮授拒降、欲逃归袁而被杀，曹操厚葬；曹军进攻冀州作为第031回起点。沮授之死不可与第031回田丰自刎混为一事。
