## 第001回：从政权失信到草创军队

1. 汉桓、灵以来宦官专权，蔡邕谏言反被构陷：朝廷监察机制失灵，成为黄巾扩张的政治背景；不是先有三兄弟冒险再突兀出现“反派军团”。
2. 张角借疫病、符水与太平要术取得信众，分三十六方组织起事；密谋遭唐周告变，迫使其提前举兵。起事有社会动员、情报泄露和时间压力，不只是法术袭击。
3. 幽州兵少募勇，刘备先遇张飞，后邀关羽；张飞出资出地，三人立誓“救困扶危、上报国家、下安黎庶”，誓约的重心是**公共责任**，不能只套成三人永远彼此增伤的战斗 Buff。
4. 张世平、苏双赠马匹、金银与铁，才使乡勇具备装备。首败程远志后，刘备于青州实施分路埋伏、佯退与夹击，刘关张不是单靠武力横扫五万人。
5. 刘备往援师卢植时错过颍川火攻，因卢植拒绝左丰索贿而被押回；董卓冷待尚无官爵的救命之人，张飞愤而欲杀。结尾停在**刚立的誓义如何面对权势不公**，自然引出第二回。

游戏对应：`taoyuan`（第001回，英雄关羽，第0幕）保留重整义旗与卖旧物分歧。后续公职、用人和粮线选择须追溯这面义旗，而非只复述典故。

## 第002回：从拒绝赃官到错误的招兵入京

1. 刘关张不杀董卓，离开其营投朱儁。张宝靠妖术使官军败退，朱儁安排污秽物件破法，关张侧翼截击；黄巾并非“全员持久法术”，反制需要**预告—准备—施放—克制**的可观察顺序。张宝由严政刺杀，末段收场不归功于主角直接斩杀。
2. 南阳宛城一役，朱儁拒绝韩忠请降，刘备指出四面死围会逼出拼命死战，建议放开逃路再歼敌；孙坚随后增援并先登。战场决策围绕给对手留退路、如何处理降将，适合敌方士气与包围状态机制，但本 PR 尚未增加这些完整机制。
3. 刘备军功不得授职，张钧弹劾十常侍反被斥退；刘备才得安喜县尉，行事廉洁，督邮则逼县吏作伪证索贿。当地老人哭求，张飞鞭打督邮；刘备**喝止并饶督邮性命**，关羽建议弃官。最终**刘备挂印绶而去**，并非三人杀督邮夺印。
4. 皇甫嵩、朱儁亦因不贿被罢，刘陶、陈耽进谏遇害。张让等人利用拥立争端操控何、董两宫；何进受袁绍建议召外镇军入京，陈琳当面警告“倒持干戈、授人以柄”。本回文末悬念是曹操提出见解，奠定第三回朝廷变故的伏线。
