# 第063回《诸葛亮痛哭庞统 张翼德义释严颜》单底本全文因果核读

2026-10-27。固定底本：[维基文库 oldid=2568024](https://zh.wikisource.org/w/index.php?title=三國演義/第063回&oldid=2568024)。正文 L119–183 连续阅读开篇至回末；**仅单底本通读，非异本文字或史料全回校勘**。

| 位置 | 事件因果与知情边界 |
|---|---|
| L119–120 | 彭羕识破冷苞决涪江的计划，黄忠魏延轮巡；冷苞决水未成，魏延再擒，刘备斩之。不能提前写成洪灾。 |
| L120–123 | 马良从荆州送孔明警书，庞统疑孔明争功；刘备梦警劝庞统守涪关，主动与其换白马，并非预谋害之。 |
| L124–143 | 张任放过魏延前军，误认骑白马的庞统为刘备，落凤坡伏弩射死庞统；魏延被围，黄忠救援，刘备败回涪关。童谣与天象为小说叙事。 |
| L147–152 | 刘封关平援军解围；刘备得报才知庞统阵亡，遣关平请孔明。孔明在荆州先据天象推测、后见书信确认；向关羽交印，嘱北拒曹操东和孙权；张飞陆路、赵云水路，孔明随后入川。 |
| L154–160 | 孔明嘱张飞勿扰民，张飞到巴郡先暴言、严颜拒降，张飞假传小路撤军诱严颜出城，亲自擒之。 |
| L161–183 | 严颜拒降，张飞由怒转敬亲释其缚，严颜归降，允领路；沿途四十五关降伏在064回兑现。 |
