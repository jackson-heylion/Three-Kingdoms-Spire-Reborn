# 第113回《丁奉定计斩孙綝 姜维斗阵破邓艾》固定单底本全文通读

| L116–117 | 承112姜维闻魏援将至先撤军器、步兵，骑兵断后；邓艾察知骆谷伏柴，决定不追。吴线回到寿春失利后，孙綝诛降将家属；孙亮蜜中鼠粪案表现其识断，史料出处须分陈寿与裴注。 |
| L118–124 | 孙亮与全纪谋除孙綝，密谋由全尚告妻泄露，孙綝先发制人杀刘丞等并废孙亮；孙休被迎立，暂以封赏安抚孙綝。泄密责任不能归到孙亮本人。 |
| L125–129 | 孙綝受宴不悦、调兵移械，张布报孙休；丁奉布置腊日宴席，张布殿中拘孙綝、丁奉外应，孙綝与宗族被诛。小说风异与跌倒为文学征兆；后续平反与株连也须分账。 |
| L130–131 | 薛珝返吴报告蜀汉黄皓用事、民困；吴廷再修国书警蜀，姜维据此再次出师祁山。吴使所见是情报与观察，非吴军直接指挥蜀军。 |
| L132–134 | 鄧艾预挖地道夜袭蜀左营，姜维稳住中军，随后八阵斗法困邓艾，司马望从西北破阵救出；蜀军虽夺九寨但伤兵与地道尸体须记账。 |
| L135–144（回末） | 姜维识破邓艾借斗阵袭后路，廖化张翼击退伏军；邓艾用党均贿通黄皓散谣，后主诏姜维回朝，魏军尾追。113尚未交代追击胜负，114才续接，不能提前写姜维已死或蜀亡。 |
