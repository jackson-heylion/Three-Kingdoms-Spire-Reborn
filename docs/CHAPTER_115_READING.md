# 第115回《诏班师后主信谗 托屯田姜维避祸》固定单底本全文通读

来源：[维基文库毛评系统 oldid=2568078](https://zh.wikisource.org/w/index.php?title=三國演義/第115回&oldid=2568078)；2026-10-28核读固定正文L119–144，从回首至回末。**状态：有证据单底本全文通读；异本文字与全回史料未校。**

| 正文锚点 | 因果、时序、责任与知情边界 |
| --- | --- |
| L119–120 | 姜维修道备粮再伐，谯周以天象谏、廖化以军民疲敝谏；邓艾判定洮阳是真目标，分兵洮阳侯河。 |
| L121–127 | 夏侯霸疑空城，见百姓逃散误判，入瓮城中伏，小说写其战死；姜维两败后采张翼分兵取祁山计，死法未作史传确证。 |
| L128–130 | 姜维牵制侯河、张翼攻祁山；邓艾识破赶救，张翼被围，姜维驰援，魏军退寨；不可抹去先前洮阳伤亡。 |
| L131–132 | 小说先写刘琰疑妻与军士辱打胡氏，后主诛刘琰并禁命妇入朝；再写黄皓与阎宇求代姜维，刘禅连发三诏召回。姜维撤军见郤正、进谏黄皓，后主不许。不得把胡氏受辱归责姜维军中。朝廷传令与军队后撤责任分别记录。 |
| L133–144（回末） | 郤正献沓中屯田兼避祸策，姜维布置汉中关防赴沓中；司马昭与钟会邓艾谋分路伐蜀，借造船伐吴作疑兵；邵悌忧钟会专兵，答话留待116。 |
