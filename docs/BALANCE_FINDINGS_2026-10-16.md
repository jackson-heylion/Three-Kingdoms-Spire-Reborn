# 2026-10-16 固定种子平衡回归：首次量化、定向调整与复测

> 本报告来自自动规则机器人在同一天的可复现实验，不是人类玩家胜率、不代表各职业的固有胜率，也不是对《杀戮尖塔 2》的对比结论。建议与 [抽样方法](BALANCE_METHODOLOGY.md) 一起阅读。

## 任务与输入

要判断“哪个职业在现有单人终端版本中明显偏强/偏弱、应先修复什么”，需要防止策略机器人偏差。采用两个行为不同的机器人，在**相同武将、同一飞升难度、同一初始 RNG 种子**上成对运行。五武将 × 飞升 0–10 × 每组合20种子 × 两种策略 = **2200局**。单职业每策略各220局，各飞升分段分别80、80、60局。

- 旧版简单策略机器人始终取第一个可用行动，上一轮 1000 个非分层样本仅赢228局（22.8%）；这与这里的分层2200局使用不同种子/权重，不得直接比较。
- 本轮战术策略机器人还会评估卡牌、奖励、低血恢复、优先敌军、营地、军市、兵法续航，并实际使用孙尚香可获得的弃换次数。
- 动作都是普通 `Game::apply`，中途每13步进行 JSON 读档一致性检测。
- “关底遭遇战失败次数”不等于“Boss 给出致命一击次数”，而是失败前所在的战斗类型。

这两种风格相差很大的机器人均表现为曹操明显更易通关，孙尚香明显更困难。这是值得调查的信号，但**不是**“曹操应该降低76个百分点”或“孙尚香真实通关率只有2.3%”的依据。

## 定向调整与机制验收

1. 孙尚香“每3次攻击抽一张牌”同时增加3点护甲；消耗一次合法的手动弃换增加2点护甲；本次两个被动行为都写入审计事件。增强灵活防守，不增加初始生命值或打出任意一张牌时自动防御。
2. 曹操开局亲兵每回合自动攻击由3降为2；护卫血量仍为12，卡牌强化亲兵仍有效，避免直接砍掉其独有玩法。
3. 完整状态与动作继续保持 `Game::apply` 的事务提交原则。新增 Rust 单测和 BDD 场景验证三连段获得护甲、合法弃换获得护甲、无效弃换不改变快照、曹操亲兵初始攻击及跨存档一致性。

复测来源：`d45f7255` 的 macOS / Linux CI [运行记录](https://github.com/jackson-heylion/Three-Kingdoms-Spire-Reborn/actions/runs/38856101053)。样本和策略代码与调整前报告一致，只有对应的职业游戏机制发生更改。

| 指标 | 修改前 | 修改后 | 解释 |

| 孙尚香·简单策略整体（220局） | 5胜 / 2.3% | 9胜 / 4.1% | 连段防守在不主动弃换时仍可能触发 |

因同一组种子下行动导致战斗结果/路线发生分歧，成对比较只控制了随机数输入，并未控制局内选择结果。不能直接宣称这12场额外胜利一定由护甲技能直接造成。

## 遭遇战线索

在调整后的简单策略中，最常见的失败遭遇分别为董卓（110）、孙坚（73）、军中校尉（41）；在调整后的战术策略中，左慈（11）、董卓（9）更突出。这里只按失败时遭遇类型汇总，不能区分“Boss 自身最后一击、援军协同、上回合失血、玩家路线/卡组选择”等原因。

## 结论和下一轮建议

- **已验证**：孙尚香短板被适度缓解，战术策略总体表现由81.8%变为87.3%。
- **仍未解决**：曹操在战术机器人下持续100%通关；只把基础亲兵攻击3改2尚未有效区分强度，可能与统御免费军令、亲兵抗伤、卡牌选择或策略漏洞共同有关。下轮先仪表化每回合亲兵输出、承担伤害、统御额外军令与死亡场景，再决定是否进一步调整。
- **数据缺口**：所有机器人对局不是真人试玩；高飞升每名职业仅60个试验，跨职业还需要更丰富的策略对抗与统计置信区间。发布1.0之前应有真人样本、精英/Boss分段耗血、卡组胜率和不同构筑覆盖。
- **质量门**：不强制胜率符合预设阈值；严格依照实际数据发布偏差和技术限制，避免隐藏失败结果。

`cargo run --release --bin tks-sim -- --balance 20 ./balance.json` 可以在本地重新生成55个分层单元的机器可读数据。CI 将不同系统的数据保存在 `tks-balance-ubuntu-latest` 和 `tks-balance-macos-14` artifacts 中供下载。
