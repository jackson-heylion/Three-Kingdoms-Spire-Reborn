# 第077回《玉泉山关公显圣 洛阳城曹操感神》固定单底本全文核读

2026-10-27。固定来源：[维基文库第077回 oldid=2568041](https://zh.wikisource.org/w/index.php?title=三國演義/第077回&oldid=2568041)，正文 L119–164；连续核读回首、回中及结尾。鬼神叙述只归小说设定。

| 固定版行位 | 情节、责任、知情边界 |
|---|---|
| L119–121 | 承076末卜西北，吕蒙料关羽从麦城北小路走，朱然与潘璋分设伏，留北门诱出；关羽仅余三百余兵、粮尽，王甫劝走大路，关羽决定险道，留王甫周仓守城。 |
| L121–122 | 关羽与关平赵累夜突，朱然佯退、潘璋再诱，赵累乱军阵亡；临沮狭路马忠以钩索擒关羽，关平救父亦被擒。不能把被擒归功于吕范占卜本身。 |
| L122–134 | 孙权问降，关羽拒绝；左咸劝即杀，孙权下令父子遇害。小说明确建安二十四年冬十二月，生死不能由玩家改写；《关羽传》裴注《蜀记》另说孙权曾欲活羽，裴松之对此提出质疑。 |
| L135–137 | 赤兔不食而死，王甫闻讯坠城、周仓自刎，麦城归吴；赤兔殉主属小说，非已核实史实。 |
| L139–145 | 玉泉山普净以昔日被斩之人反问关羽索头，小说写英魂悟因果并显圣；不是历史现场记录，游戏可做传闻分类但不得写成真实鬼魂事件。 |
| L150 | 小说写吕蒙庆功宴被关羽英魂附体、七窍流血死；《吕蒙传》陈寿正文记吕蒙病重、孙权求医、内殿病卒，冲突须明示。 |
| L151–152 | 张昭主张送关羽首级给曹操转移刘备报复，司马懿识破并建议厚葬，小说写关羽首级显异、曹操祭葬；《关羽传》裴注《吴历》只载送首与以诸侯礼葬尸骸，不能推出显灵。 |
| L153–158 | 成都先叙刘备纳吴氏；闻关羽婚使拒绝、七军捷报和江防严备后稍安；刘备梦关羽，诸葛亮与许靖先获传闻，马良伊籍与廖化接连送报，刘备终获父子遇害实讯昏厥。军报传递有先后，不能说刘备从开篇已知死讯。 |
| L164 | 以刘备昏厥存亡为下回悬念，078才接其后续，勿在077写成刘备已起兵报仇。 |

可玩定位：吴方核实江陵家属保护与杀俘决策责任、曹方归档送首厚葬与传闻证据等级、蜀方记录求援迟滞及刘备获讯时序；不改变原著关羽、关平、吕蒙命运。

未校：第二小说底本全回对校；鬼神信仰史与后世祠庙发展未做全证；正史仅局部对照。
