# 第084—086回局部《三国志》核证（非全回校勘）

固定小说：084 oldid=2568047、085 oldid=2568048、086 oldid=2568049。固定史书：卷58 [oldid=2131313](https://zh.wikisource.org/w/index.php?title=三國志/卷58&oldid=2131313)、卷32 [oldid=2583378](https://zh.wikisource.org/w/index.php?title=三國志/卷32&oldid=2583378)、卷35 [oldid=2115776](https://zh.wikisource.org/w/index.php?title=三國志/卷35&oldid=2115776)、卷47 [oldid=2602668](https://zh.wikisource.org/w/index.php?title=三國志/卷47&oldid=2602668)、卷17 [oldid=2390639](https://zh.wikisource.org/w/index.php?title=三國志/卷17&oldid=2390639)。仅核下列明确条文，不以史书空白证明小说情节绝对虚构。第二小说底本全文异文对校 **0/120**。

1. **084 L115–159 火攻与败退。** 卷58《陆逊传》陈寿正文“黄武元年，刘备率大众来向西界”后载吴班诱战、陆逊拒躁进、火攻破四十余营、刘备败退；卷32《先主传》陈寿正文“二年春正月”至“秋八月”记黄权督江北、冯习张南战没、刘备退鱼复改永安。小说八阵图困陆逊、黄承彦引路、赵云刺朱然与孙夫人误闻死讯投江，**不在上述史传条文证成**；不把这些说成正史。
2. **085 L115–130 黄权与托孤。** 卷32正文“三年春二月”至“四月癸巳”明确刘备病笃、托孤诸葛亮，**尚书令李严为副**，卒于永安；其后裴注引《诸葛亮集》录遗诏。小说刘备梦关张、试马谡等须分层，不能因遗诏文字相近就认作第二小说底本已校。黄权降魏后家属不罪为小说与史传可继续对照的题目，未做全传核证。
3. **085→086 使节与年份。** 卷47《吴主传》陈寿正文：黄武元年十二月孙权遣郑泉聘刘备，二年十一月蜀使邓芝来聘，三年夏张温使蜀。小说085邓芝刚受命、086油鼎谈判与张温答礼；**不将油鼎和秦宓辩天当作史书原话**，也不将这些使节合并成同一史实日期。
4. **086 L132–137 广陵疑城。** 卷47《吴主传》陈寿正文三年九月记曹丕至广陵望江而退；裴注引干宝《晋纪》才详述吴人一夜造疑城、苇席装饰。小说徐盛独揽疑城、孙韶夜袭、丁奉射张辽及鱼油火攻的完整过程不能冒充陈寿正文。卷17《张辽传》另记张辽患病而卒，不能据小说箭伤死亡反推正史死因。卷47四年冬另记魏文帝临江，**不要把不同年份的临江记载混成一战**。
5. **086回末南征界线。** 小说回末诸葛亮因雍闿孟获消息召回赵云，南征尚未展开；史书《诸葛亮传》关于南征时间另核，不得用游戏先行触发第087回事件。

原创游戏节点只审计责任、民户安置、使节信任及后继档案；孙夫人按小说084已死，后续孙尚香职业节点只能使用吴方存留档案视角，不能让本人继续出场。曹操亦早于085病卒，曹魏节点仅为后继朝廷档案。待校：第二小说底本真实异文、裴注《吴历》《江表传》逐项核对、朱然孙夫人张辽生卒及广陵多次战役时序。**异本及史料全回校勘 0/120**。
