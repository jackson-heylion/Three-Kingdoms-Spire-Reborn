# 《三国演义》第003回：温明废立、赤兔诱变与义父之死

审读日：2026-10-20。底本采用维基文库[固定修订 oldid=2567965](https://zh.wikisource.org/w/index.php?title=三國演義/第003回&oldid=2567965)，题为「议温明董卓叱丁原　馈金珠李肃说吕布」。审读覆盖该固定版正文从开头曹操谏何进至末尾袁绍与董卓拔剑相对、转入下回的全部段落。本文保留可重查的**叙事梳理**，不是逐字异文校勘，更不是对《三国志》、范晔《后汉书》或裴注的逐项考证。

## 全回情节按正文先后重建

1. **劝阻招外兵失败，宫变不是天降灾难。** 曹操提醒何进，清除元恶本不必召外镇军，郑泰、卢植和陈琳则分别警告董卓危险和宫中召命可能有诈。何进不从。张让等预伏人手，何进独入宫门被杀。曹操与袁绍的预警在事件发生前已出现，不可将本回写成所有人同样无知。
2. **清剿失控与救驾两条线并行。** 袁术、袁绍等人激烈诛杀宦官，正文特写无须者遭误杀；曹操另行救灭宫火、请求何太后摄事并追寻少帝。张让、段圭挟少帝及陈留王至北邙，张让投河，闵贡杀段圭，崔毅收留二王，后由大臣接驾。紧急秩序恢复与报复性滥杀不可合并成一条单纯“清君侧成功”的凯旋线。
3. **陈留王与董卓初遇触发废立意图。** 少帝惊惧失语，陈留王责问董卓是来保驾还是劫驾并令其下马；董卓由此暗生废立之念。同段明确写到宫中清点时**传国玉玺失踪**。玉玺之谜应作为前置伏线，不能将此回误写为董卓已发现并持有玉玺。
4. **温明园内丁原抗议，吕布此时仍属丁原。** 董卓吸纳何进旧兵，以宴席威胁百官，强议废立；丁原与卢植反对。李儒看见持方天戟的吕布护丁原，劝董卓暂缓。次日丁原出战，吕布冲阵迫董卓败退三十余里。此时吕布对董卓的首次出场是**敌对关系**，而非原本就忠于董卓。
5. **李肃献礼后，吕布主动提出杀丁原。** 董卓采纳李肃建议，将赤兔、黄金、明珠、玉带交付劝降。李肃先以旧识与骏马示好，再谈功名富贵。正文中**吕布本人提出杀丁原、引军归董卓**，李肃赞许并催促速决。不是“李肃当场刺杀丁原”，也不是“一匹马令吕布立即被迫杀人”。
6. **叛变改变的是人际秩序和军权。** 吕布二更入帐亲杀丁原，命军士从己或离去，军士散去大半；随即投董卓，再拜董卓为义父。董卓掌握军力、加官进爵，更能强推废立。读者随后看到袁绍与董卓于宴上拔剑相争，全文在“袁绍性命如何”处停章，不能提前写成袁绍死亡或董卓已经在此处失势。

## 三个应进入游戏的连续性约束

**吕布“义父—背盟—再结父子”**：第003回由丁原转董卓，不仅产生道具赤兔，还建立背盟的政治责任。游戏现有 `redhare`（第3回、吕布、第0幕）→ `pavilion`（第8回）→ `halberd`（第16回）→ `whitegate`（第19回）本来已有跨幕旗标关系。本次改写 `redhare` 前提及二择文案，突出李肃的诱因与吕布的主动选择；如果玩家选“向旧部说明背盟之责”则立 `red_hare`，选财宝则不立旗，后续 `pavilion` 无法走该分支。这是**架空玩家改写历史的选择**，不是声称原著吕布曾公开承担责任。真正的政治/战斗层后果还未全部机制化。

**玉玺失踪—井中玉玺—王朝合法性**：第003回只记录玉玺不见，既有 `imperial_jade`（第6回、孙坚/袁术的传国玺线）与 `jin_unification`（第120回、晋朝结局）是原创游戏对“权力名器终归何处”的延伸。当前支线的旗标并不回写第003回事件；要做真正的跨幕“玉玺来源链”，仍需增加可交互的第003回预告和选择约束。

**曹操对引兵入京的判断—权力与名分**：本回曹操劝何进并试图在宫变后恢复秩序，与游戏第14回 `xudu`“奉迎天子”构成主题对照，但目前两事件无旗标前置，不能宣称已实现因果触发。
