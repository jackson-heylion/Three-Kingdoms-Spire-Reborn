# 第025回《屯土山关公约三事 救白马曹操解重围》：单底本全文因果核读

核读：2026-10-26。固定底本：维基文库《三國演義》第025回，oldid=2567988，https://zh.wikisource.org/w/index.php?title=三國演義/第025回&oldid=2567988 。正文已从“卻說程昱獻計曰”连续核至“未知玄德性命如何”；定位以下列固定修订的段落起止语为准。只完成**单一底本全文情节/责任核读**，没有逐字异本对校，也没有完成《三国志》全回史实核证。

## 连续证据与因果

1. **“卻說程昱獻計曰”→“曹操自提大軍殺入城中”**：承接第024回末程昱提出诱关羽出城、再遣张辽说降；第025回才实施。徐州旧降兵诈返下邳，夏侯惇挑战诱出关羽，徐晃、许褚及强弩截归路；关羽困土山，城内内应开门，曹操入下邳。关羽尚未降曹，不能倒写成主动献城。
2. **“關公見下邳火起”→“有此三便”**：张辽先以刘备存亡未明、家眷安全劝说，继以桃园之誓、受托二嫂、匡汉大义陈“三罪”，再提保存性命、保护二嫂、日后寻刘的“三便”。张辽劝降不是无条件背盟。
3. **“公曰：兄言三便”→“吾願從此三事”**：关羽“三约”分别为只降汉帝不降曹操、供养并禁止打扰二嫂、得知刘备下落便离开；曹操对第三条先摇首，经张辽以豫让之论相劝才应允。三约的主体与次序不能互换。
4. **“張遼再往上回報”→“未敢擅便”**：曹操退军十里，关羽先回城见甘糜二夫人、陈述约定并征询。二嫂担忧曹操日后不肯放行；这是对第026回的真实前置悬念。
5. **“關公辭退”→“愈加敬服”**：关羽拜曹、护车入许昌；驿馆秉烛、内外分院、受赠礼物均以护眷与不忘刘备为边界，不能把曹营礼遇直接等同于关羽移忠。
6. **“一日，操見關公所穿綠錦戰袍”→“操愕然而悔”**：旧袍外罩新袍、献帝称美髯公、曹操赠赤兔。关羽因赤兔可早日寻兄而拜谢，曹操由此知其去志；不是关羽已知刘备确切所在地。
7. **“操問張遼曰”→“沮授見田豐下獄”**：关羽明言立功报曹后离开；袁绍不听田丰持久之策而囚田丰，沮授忧军败。两条阵营线并行，非曹操指使袁绍囚田丰。
8. **“紹遣大將顏良作先鋒”→“未知玄德性命如何”**：颜良斩宋宪、魏续，败徐晃；程昱建议请关羽，并明言借斩袁将令袁绍疑杀刘备。关羽斩颜良，袁绍果然因沮授指认关羽而欲斩刘备。**本回末只到刘备待斩，解危在第026回**。
