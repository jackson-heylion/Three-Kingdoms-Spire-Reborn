# 第117—119回局部史料核证（非全回对校）

| 回 | 可访问史料位置 | 证据界限 |
| --- | --- | --- |
| 117 阴平绵竹 | [《三国志》卷28《邓艾传》](https://zh.wikisource.org/wiki/三國志/卷28)“冬十月，艾自阴平道行无人之地七百余里”至“刘禅遣使奉皇帝玺绶”（页面L192–195）；[卷35《诸葛瞻传》](https://zh.wikisource.org/wiki/三國志/卷35)“瞻督诸军至涪停住”至“瞻长子尚，与瞻俱没”（L191–192） | 阴平凿山架桥、马邈降、绵竹瞻尚战死有陈寿正文；小说木像退敌、石刻预言、李氏自尽、吴援具体路线不能径作史实。小说诸葛瞻自刎与史传“临阵死”记法不同。 |
| 118 成都降魏 | [卷33《后主传》](https://zh.wikisource.org/wiki/三國志/卷33)炎兴元年“用光禄大夫谯周策，降于艾”（L201–202）；[卷28《邓艾传》](https://zh.wikisource.org/wiki/三國志/卷28)“禅率太子诸王及群臣六十余人面缚舆榇”（L195） | 谯周劝降、交玺、邓艾受降有史传；小说刘谌杀妻子、祭祖场面不可直接归陈寿正文，且不能将家属被害美化为玩家奖励。 |
| 118—119 邓艾钟会 | [卷28《钟会传》](https://zh.wikisource.org/wiki/三國志/卷28)“会内有异志”至“姜维率会左右战，手杀五六人，众既格斩维”（L229–231） | 钟会矫诏、胡烈传信、兵变有陈寿正文；效仿邓艾笔迹改表见裴注引《世语》，不是陈寿正文。小说写姜维自刎，史传写乱兵格杀，必须标为叙述差异。 |
| 119 司马炎受禅 | [卷04《三少帝纪》](https://zh.wikisource.org/wiki/三國志/卷04)咸熙元年钟会反、邓艾被杀、刘禅封安乐公（L249–250）及魏末禅位段 | 陈寿正文可证魏晋政权更替；小说张节当殿被打死、司马炎对曹奂具体对白不能当作史实。第119回结尾只谋伐吴，120回才完成晋灭吴。 |
