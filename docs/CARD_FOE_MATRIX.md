# P1 可收集卡牌 × 全敌军：首牌交互矩阵

`tests/card_foe_cross_product.rs` 使用真正的 Rust `Game::apply(Action::Play)`，分别遍历五职业所属卡池、12张共享战利品、14张中立牌和基础突刺/招架（按职业去重），对全部 **31 种敌军**模拟**普通/升级**两种版本各一次。每局合成夹具为首战单敌，生命额外加200、护甲5、军令6，抽牌与弃牌堆都有真实牌，因此指定检索与复制卡能走真实副选逻辑。所有有效出牌应成功，并验证 `CardPlayed` 事件、日志序号连续、合法存档往返。不依赖并不污染用户战役。

第二个用例把每张可收集卡的副选编号设为999，要求**无效副选不扣军令、不出牌、不污染存档或操作历史**。测试用例是按当前真实卡池动态求乘积、下限守卫以防误删，自动执行时必须以最新 macOS/Linux CI 为依据。

重要限制：

- 这是**单牌单敌起手可执行性**，不代表整套卡牌复杂连锁、道具 × 能力 × 卡牌 × 敌方意图的穷举；
- 将敌军阶段/状态简化并提高生命，尚未验证每名敌人多回合全意图、死亡清场、所有药剂或全套遗物交织；
- 人工注入卡牌和军令，**不代表这些卡已在正常运营中成功获得**，也不构成构筑成型概率和 0–10 飞升胜率证据；
- 不存在对真实 `action_history` 的重播验证，因为夹具显式改写了初始战斗；保存恢复检查仅涵盖当前合成快照。

实际组合数量以测试运行和 CI 日志为准，不因理论乘积直接写成已经通过。
