# 第044回《孔明用智激周瑜 孙权决计破曹操》单底本全文核读

2026-10-27 自开篇至回末连续核读；固定底本（oldid=2568008）：https://zh.wikisource.org/w/index.php?title=三國演義/第044回&oldid=2568008 。L 为固定网页正文行号。只标记**单底本全文阅读**，不冒充异本/史料全回校勘。

| 位置 | 情节因果、人物责任及未决处 |
|---|---|
| L119–126 | 承043吴国太提醒孙策遗言，周瑜自鄱阳回柴桑；先向张昭等假称愿降，再对程普黄盖等表态愿战，对诸葛瑾、吕蒙甘宁等仍不露全部盘算。不能写成周瑜一到即获全体一致。 |
| L127–152 | 鲁肃引孔明见周瑜；周瑜试探言降，孔明借铜雀台与二乔激其怒，援引《铜雀台赋》。周瑜表明二乔分别为孙策、周瑜妻，随后承认此前言降是试探，求孔明相助。铜雀台赋的“二乔”解释为小说激将设计，不能当曹操真实诏令或《三国志》史实。 |
| L154–164 | 周瑜向孙权指出北土未平、北军不习水战、隆冬马乏草、士卒不服水土四忌；孙权断案授剑，任周瑜大都督、程普副都督、鲁肃赞军校尉，令诸将听令。此时只是决战部署，赤壁尚未胜。 |
| L165–174 | 孔明提醒周瑜孙权仍惧曹兵数；周瑜夜间重估兵力，孙权确认后援。周瑜忌孔明欲杀，鲁肃劝止；周瑜部署五队水军与巡警，令不得扰民。程普因资历不服，听儿子转述军令后亲来谢罪。 |
| L175–185 | 周瑜遣诸葛瑾劝孔明改事孙权，孔明反劝兄长同事刘备，诸葛瑾不从；回末周瑜另谋制孔明，具体计策留045。不可提前说孔明归吴、周瑜已害孔明或赤壁已胜。 |
