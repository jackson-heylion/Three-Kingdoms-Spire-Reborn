| 正文锚点 | 情节因果、责任与知情边界 |

| L119–121（回首） | 承107姜维牛头山败退，司马师追至阳平关遭蜀军连弩阻击；句安在麴山因援军不到降魏，姜维折兵退汉中。不能将击退追兵等同于麴山解围成功。随后司马懿病逝、司马师司马昭继权，形成魏廷后继档案视角。 |
| L122–128 | 小说回溯孙登、孙和、孙亮储位之争及孙权病终；诸葛恪辅幼主，魏廷因吴主新亡判断有机可乘。孙权已死，后续不是孙尚香亲历。史传储位时序及孙和结局需另校。 |
| L130–134 | 司马昭分三路，胡遵以浮桥逼东兴两城；丁奉雪中弃长兵持短刀突袭，韩综、桓嘉死，魏兵争桥落水。胜负由守城、奇袭与浮桥拥堵共同造成，战后救护、缴获须分账。 |
| L135–137 | 诸葛恪乘胜出兵、遣书求姜维联攻；张特以百日守城之法诈缓数日，修补新城缺口，诸葛恪强攻不克，酷暑疾疫、军士逃亡，撤退遭追。不能把张特的降书当成已投降事实。 |
| L138–145 | 诸葛恪败后以刑威立权，孙峻、滕胤与孙亮设宴伏杀；小说插入白虹、犬哭、亡魂等异象。宴杀、张约受伤、恪家族被诛及孙峻得权须分别记责任，异象不作史实。 |
| L147–150（回末） | 姜维收到诸葛恪联魏书而再次奏请北伐，**109回才写蜀军进兵**。小说叙事在吴政变后回接前已发出的使书，不可误写成恪被杀后新发令。 |
