# 第099回《诸葛亮大破魏兵 司马懿入寇西蜀》固定单底本全文核读

固定底本：[维基文库第099回 oldid=2568060](https://zh.wikisource.org/w/index.php?title=三國演義/第099回&oldid=2568060)，正文 L119–171；2026-10-28按回首至回末逐段核读。**单底本全文通读，不等于异本对校或史实全回核证。**

| 正文位置 | 叙事因果、人物责任、知情边界 |
| --- | --- |
| L119–122（回首） | 承098武都阴平尚待争夺。司马懿命郭淮孙礼从后袭蜀，二人得报王平取阴平、姜维取武都，孙礼先疑诈；诸葛亮伏击使二人弃马逃走，张苞追击跌涧受伤，被送成都。**二郡在本回已取，不可倒记于098。** |
| L123–125 | 司马懿以为诸葛亮安抚二郡不在营中，命张郃戴陵夜袭。蜀军草车阻路、火鼓合围；张郃冲出又折返救戴陵。诸葛亮看出张郃勇武并生除之之意，司马懿改为坚守。 |
| L127–133 | 半月相持后费祎持刘禅诏复诸葛亮丞相职。诏文追叙街亭自贬、王双被斩、二郡收复；诸葛亮先辞后受。此处**小说中的诏令可与《诸葛亮传》陈寿正文逐项核证**，但不能将前述草车伏击全部当作史实。 |
| L134–142 | 诸葛亮三次缓退设饵，司马懿反复警惕，张郃请追；诸葛亮令王平张翼设伏，姜维廖化持锦囊袭魏营迫司马懿撤救，蜀军赢得追击战。魏方误判与蜀军计策分属不同人物视角。 |
| L144–152 | 张苞死讯传来，诸葛亮悲恸病倒，董厥樊建奉命秘密撤军，司马懿五日后方知。蜀军回汉中，诸葛亮归成都疗养。张苞小说死讯与史传人物记载不等同。 |
| L153–155 | 建兴八年曹真请伐蜀，刘晔对皇帝与群臣不同答复源于军事保密；曹真、司马懿统军入汉中。诸葛亮命王平张嶷少兵守隘并预备一月粮草，解释将以秋雨拖住魏军。 |
| L156–171（回末） | 曹真司马懿因雨驻陈仓，连降三十日；王肃上疏陈述山险霖雨、粮运困境，魏主下令撤军。司马懿布置后卫，诸葛亮**明确不追**，本回只伏笔下一回如何另取魏兵，不得提前记劫寨成功。 |

跨回：098陈仓再袭及武都阴平出兵→099二郡既得、祁山相持、张苞伤亡、秋雨退魏→100蜀军改走斜谷箕谷、陈式违令。游戏只让玩家选择保留安民、伤兵与雨季粮道责任账，不改变原著战果。
