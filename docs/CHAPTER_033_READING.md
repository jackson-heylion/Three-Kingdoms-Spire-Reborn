# 《三国演义》第033回单底本因果审读

底本：维基文库《三國演義/第033回》 oldid=2567995；2026-10-23审读。此处只作小说单底本全回因果通读，非异本、正史校勘，未实装游戏。

1. 曹丕擅入袁府，先威胁刘氏与甄氏；曹操先责其擅入，后经刘氏陈情批准婚事，不能写成事前奉命迎娶。
2. 许攸自夸入城功劳，辱骂许褚后被许褚杀死；曹操随后责许褚并厚葬许攸。杀人者和处置者必须区分。
3. 袁谭与曹操决裂，刘表听刘备之议以书婉拒出兵；袁谭退南皮，郭图建议驱百姓当先，混战中曹洪杀袁谭、乐进射郭图。不能将平民死伤抹去。
4. 王修违禁哭祭袁谭，曹操礼遇；韩珩拒绝随乌桓触降曹，获准离去。两人均未因被尊重而改投曹操。
5. 并州高干守壶口，荀攸献诈降计，吕旷吕翔诱其夜袭，乐进李典趁虚夺关；高干求左贤王援助被拒，途中被王琰所杀。
6. 郭嘉主张趁乌桓疏备轻兵速袭，田畴另提供卢龙口路线，张辽白狼山突击；三人的情报、决策和执行不可互换。
7. 回军缺水缺粮，曹操仍赏先前谏阻远征者；胜利不意味着远征风险从未存在。
8. 郭嘉病死易州，留下密封遗书；曹操按兵不攻辽东，公孙康探知后杀袁熙袁尚送首级。郭嘉遗计是利用公孙康与二袁互疑，而非事先与公孙康密谋。
9. 底本白狼山敌将作「冒顿」，与历史称谓存在待校疑点，不能冒称已完成史料考证。
10. 回末地下金光悬念须留待第034回，不提前结算。
