# 第110回《文鸯单骑退雄兵 姜维背水破大敌》单底本全文通读

固定来源：[维基文库第110回 oldid=2568072](https://zh.wikisource.org/w/index.php?title=三國演義/第110回&oldid=2568072)，正文 L119–146。2026-10-28回首至回末核读。状态：**单底本全文通读**，第二小说底本与史料全回校勘未完成。

| 正文锚点 | 情节因果、责任与知情边界 |
| --- | --- |
| L119–123（回首） | 承109曹芳被废，毌丘俭、文钦矫称太后密诏，歃血起兵；司马师带眼疾亲征，王基先占南顿，魏军分路切断淮南归途。檄文所称「太后诏」是叛军宣称，不可当作真实授权。 |
| L124–130 | 文鸯与父文钦约定两路夜袭乐嘉，文鸯先至，文钦迷路失约；文鸯孤军退魏兵，司马师眼疾发作。小说单骑反复冲阵的次数、眼珠迸出细节须与裴注异文区分。 |
| L132–134 | 尹大目劝文钦忍数日而对方未解；文钦退吴、毌丘俭败死、司马师病卒，司马昭拒留许昌而入洛继权。小说写宋白酒宴杀毌丘俭，陈寿正文另有死因。 |
| L135–136 | 蜀军闻司马师死、司马昭新掌权，姜维请伐魏，张翼谏粮少民疲，夏侯霸主张趁隙。小说既有军议分歧，不能把张翼写成始终赞成继续攻城。 |
| L136–140 | 洮水背水战姜维击败王经，王经退守狄道；张翼再谏见好就收，姜维不从而围狄道，陈泰、邓艾以虚张火鼓解围，蜀军撤汉中。不能把洮水胜利记成狄道已攻克。 |
| L140–146（回末） | 姜维因洮西之功受封大将军，仍议再出师；111回才续写邓艾与姜维对峙。功赏与补给风险并存，撤军未消除后续冲突。 |
