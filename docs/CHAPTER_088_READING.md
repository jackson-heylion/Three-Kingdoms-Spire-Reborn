# 第088回《渡泸水再缚番王 识诈降三擒孟获》固定单底本正文核读

固定底本：[维基文库第088回 oldid=2568052](https://zh.wikisource.org/w/index.php?title=三國演義/第088回&oldid=2568052)，正文 L119–155。2026-10-27 按该固定修订从回首至回末核对。**单底本全文通读，未做真实第二小说底本异文全回对校。**

| 正文锚点 | 连续因果、责任及信息边界 |
| --- | --- |
| L119–123（回首） | 承087第一次释放，孟获向部众谎称杀守卒逃出，聚兵据泸水、收船拒渡；诸葛亮为暑热设四寨，蒋琬指出类似夷陵火营风险，马岱携粮药抵达。孟获并非此处已归顺。 |
| L124–128 | 马岱部下**白昼涉水中毒伤亡**，向当地人询问后改夜渡，夺夹山峪粮道；孟获轻忽渡口建议，忙牙长败死，董荼那因不愿交战被孟获杖责。毒水致死机理是小说叙述，不宜当现代医学事实。 |
| L130–132 | 董荼那及部众不满孟获，夜缚孟获送蜀营，形成**第二擒**；孟获以部下内讧为由不服。诸葛亮示营粮军械、放归孟获，仍未结束战争。 |
| L134–140 | 孟获返回后**诱杀董荼那、阿会喃**；孟优携珍宝诈降拟火攻，马谡识破，诸葛亮使来者醉倒、空寨设伏，马岱扮舟人擒孟获，形成**第三擒**。不能把第二、第三次混作一场。 |
| L141–155（回末） | 孟获、孟优被放归，沿途见马岱赵云魏延已控要道；诸葛亮向诸将说明不杀是为服心，孟获返银坑洞募兵。**本回止于三擒，第四次从089开始。** |

跨回：087首次释放使孟获得以再据泸水→088水道后勤、地方洞主倒戈与诈降火攻→089孟获增兵后西洱河再败、入秃龙洞。原创玩法可审计渡水救护、降者安置、被杀洞主与诈降处置；不能提前写七擒完结。
