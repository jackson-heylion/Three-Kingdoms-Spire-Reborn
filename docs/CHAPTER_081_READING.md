# 第081回《急兄仇张飞遇害 雪弟恨先主兴兵》固定单底本全文核读

固定小说底本：[维基文库第081回 oldid=8730381](https://zh.wikisource.org/w/index.php?title=三國演義/第081回&oldid=8730381)，正文 L119–150；2026-10-27 自首段至“未知诸葛瑾此去如何”回末连续审读。页面修订注记“毛宗岗本作范疆”，本次只按此修订正文记“范疆”，不冒称已核验纸本毛评原刻。**单底本全文情节因果核读，不是逐字异本校勘或全回史证。**

| 固定行位 | 叙事时序、知情与责任 |
| --- | --- |
| L119–120 | 承080刘备即位后欲伐吴，赵云明确以“先魏后吴”的公私轻重劝阻；刘备拒谏，命五溪兵并封张飞。张飞在阆中因关羽遇害而酗酒鞭军，得诏赴成都。 |
| L121–124 | 孔明与百官谏御驾亲征，刘备一度犹豫，张飞以桃园誓迫其复决东征；刘备告诫张飞酒后鞭人留在身边会招祸。秦宓再谏几乎被杀，众官救免暂囚；孔明上表劝先魏，刘备掷表，安排诸葛留蜀、赵云督粮、黄权程畿参谋等军职。此时张飞**尚未遇害**。 |
| L125–131 | 张飞限三日制白旗白甲；范疆张达诉不可办，遭鞭五十并受死令；两人因惧刑趁张飞醉睡刺死，斩首奔吴。暴虐、死令与叛杀有明确责任链，不能写成吴国事先指使。 |
| L133–134 | 吴班先遣军报，张苞治丧；刘备观星疑凶，军报到后才确认张飞遇害；张苞与关兴先后到营。小说星象是叙事手法，非可靠史证；**书面军报先于刘备确认**。 |
| L135–136 | 刘备悲伤影响军务，马良陈震建议召李意；李意绘破碎兵器与“白”字而去，刘备焚画继续前进。神仙预知不可标成历史事实。 |
| L137–138 | 张苞关兴争先锋，刘备制止比武，命二人折箭结义；吴班领先锋，二人护驾，水陆出征。**不应在玩家选择中让二人决斗致死或取消东征**。 |
| L140–150（回末） | 范疆张达携张飞首级投孙权，孙权收容；诸葛瑾自请为使议和，前往劝刘备，结果留082。不得把诸葛瑾劝和误写在081已成功。 |

跨回：080赵云刚起身进谏→081谏辞完整、张飞遭部将刺杀、吴方收容凶手并遣诸葛瑾→082使节被拒、吴向魏称臣。跨幕可玩：诸葛亮以留蜀档案复核秦宓谏书、军粮和张飞遇害军报；孙尚香只能读吴方接收凶手的后报，不在阆中现场。旧夷陵节点优先，不改变张飞命运。

未校：真实第二小说底本逐字对照（特别范疆/范彊名形）、出师人数、秦宓狱案、李意异闻的史证；局部史料见 CHAPTERS_081_083_HISTORY_SPOTCHECK.md。
