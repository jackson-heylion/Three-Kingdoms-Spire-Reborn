# 第026回《袁本初败兵折将 关云长挂印封金》：单底本全文因果核读

核读：2026-10-26。固定底本：维基文库《三國演義》第026回，oldid=8185862，https://zh.wikisource.org/w/index.php?title=三國演義/第026回&oldid=8185862 。正文已从“卻說袁紹欲斬玄德”连续核至“蔡陽要趕關公，畢竟如何”。只完成**单一底本全文情节/责任核读**；第二底本逐字对校、史料逐段核证均未做。

## 连续证据与因果

1. **“卻說袁紹欲斬玄德”→“教他為後部”**：承接第025回刘备被袁绍以颜良之死问罪。刘备以同貌不可据证辩解脱险，袁绍反责沮授；文丑请战，沮授主张延津守势遭拒，刘备随军却被文丑分作后部。此时刘备尚未与关羽相认。
2. **“且說曹操見雲長斬了顏良”→“曹兵圍裹將來”**：曹操奏封关羽汉寿亭侯，延津面对文丑，曹操故以辎重、马匹诱敌乱阵，荀攸识其意。粮车前置是诱敌战术，不是仓官失职。
3. **“文醜挺身獨戰”→“仍被曹操奪回”**：文丑射落张辽坐骑，徐晃抵挡不敌，关羽追斩文丑；曹军乘胜收回辎重。小说把关羽斩文丑写得明确，不能据此声称正史同载。
4. **“雲長引數騎東衝西突”→“請玄德上帳而坐”**：刘备隔河见关羽旗号却不能相认，袁绍因郭图、审配谗言再次欲杀刘备；刘备指出曹操可能借袁绍之手杀己，再次获释。**本回两次问罪，不能压成一次。**
5. **“玄德謝曰”→“吾不復教臨敵矣”**：刘备请托送信，袁绍同意；曹操回许都设宴，汝南刘辟龚都告急，关羽再出征，荀彧提醒其知刘备下落后会离开。关羽此时尚未取得刘备书信。
6. **“且說雲長領兵將近汝南”→“坐立不安”**：孙乾先在汝南密告刘备所在，刘辟龚都佯败让城；关羽暂瞒二嫂以防泄密，随行老军说漏消息后甘夫人责问，关羽承认并解释。不是二嫂早在土山就知刘备所在。
7. **“原來于禁探知劉備在河北”→“披肝瀝膽”**：曹操遣张辽探去志；陈震携刘备书信到来，关羽回书解释因护眷而暂留曹营，承诺辞曹迎二嫂。**孙乾口信与陈震书信是不同事件、不同信息源**。
8. **“陳震得書自回”→“蔡陽要趕關公”**：曹操数次挂回避牌，张辽亦托疾不见；关羽最终留书告辞、封存金银、挂汉寿亭侯印、带原随从护二嫂出北门。门吏退避，蔡阳欲率兵追击是回末悬念，不能写成蔡阳已经追上或曹操当面允准放行。
