| 111 段谷 | [《三国志》卷44《姜维传》oldid=12068919](https://zh.wikisource.org/w/index.php?title=三國志/卷44&oldid=12068919)，姜维段谷败后自贬段；[卷43《张嶷传》](https://zh.wikisource.org/wiki/三國志/卷43)，张嶷延熙十七年狄道与徐质战死段（本轮未固定该卷修订） | 小说将张嶷死于段谷突围，史传却记他于延熙十七年（254）在狄道与徐质交战时战死，段谷之败发生于256年；同一人不能在两战均存活。段谷失利、自贬见姜维传，但小说九寨、换旗哨马、武城山焚车、夏侯霸救援具体战术未逐项证实。 |
| 111 诸葛诞 | [《三国志》卷28《诸葛诞传》oldid=2386518](https://zh.wikisource.org/w/index.php?title=三國志/卷28&oldid=2386518)，征司空、杀乐綝、遣子靓入吴段 | 陈寿正文记司马昭征诞为司空，诞杀扬州刺史乐綝、举兵据寿春并送子靓赴吴；小说贾充宴中试探禅代、斩使与城门攻杀细节不能直接冒称史传逐字事实。 |
| 112 寿春 | 同卷28诸葛诞围城、文钦被杀、文鸯文虎降、诞败死段；[卷48《孙亮传》oldid=2085142](https://zh.wikisource.org/w/index.php?title=三國志/卷48&oldid=2085142)，太平二年与三年条 | 史传确认文钦被诞杀、二子归魏、寿春破、诞与部众战死；小说把于诠死节、数百不降部曲逐一处决、魏廷放归吴俘等戏剧细节串为连续场面。死亡责任、降卒赦免、家属株连必须分别保留；于诠个人死节细节未做第二史料核证。 |
| 112 《仇国论》 | [《三国志》卷42《谯周传》oldid=2589674](https://zh.wikisource.org/w/index.php?title=三國志/卷42&oldid=2589674)，「於時軍旅數出」与《仇国论》原文 | 该论确为陈寿正文所载，核心是小国慎战、重民劳；小说摘改文本并写姜维阅后掷地、径出兵。不能将掷书动作说成陈寿正文，也不能将小说段落视作原论逐字照录。 |
| 113 吴廷废立 | 同卷48《孙亮传》太平三年九月孙亮被废、孙休继位及孙綝被诛条；[《三国志》卷55《丁奉传》](https://zh.wikisource.org/wiki/三國志/卷55)，丁奉协谋除孙綝段（卷55未固定修订） | 孙亮被废、孙休即位、丁奉参与诛孙綝可核；小说蜜中鼠粪断案细节见**裴注引《吴历》《江表传》**，并非陈寿正文；裴松之对两种说法的可靠性另有评议。小说风异预兆不可写成史实。 |
| 113 祁山与黄皓 | [《三国志》卷44《姜维传》oldid=12068919](https://zh.wikisource.org/w/index.php?title=三國志/卷44&oldid=12068919)，姜维与黄皓关系及数次出师段 | 小说祁山八阵三百六十五变、党均贿黄皓传谣、夜袭地道等属于待核小说情节；不能直接归于陈寿正文，尤其不能提前把114回撤退结果或蜀亡归入113回。 |
