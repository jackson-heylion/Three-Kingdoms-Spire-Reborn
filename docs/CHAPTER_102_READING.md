# 第102回《司马懿占北原渭桥 诸葛亮造木牛流马》单底本全文通读

固定来源：[维基文库第102回 oldid=2568065](https://zh.wikisource.org/w/index.php?title=三國演義/第102回&oldid=2568065)，正文 L115–176，2026-10-28逐段核对回首至回末。状态：单底本全文通读；不是第二小说底本异文校勘，更非全回史实核证。

| 固定正文位置 | 情节、人物责任与知情边界 |
| --- | --- |
| L115–122（回首） | 承101回末谯周谏阻，谯周以鸟死、星象、柏树夜哭劝止；诸葛亮以托孤使命回应并祭刘备。关兴病故令蜀军再失一将。五路出祁山、李恢运粮先铺长期战线。灾异只属小说叙事，不能证明真实天象因果。 |
| L123–130 | 魏明帝曹叡召司马懿、任夏侯氏四兄弟参军；手诏坚壁不战、待蜀粮尽。司马懿架渭水浮桥，郭淮孙礼据北原；诸葛亮以虚攻北原、木筏火攻浮桥并取渭南为复合计划。此时双方只知各自侦察，不得将魏方已识破的情报写成蜀方已知。 |
| L131–134 | 司马懿识破北原佯攻与浮桥火攻，分路伏兵。魏延马岱受夹击、吴懿救援；吴班中箭落水身亡，王平张嶷因前线消息滞后陷伏，蜀军折损万余。不是木牛流马获胜后的伤亡。 |
| L135–140 | 费祎携诸葛亮信赴吴，孙权议三路北伐，费祎回报魏延勇而有隐患。此时仅是联吴出兵的承诺与报告，战局结果在103回，不能提前写成三路皆胜。 |
| L141–145 | 魏偏将郑文诈降，伪斩秦朗弟秦明；诸葛亮识破并反用书信诱魏军夜袭，秦朗死于乱军，郑文最终被斩。诸葛亮探上方谷，派杜叡胡忠造器、马岱守口，布局下一回火计；遁甲风云属小说叙事。 |
| L146–160 | 杨仪忧剑阁粮运，诸葛亮出木牛、流马形制和尺寸，令高翔转运。造具不是会自行行动的魔法机关；《三国志》卷35裴注引《亮集》有相近而不全同的尺寸与行程文本，须标明来源层级。 |
| L165–176（回末） | 司马懿夺样仿造，派岑威运粮；诸葛亮以王平诈巡粮夺具、扭转机关暂止行进，再由姜维魏延等夹击，张嶷作神兵烟火疑兵。郭淮败退，司马懿遭张翼廖化截击，回末悬念交103开篇廖化追击；不可提前写司马懿阵亡。 |

跨回：101谯周出班→102谏伐与魏渭水守势→北原失利/吴班阵亡→费祎联吴→木牛流马夺粮→103廖化追司马懿、吴军三路及上方谷。原创选择只决定保留军伤、工匠、民夫与运输证据，不逆转史诗结局。

未校：第二小说底本逐字异文；木牛流马物理复原；小说军数与战损独立史证；费祎使吴细节。局部史料见 CHAPTERS_102_104_HISTORY_SPOTCHECK.md。
