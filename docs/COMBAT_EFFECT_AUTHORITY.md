# P1 战斗持续军略与动态监听器的动作边界事件归约（2026-10-25）

此前四份权威日志可恢复持久资源、军令/护甲、敌军棋盘与有序牌区，但无法从事件恢复战斗中的八种持续军略层数及动态监听器。仅检查其余四份日志，即使当前存档中的监听器被修改，也无法发现。

新增 `src/combat_effect_events.rs`，每次成功 `Game::apply` 记录一条全局修订号事件，包含以下状态：

- 战斗开始 `Enter`：楼层、回合、有序 `PowerStack` 列表和完整 `event_stack::Stack`（监听器 ID、来源、目标、优先级、剩余次数、反制动作）。
- 战斗中 `Update`：当军略层数或监听器注册、注销、消耗变化时记录完整提交后状态；未变化时记录 `Unchanged`，仍消耗一次修订号。
- 战斗外 `Idle`、结束 `Exit`；禁止非法转场、回合回退、跨楼层伪更新、修订号缺口、非法监听器或重复/非法军略层数。

`CombatEffectProjector` 仅从日志增量恢复状态，非法事件不推进已提交修订号。 `Game::audit_combat_effects()` 将恢复结果与当前游戏比较；`Game::audit_authority_bundle()` 现在同步检查五份日志在每个修订边界的战斗生命周期、楼层和回合，并比较最终快照。

新战役从修订号0开始记录。旧版V2缺少此日志时仍可读档、继续游玩、验证已有动作历史，但**不能伪造历史事件，也不能宣称通过五日志审计**。存档版本保持V2。

为避免在已超大的 `src/lib.rs` 继续堆积方法，本轮将原有 `verify_action_replay()` 和 `reconstruct_event_history()` 实现抽至 `src/replay.rs`，保留公开API与旧存档缺失日志的兼容分支。

新增回归覆盖自定义战斗注册/注销监听器、军略层数归约、非法监听器与重复军略的原子拒绝、单日志终态合法但中间回合不一致、旧V2无新日志时的回放兼容，以及拒绝动作不污染五份日志。

**验收边界：**本轮仅记录每次成功动作提交后的军略与监听器状态，未捕获动作内部每次监听器触发、替换和反制的因果细节；不能从这五份日志独立重建全部 `Game`、RNG、剧情、市场或跨战斗效果。日志可被协同篡改，未提供可信签名或外部锚点。15套成熟构筑、复杂卡牌/道具/敌军交互、120回正文及异本校勘、真人试玩、完整中英国际化和正式1.0继续未验收。
