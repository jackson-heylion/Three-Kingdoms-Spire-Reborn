| 正文锚点 | 事件因果、人物责任与信息边界 |

| L115–116 | 承110洮西胜而狄道未克，邓艾论蜀必再出、姜维自陈五胜；樊建与夏侯霸提出再战风险，姜维仍决定出师。魏军已先设防，不可把蜀方主张视为客观胜算。 |
| L117–118 | 姜维以更换哨马衣甲、五色旗伪造大军驻祁山，实欲董亭袭南安；邓艾从马匹疲惫识破虚张，命陈泰攻祁山，自己抢武城山、伏段谷。双方情报判断各有因果。 |

| L121–123 | 邓忠、师纂、邓艾三路合围，夏侯霸救姜维，陈泰又截退路；小说写张嶷突围战死，姜维退汉中并自贬。张嶷史传死亡时序另有冲突，不能记为同一史实。 |
| L124–125 | 魏廷司马昭擅权，贾充借劳军试探诸葛诞，后者公开反对禅代；司马昭遣使征为司空并密令乐綝，诸葛诞杀使、攻扬州杀乐綝，召集屯田兵与民户。不能把召征与实质谋反先后颠倒。 |
