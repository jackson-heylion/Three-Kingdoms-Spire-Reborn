# 第090回《驱巨兽六破蛮兵 烧藤甲七擒孟获》固定单底本正文核读

固定单底本：[维基文库第090回 oldid=2568053](https://zh.wikisource.org/w/index.php?title=三國演義/第090回&oldid=2568053)，正文 L119–155；2026-10-27逐段从回首读至回末。**单底本全文通读；第二小说底本逐字对校、史料全回校勘未完成。**

| 锚点 | 因果、责任、时序、知识边界 |
| --- | --- |
| L119–123（回首） | 承089第五擒后释放，孟获返银坑，带来洞主请木鹿，朵思守三江。赵云魏延攻城遇毒箭，诸葛亮以包土登城破三江，朵思死于乱军。祝融擒张嶷马忠；孟获以五次放还之义阻止斩俘。 |
| L125–127 | 赵云魏延诱敌，马岱绊马擒祝融，诸葛亮交换两名蜀将，**不是处决祝融**；木鹿驱兽迫退蜀军，诸葛亮用假兽烟火反制，木鹿死于乱军。风咒与驱兽属小说叙事，不是已核实自然机制。 |
| L128–129 | 带来洞主假献孟获、祝融等，诸葛亮识破携刀诈降，**第六擒后再放**。孟获才转求乌戈国兀突骨藤甲军；不能把第六擒当成七擒完成。 |
| L130–136 | 桃花水与藤甲情报→吕凯劝退→诸葛亮探盘蛇谷→马岱设黑油柜、赵云布草车、魏延十五败七弃寨诱入谷；火攻使兀突骨与三万藤甲军在小说中覆灭。诸葛亮见惨状自叹损阴德，**胜利与大规模伤亡不可互相抵销**。 |
| L137–141 | 孟获受假报前往谷口，伏兵围困，马岱生擒孟获；祝融家眷亦被擒。诸葛亮承认火攻罪责；孟获拒绝第七次放归、表示心服，诸葛亮退还所夺地，令其继续为洞主。 |
| L147–155（回末） | 费祎建议留官驻军，诸葛亮列三条困难（兵粮、仇怨、互疑），决定不留外官与兵；军班师至泸水遇风浪，魏延回报，悬念交091。 |

跨回：089第五擒→090第六擒、藤甲火攻、第七擒及自治安置→091泸水祭亡、南征善后。**小说中的南方族群贬称、奇俗、神异及“永不再反”不等于史实**；游戏新增的是伤亡、俘虏、民粮与撤军档案，不改小说已定的擒放和结局。
