# BDD 自动化验收：从演义人物抉择到可复现的战斗状态

## 可执行契约

- 场景文件：`features/lore.feature`、`features/save_resume.feature`、`features/novel_provenance.feature`、`features/combat_powers.feature`、`features/advanced_combat.feature`、`features/advanced_cards.feature`、`features/boss_tactics.feature`
- 运行器：`tests/bdd.rs`，执行单一、严格的 Given / When / Then / And / But 子集。不是完整通用 Gherkin 解析器；不支持 Scenario Outline、Examples、Rule、Background、标签和数据表。遇到不认识的步骤，必须失败，不能自动跳过。
- CI：`cargo test --test bdd -- --nocapture`，`cargo test --all-targets` 也会执行 BDD 验收。
- 辅助质量门：Rust 单元测试、Clippy `-D warnings`、Release 构建、终端进度持久化冒烟、两平台各 1000 局种子模拟。
- 本轮新增5个职业持久能力BDD：关羽攻击触发一次护阵，诸葛计策触发恢复，孙尚香主动弃换触发伤害，曹操后勤随存档，吕布浴血随存档；现在合计41个Gherkin场景；新增5个高级战斗案例覆盖保留/虚无、抽牌护甲、施毒增强、击杀回复、非法动作无副作用。
- 内容审查：必须有小说回目 provenance；游戏虚构、小说演义、史实评价分开，不能写成已验证史实。

## 行为覆盖目录

| 验收域 | BDD 意图 | 反向场景 |
|---|---|---|
| 关羽：白马→华容 | 恩义结缘、之后有条件地出现回报、跨存档保留 | 只取赏金则后续不解锁 |
| 关羽：桃园 | 结义后开战实际增加护甲 | 不结誓不触发 |
| 诸葛亮：隆中→草船 | 历史关系门槛开启对应谋略线并增加开战谋略 | 未经历铺垫不会触发 |
| 孙尚香：联姻→截江 | 关系旗标连接吴蜀亲缘及连段起始资源 | 拒绝事件不获得 |
| 曹操：迁许→官渡 | 荀彧关系及统御初始加成 | 未见许都事件没有官渡后续 |
| 吕布：赤兔→凤仪 | 选择留下背盟痕迹，演变为怒气初始加成 | 省略铺垫不能跳到后续 |
| 彩蛋：白马旧债→华容 | 一条完整旗标链触发一次隐藏结局，读档状态不重复奖励 | 未集齐不得出现 |
| 强制拒绝错误动作 | 选项编号错误不可更改金币、人物结缘、RNG、修订号 | 非法选择必须被拒绝 |
| 回合中断恢复 | 战斗已开始、结束回合、序列化再读取仍处在有效场景 | 快照转换不能重排状态 |
| 小说章回 | 120回连续编号、各回有可追溯的经典文本索引 URL | 任意来源缺失、孤儿前置旗标失败 |
| 文学与史实 | 资料明确标识本项目并非正史复现及尚未完成逐回审校 | 不能把目录校核当作全文读校 |

## 测试编写约定

每新增一个三国故事，应有至少一对场景：玩家遵守诺言获得旗标的正向路径，以及放弃、交易或失败时不能凭空触发伏笔的反向路径。

每新增一个武将羁绊，应测试：

1. 实际生效的战斗资源变化，例如护甲或谋略，而不只测试文案；
2. 同一人物在不同宿命选择后，是否能/不能取得另一章节；
3. 战斗中或事件中中断后的 JSON 往返严格相同；
4. 已完成的隐藏彩蛋不能再次获得奖励；
5. `Game::apply` 失败指令必须完全回滚。

每新增一个来源章节，应核查 `data/novel_chapters.tsv` 中的准确回目和 `src/lore.rs` 的编号。**该 TSV 仅为120回目录，并不等同于已读完120回正文。** 人物关系和历史情节的逐回核对记录持续维护在 `NOVEL_STUDY.md`。

## 如何运行

```bash
cargo test --test bdd -- --nocapture
cargo test --all-targets
cargo run --release --bin tks-sim -- 1000
```

这里的 BDD 场景是业务行为测试，不代表完全覆盖全部卡牌组合、所有剧情线或所有战役随机状态。完整质量门还需要真正的状态机模型测试、所有事件分支的穷举、组合机制边界与回放日志。

## 战斗事件测试规范

- 一张攻击牌中的多段命中只触发一次按“出牌”定义的义军护阵，反之按“每次造成伤害”定义的记录保留各个来源；
- 伤害来源列出英雄攻击、亲兵、中毒、反击；只有最终实际损失的英雄生命值才增加浴血触发怒气；
- 每回合仅一次的计策持续效果和堆叠次数必须写入战斗快照，中途恢复不得双触发；
- 最近80条日志有严格递增序号，不能接受重复或倒序伪造；
- 任何失败行动不修改事件日志或任何游戏数据；
- `cargo test --test bdd -- --nocapture` 以及全平台 CI 都必须绿色才将功能标为通过。

## 新一轮规则覆盖

- 保留牌在回合边界不进入弃牌堆；未打出的虚无牌进消耗堆，且只记录一次 `CardExhausted`；
- `CardDrawn` 只在真正进入手牌时触发（手牌上限10张，空牌堆且弃牌堆也空不得触发）；
- `StatusApplied` 再触发额外中毒，但增强效果不再次发出同类事件，以防无限递归；
- 每个敌人第一次归零时产生一次 `FoeDefeated`；重复攻击阵亡目标没有再次奖励；
- 卡牌被打出且完成效果后产生 `CardResolved`，随后触发依赖完整卡牌结算的持续能力；
- 事件触发、敌方意图、卡牌生命周期必须在保存和恢复后保持确定性与严格单调序号。

## 2026-10-16 新增高级卡牌 BDD 6 场景

1. 关羽 X 重击按投入的军令数结算，结束后当前军令为0，单次攻击伤害可观测；
2. 吕布零军令 X 重击合法，但不会无中生有地造成基础 X 伤害；
3. 诸葛亮在明确指定抽牌堆第二张攻击牌前，先故意提交编号99；`Game::apply` 必须完整回滚，其后正确检索可跨存档恢复；
4. 孙尚香选择弃牌堆第二张复制，复制品标记为临时，打出后必须消耗而非回到弃牌堆；
5. 曹操临时募兵在结束回合后自动消耗，`CardGenerated` 与存档需保持一致；
6. 中立 X 格挡遵守手牌、军令和护甲规则。

附加单元测试验证 10 手牌上限、临时牌主动弃换消耗、X + 迅捷附魔、检索不触发 `CardDrawn` 类能力、临时保留牌的生命周期、无效动作 RNG/版本回滚。当前合计41个行为场景，另有数十项单元测试。

## 六首领 + 敌军协同（8个新场景）

`features/boss_tactics.feature` 使用真实 `Game::apply(Action::Choose)` 进入各幕Boss关卡（通过本轮 BDD 专用 fixture 设定关底和章节变体），断言六种不同的可预告专属招式实际产生的弱化、连段、扣金、护阵、延期军令、回复效果。另断言：司马懿对玩家当回合连续四次出牌的下一回合反制；至少两名存活敌军时校尉能为其他敌军上护甲。每个技能的身份与时序使用 `EnemyTechnique` 事件和递增序号校核，相关状态经 JSON 往返仍一致。

同时增加10个 Rust 单元测试，覆盖六 Boss 意图序列化与双实例确定性重放、虚弱必须受真实生命损失才生效、双连击、军资不为负、友军护甲、二阶段护甲保留与一次性转换、恢复上限以及本地协同。此版本仍缺跨Boss所有卡牌/遗物交叉组合的完整穷举。
