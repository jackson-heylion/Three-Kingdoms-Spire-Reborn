# 2026-10-16：曹操资源收益归因与孙尚香构筑对照

**性质：**可重复、固定种子、规则机器人分析；不是玩家胜率，也不能视为对具体技能收益的因果分解。数字来自相同种子的前后两个程序版本，因战斗回合数和路线会受修改影响，跨版本平均值的变化包含间接效应。

两个版本都在 macOS 与 Linux 通过 Clippy、单元测试、BDD、每平台1000局回归及每平台2200局分层成对平衡抽样、495局孙尚香构筑实验，所有对应 JSON 按跨平台逐字节一致校验。

每版本的曹操战术机器人结果来自**220局**，飞升0–10每档20个固定种子。分母是本策略记录的 `turns_completed`；末次不完整战斗回合可能被排除，因此“/回合”是诊断性平均，不能当作每一回合的恒定伤害。

## 曹操：亲兵和统御的实际资源贡献

| 战术机器人指标 | 满3层奖励（前） | 满4层奖励（后） |
| --- | ---: | ---: |
| 完整结算回合数 | 5,915 | 6,111 |
| 亲兵 HP 真实伤害/完整回合 | 2.21 | 2.11 |
| 亲兵真实吸收伤害/完整回合 | 2.24 | 2.68 |
| 统御额外军令/完整回合 | 1.07 | 0.73 |
| 战术机器人胜场 | 220/220 | 220/220 |

将统御门槛由3层改为4层，使额外军令/回合由1.07降低为0.73，下降约31.8%。由于观察到的游戏行动与回合数会随规则变化，这不是“直接削掉31.8%总战力”的意思。原先的亲兵伤害2/轮基础数值仍不变，且反映了卡牌升级、攻击抵挡、敌方死亡和存活时间的综合结果。

**重要：**战术机器人两版均220胜、0败，存在天花板效应，无法凭本统计推断哪个职业真正最适合真人玩家。第一张可打牌的简单机器人则敏感得多：修改前曹操按低/中/高飞升分别为90.0%、75.0%、63.3%，修改后为76.2%、52.5%、38.3%。**需要更丰富的机器人策略和真人测试评估手感是否过度削弱**。

## 孙尚香：等规模起始牌组实验

运行 `--sun-archetypes 15`，11个飞升等级，每难度每构筑15局，总计495局。标准牌组与两个测试构筑使用同一 RNG 种子集合，但后两套各用四张职业牌替换两张基础突刺和两张基础招架，**不是普通模式的自然抽到概率**。

| 流派 | 飞升0–3（60局） | 飞升4–7（60局） | 飞升8–10（45局） |
| --- | ---: | ---: | ---: |
| 标准开局 | 60/60 | 59/60 | 37/45 |
| 主动弃换 | 60/60 | 58/60 | 44/45 |
| 攻击连段 | 60/60 | 60/60 | 43/45 |

在高飞升场景中，定向构筑收益显著，但每组只有45局，应先进一步观察更多种子并模拟真实选牌/替换的渐进过程。弃换组在飞升8–10的45局累计 **1094 次**有效弃换，而标准组 **128 次**；这证明此构筑确实激活了弃换玩法，而不仅仅是更容易获胜。连续攻击组则通过更多攻击触发连段奖励，二者是不同的构筑方向。

## 实施内容和下一阶段

- 在 `Game.telemetry` 持久化 **17 项**战斗累计计数，支持旧版 V2 快照默认值，避免读取无历史统计的旧存档时报错。
- 维护最近24回合的紧凑诊断记录；终端 `metrics` 显示累计数和最近8个回合。
- 模拟器平衡 JSON 包含各职业/飞升/策略的聚合实测资源，孙尚香流派 JSON 包含各实验牌组的真实弃换/连段/护甲触发统计。
- 添加和更新实际 Rust 单测、BDD、终端冒烟及两平台完整机器 JSON 对比。
- 曹操统御满3改满4，保留奖励数量（1能量、5护甲），不再同时大幅变动其亲兵伤害。
- **下一阶段优先**：引入不同水平及牌组构筑倾向的机器人、关键卡牌贡献和真人可玩性测试；之后才考虑进一步职业调整。原始存档不存老版本的战斗历史，新增统计从存档升级后开始记载。
