# 第056回《曹操大宴铜雀台 孔明三气周公瑾》单底本全文因果核读

2026-10-27。固定小说底本：[维基文库 oldid=2568019](https://zh.wikisource.org/w/index.php?title=三國演義/第056回&oldid=2568019)。连续核对 L119–157；单底本，不是异本/史料全回完成。

| 正文位置 | 因果、责任、时序与证据边界 |
|---|---|
| L119–120 | 承055周瑜昏厥：吴将救醒退兵；孙权怒欲攻荆，张昭谏吴刘相争会招曹军，顾雍献以华歆表刘备荆州牧并离间曹刘之计。周瑜此时未死。 |
| L122–125 | 小说记建安十五年春铜雀台竣工；曹操在邺设骑射竞袍，曹休、文聘、曹洪、张郃、夏侯渊、徐晃争射，许褚与徐晃夺袍扯碎，曹操改赐众将。此为小说具体表演，非可直接引作陈寿记载。 |
| L126–133 | 文士献诗，曹操当众解释持兵权与“无篡意”，附后人王莽诗评；不能把小说中政治自述直接当作事实证明。 |
| L134–137 | 华歆报孙刘婚盟及荆州，曹操惊，程昱识破东吴表奏的制衡用意，建议封周瑜南郡太守、程普江夏太守促吴刘相争，曹操依计行事。 |
| L140–144 | 鲁肃再索荆州，刘备哭称同宗刘璋不可攻、无西川难归荆，孔明劝鲁肃转圜；周瑜再献“代取西川”假途灭虢之计，实欲借过境袭荆州。 |
| L145–150 | 孔明识计而故作答应，周瑜以甘宁前锋、自己二队、凌统吕蒙后队率兵，表面远征西川，实际要刘备出城劳军以乘机袭城。 |
| L151–157 | 周瑜见荆州白旗空城，赵云在城头点破假途灭虢；关羽、张飞、黄忠、魏延四路夹击，周瑜箭疮再裂倒马。**回末仍留生死悬念，第057回才续写**。 |

跨回：055退兵→056孙吴内部反间；054借据→056再次索城及假途；056周瑜倒马→057后续。游戏的曹营情报与孔明防务记账均为原创选择，不让玩家改变历史人物既定命运。
