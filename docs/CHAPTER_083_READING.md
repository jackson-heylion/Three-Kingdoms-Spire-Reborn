# 第083回《战猇亭先主得仇人 守江口书生拜大将》固定单底本全文核读

固定小说底本：[维基文库第083回 oldid=8730382](https://zh.wikisource.org/w/index.php?title=三國演義/第083回&oldid=8730382)，正文 L119–163。2026-10-27 自黄忠不服老出战至马良携营图问孔明、陆逊守险待机的回末逐段核读。页面修订注“毛宗岗本作范疆”，不当作真实第二底本。**单底本通读，不是史料全回校勘。**
