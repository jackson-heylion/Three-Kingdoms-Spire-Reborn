# 《三国演义》第009回单一底本正文通读：诛董后的长安危局

审读日期：2026-10-21。底本：[维基文库第009回固定修订 oldid=2567971](https://zh.wikisource.org/w/index.php?title=三國演義/第009回&oldid=2567971)，题为「除暴兇呂布助司徒　犯長安李傕聽賈詡」。审读范围：自第008回凤仪亭掷戟的悬念解释，到王允身死、李傕郭汜闯入宫中威胁献帝的回末悬念。**只完成这一底本的全回因果与角色行为核读，没有异本逐字校勘，也没有将小说叙述当成正史核证。**

## 全回因果与身份校核

1. **第008回撞倒董卓者是李儒。**李儒援引楚庄王绝缨故事，建议赐貂蝉以维系吕布；貂蝉在董卓面前反对被赐，董卓转而拒绝李儒。此时刺董并未发生。
2. **王允进一步推动，吕布主动表态。**董卓归郿坞途中，王允与吕布会面并在密室谈及凤仪亭；王允以国事、羞辱与父子名分动摇吕布，吕布刺臂立誓。不能把吕布决定简写成被貂蝉直接命令，也不能写成王允单独完成诛董。
3. **诛董并非吕布单人正面冲杀。**士孙瑞、黄琬参与设局，李肃获选前往郿坞，以皇帝让位之谎诱董卓赴未央殿。李肃原曾劝吕布投董，反转成了这一局的关键。
4. **董卓途中有多重不祥征兆却被反向解释。**折车轮、马断辔、狂风、童谣以及双口字旛依次出现，李肃将若干警讯解释成将受禅的吉兆；这是作品的文学讽喻，不是占候史实。
5. **北掖门刺董是第009回正事。**卫兵被隔于外，伏兵刺董未穿甲，吕布从后以诏讨贼并刺其喉，李肃割首。第008回仅止于掷戟，不可移到第008回结尾。
6. **诛董之后存在暴烈清算。**李儒被捉处死，董家郿坞财产被抄、亲属受戮，部分被掳女子获释；胜利与牵连之罪同时出现，不宜只叙作“一举大快人心”。
7. **蔡邕之死暴露王允善后的严酷。**蔡邕因念董卓知遇而哭，说明并未自认支持乱政，众臣和马日磾求情；王允拒绝并命蔡邕入狱致死。作品将此事写成王允失人望的重要前兆，不能误写蔡邕亲自参加刺董。
8. **不赦才推动旧部反攻。**李傕、郭汜、张济、樊稠求赦遭王允拒绝，原欲各自逃生；贾诩反对解散军队，劝其合兵入长安，并以对凉州人清洗的恐惧招募。这不是董卓死后旧部立即毫无缘由进兵。
9. **李肃与牛辅的命运不应跳步。**李肃遭牛辅夜袭败退后被吕布斩首；牛辅再败后想携财逃跑，反被胡赤儿杀害，胡赤儿亦因夺财杀主而被吕布处死。
10. **李傕以分兵引诱破解吕布的个人武勇。**李傕郭汜反复诱战，张济、樊稠另路攻城。吕布回师不及，又因军中畏惧其暴厉发生降敌，显示勇将难挽盟友与军纪的结构性失衡。
11. **长安失守、王允殒命；献帝危机留到下回。**李蒙、王方从城中开门，吕布劝王允走，王允拒绝而死于李傕郭汜之手。吕布出关投袁术。篇末二将执剑进入内廷、献帝前途悬而未决；不能把这场宫闱后果提前写成既定结局。
