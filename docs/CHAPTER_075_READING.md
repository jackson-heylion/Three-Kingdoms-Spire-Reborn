# 第075回《关云长刮骨疗毒 吕子明白衣渡江》固定单底本全文核读

2026-10-27。固定来源：[维基文库第075回 oldid=2568039](https://zh.wikisource.org/w/index.php?title=三國演義/第075回&oldid=2568039)，正文 L119–149；按回首、回中、回末连续核对，尚未做第二小说底本全回异文对校。

|---|---|
| L119–120 | 紧接074末曹仁射中关羽右臂：关平救回，拔箭发现毒伤；众将请暂回荆州，关羽以樊城将克为由拒绝，不能误写成庞德射中此箭。 |
| L120–124 | 华佗从江东来，见关羽与马良对弈，诊为乌头毒入骨，建议束臂蒙首手术；关羽拒绝束缚，饮酒弈棋受刮骨，华佗嘱百日休养，拒百金并留药。小说明确为华佗；《关羽传》只写“医”，且左臂旧伤，人物与时序不可合并为正史。 |
| L125 | 曹操因于禁降、庞德死议迁都；司马懿、蒋济判断孙刘失和，可联吴袭关羽后路；曹操命徐晃率兵赴阳陵陂，尚未解樊城围。 |
| L126–132 | 孙权同意与曹联手；吕蒙判断徐州陆战难守，欲先取荆州；江岸烽火台严备，陆逊识破吕蒙托病，献“以无名者代陆口、卑辞骄关羽”计；吕蒙荐陆逊，孙权任命。谋划属于吴方，关羽此时不知其真实用意。 |
| L133–135 | 陆逊书礼恭谨，关羽轻视并收礼；陆逊侦得荆州大半兵力调往樊城后报告孙权；孙权拟孙皎与吕蒙并督，吕蒙反对双主帅，遂独领军。不能把关羽接信写成主动接受割地。 |
| L137–138 | 吕蒙以白衣商船藏兵、夜缚烽台守军，借被俘守兵骗开荆州门，夺城并下令不扰民、保护关羽家属；不是单靠陆逊一封书立即占城。 |
| L140–141 | 吕蒙斩取民笠覆官甲的同乡以明军纪；孙权到城后任潘濬、释于禁，问公安南郡归附之策。军纪与处罚须区分叙事事实和游戏是否赞同。 |
| L143–149 | 虞翻书劝傅士仁降，傅士仁交印后受命招糜芳；糜芳尚未在本回投降。回末悬念交076开篇，不能提前将其降吴写在075。 |
