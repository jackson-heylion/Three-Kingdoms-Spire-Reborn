# 第060—062回《三国志》局部史料核证（非全回校勘）

固定史料：[《三国志》卷37 oldid=2583384](https://zh.wikisource.org/w/index.php?title=三國志/卷37&oldid=2583384) L134–141；[卷36 oldid=2583383](https://zh.wikisource.org/w/index.php?title=三國志/卷36&oldid=2583383) L166–168；[卷10 oldid=2274279](https://zh.wikisource.org/w/index.php?title=三國志/卷10&oldid=2274279)《荀彧传》。2026-10-27局部对勘；没有第二小说底本全文逐字比较。

| 回目 | 史料层级与具体证据 | 不能混同的小说与原创改编 |
|---|---|---|
| 060 | 卷37《法正传》陈寿正文 L140：张松于荆州见曹公还，劝刘璋结刘备；法正先出使再密议取蜀。卷37《庞统传》L134陈寿记庞统荐西川；裴注引《九州春秋》载刘备仁义与庞统权变之辩。 | 小说详细写许都杨修辩才、曹操焚《孟德新书》、张松转献地图，不能把戏剧化接待和失图写成陈寿直接记载。原创孔明地图副簿只供玩家抉择。 |
| 061 | 卷36《赵云传》L167陈寿正文仅记刘备入蜀赵云留荆州；裴注引《云别传》记孙权遣船迎妹、孙夫人欲携后主归吴、赵云张飞截江救回后主。 | 小说增周善假报国太病、赵云青釭剑登船、张飞斩周善等具体细节；《云别传》不等于陈寿正文，不能凭史料直接断言孙夫人知假信。原创夫人见证不改阿斗归蜀。 |
| 061 | 卷10《荀彧传》陈寿正文记荀彧因九锡议不合曹操，留寿春病卒；裴注引书另有自尽说法，应与陈寿正文及小说空食盒服毒情节分层。 | 小说把空盒作为曹操杀意明确表达；不能把具体空盒视为陈寿正文事实。 |
| 062 | 卷37《庞统传》陈寿正文 L135记庞统献上中下三计、刘备取中计斩杨怀高沛、涪城饮宴与君臣俱失；裴注中习凿齿评论、裴松之驳论需分开。 | 小说添张松家属遭斩、魏延抢功黄忠救援、冷苞假降与紫虚谶语；这些细节不因核心三计见正史便全部获得史实支持。第062回庞统未死，陈寿记其后围雒县中流矢亡。 |
