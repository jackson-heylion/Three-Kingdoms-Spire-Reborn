# 第105—107回：局部《三国志》史料核证（非全回异本/史料校勘）

2026-10-28核查固定可访问来源，**只记录实际比对过的条目**；第二部小说底本未取得并逐字校勘，故全回异本及史料完成数仍为 **0/120**。下列《三国志》陈寿正文、裴松之注引书、小说叙事与原创游戏选择须分别标注。

- **第105回魏延、杨仪**：小说 [oldid=2602415 L119–141](https://zh.wikisource.org/w/index.php?title=三國演義/第105回&oldid=2602415) 写魏延与马岱议投魏、锦囊阵前斩魏延；《三国志》[卷40 oldid=2583390 魏延传 L191–193](https://zh.wikisource.org/w/index.php?title=三國志/卷40&oldid=2583390) 陈寿正文记魏延先南归烧阁道、何平散军、马岱追斩，明确其原意不北降魏而欲除杨仪。裴注《魏略》另有魏延受命摄军、杨仪攻击说，裴松之认为敌国传闻不及本传可信。**史书不是小说“锦囊”证明**。同卷杨仪传 L194–200记其怨言、废为民与自尽；宗预使吴的史源尚待全量核对。
- **第106回辽东与魏廷托孤**：小说 [oldid=7909163 L119–136](https://zh.wikisource.org/w/index.php?title=三國演義/第106回&oldid=7909163) 写公孙渊叛、围襄平、夜逃受戮、曹叡病卒与曹爽司马懿共辅。陈寿《三国志》[卷08 oldid=2086403 公孙渊篇 L171–200](https://zh.wikisource.org/w/index.php?title=三國志/卷08&oldid=2086403) 记公孙渊夺位、吴魏两端、景初元年叛与次年讨平；裴注《吴书》《魏书》等叙事应标为引书。小说流星应验、毛后索命及司马懿每句战术对话不能自动当作陈寿正文。征讨与围城后处置另有细节争议，未全校。
- **第107回曹爽失权**：小说 [oldid=2568071 L119–153](https://zh.wikisource.org/w/index.php?title=三國演義/第107回&oldid=2568071) 写司马懿洛水誓言、曹爽交兵权、三族被诛；《三国志》[卷09 oldid=2274283 曹爽传 L200起](https://zh.wikisource.org/w/index.php?title=三國志/卷09&oldid=2274283) 记曹爽与司马懿同受顾命、曹爽擅权与最终被诛，注引《魏书》《世语》《汉晋春秋》等另有评价。**誓约是政治承诺，不等于可采信的免罪事实**；供词与判决要区分。
- **第107回姜维与费祎**：小说 [oldid=2568071 L154–166](https://zh.wikisource.org/w/index.php?title=三國演義/第107回&oldid=2568071) 详写夏侯霸入蜀、麴山断水、牛头山败退；《三国志》[卷44 oldid=12068919 姜维传 L156–161](https://zh.wikisource.org/w/index.php?title=三國志/卷44&oldid=12068919) 记姜维与费祎共事、屡欲大举而费祎限制兵力，裴注引《汉晋春秋》另记费祎谏辞。**不能把小说麴山逐次计谋、十矢连弩救关直接归入陈寿《姜维传》**。

游戏新增旗标只表示玩家接受原创责任档案，**不改变**魏延、曹爽、公孙渊的原著结局，也不把神异/传闻写成史实。

仍未校：第二小说底本真实逐字异文；《三国志》诸卷完整史料校勘；宫室徭役和毛后史源全量对读；第107回牛头山与陈泰传逐条核实。
