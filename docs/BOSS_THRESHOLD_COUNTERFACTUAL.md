# P1 固定战斗状态：指定 Boss 出牌频次反制的因果夹具

2026-10-24。对应 `tests/boss_threshold_counterfactual.rs`。这是**战斗意图层**的受控反事实（controlled counterfactual），不是完整 Boss 战胜率实验。

## 可验证的干预

从同一种子进入合法战斗后，构造单一 Boss 的合成快照。两组拥有相同武将、飞升等级、生命、敌军生命与状态、牌堆、手牌、初始 RNG、当前敌方意图和回合号。仅将本回合已出牌数从阈值前一张改为阈值：

- 司马懿：3 → 4 张，下一回合应从普通意图变为 `HiddenScheme`（暗度陈仓）。
- 左慈：4 → 5 张，下一回合应从普通意图变为 `Mirage`（幻身遁甲）。

固定为第2回合结束、即将预告第3回合；避开每三回合固定出现的 Boss 招牌技能，以免把自然触发误当成频次反制。覆盖5名武将 × 飞升0/10 × 2名Boss，共20组阈值前后配对。使用真实 `Game::apply(Action::EndTurn)`，检查意图、RNG、双方生命、敌军身份及V2存档往返。

运行：`cargo test --test boss_threshold_counterfactual`。最终机器验收须看PR最新提交的真实 macOS/Ubuntu CI；仅检查源码不等于编译通过。

## 严格边界

这不是正常地图生成的Boss遭遇：敌军由合成夹具替换，HP设为300，当前敌方意图设为无伤害护甲动作，且动作/事件档案被标记为旧式无完整历史。因此只能测试规则阈值和后续意图因果，**不得宣称该合成快照可以从初始种子通过动作或事件日志重建**。

下一步应将15套构筑分别放入**同一合法Boss战初始状态**，保持双方Boss属性、血量、装备、RNG与机器人策略一致，仅改变构筑处理；逐Boss统计胜负、生命损失、阶段转换与牌组自然获取概率。此处未建立那套全程反事实实验，更不能由20组阈值测试推断构筑成熟、敌人克制强度、真人胜率或P1验收完成。
