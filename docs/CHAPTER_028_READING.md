# 第028回《斩蔡阳兄弟释疑 会古城主臣聚义》：单底本全文因果核读

核读：2026-10-27。维基文库固定修订 oldid=2567993，https://zh.wikisource.org/w/index.php?title=三國演義/第028回&oldid=2567993 。从“卻說關公同孫乾保二嫂”连续读至“未知其事如何”；尚未完成异本/史料全回对校。

1. “卻說關公同孫乾保二嫂”→“與張遼拱手而別”：夏侯惇因秦琪为蔡阳外甥、关羽无通行明文而追；两批使者公文未释其疑，张辽传曹操明确放行之令后才止兵。不可倒写成第027回曹操令追杀。
2. “關公趕上車仗”→“吾看汝父之面”：郭常留宿，其子盗赤兔失败、又勾连裴元绍劫马；关羽两次因郭父求情宽恕其子。
3. “正說話間”→“往汝南進發”：周仓愿率众投关，甘糜二夫人担忧，关羽只许周仓单人随行，其余暂留裴元绍处。不能写成已收编整寨。
4. “行了數日，遙見一座山城”→“張飛方纔信”：张飞据古城，疑关羽降曹，二嫂孙乾证言不足消疑；蔡阳偶率兵至，关羽一通鼓未毕斩蔡阳，旗卒证明蔡阳本奉命攻汝南刘辟、非奉曹操追杀关羽，张飞才信。
5. “忽城中軍士來報”→“便欲同至河北”：糜竺糜芳重聚，刘备已离汝南返回袁绍处求援，关羽请张飞守古城、孙乾先探河北。
6. “孫乾匹馬入冀州”→“簡雍與玄德同行”：简雍协助刘备借说刘表合兵之辞脱离袁绍；袁绍曾扬言杀关羽，刘备以虎鹿比喻辩护，简雍假借监行同行。
7. “玄德先命孫乾出城”→“關定送了一程”：关定次子关平经刘备提议拜关羽为义父；此为小说情节，非未经核证的正史亲缘。
8. “忽見周倉引數十人帶傷”→“招軍買馬”：裴元绍欲夺马被赵云刺死，周仓战败；刘备认出赵云，众人古城会合，后转驻汝南。
9. “且說袁紹見玄德不回”→“且聽下文分解”：袁绍采郭图建议遣陈震联络孙策，直接引第029回江东线。
