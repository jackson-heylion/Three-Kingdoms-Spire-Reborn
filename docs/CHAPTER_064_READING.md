# 第064回《孔明定计捉张任 杨阜借兵破马超》单底本全文因果核读

2026-10-27。固定底本：[维基文库 oldid=2568026](https://zh.wikisource.org/w/index.php?title=三國演義/第064回&oldid=2568026)。正文 L119–169 连续阅读开篇至回末；**仅单底本通读，非异本文字或史料全回校勘**。

| 位置 | 因果、责任、时序 |
|---|---|
| L119–126 | 严颜领张飞沿途四十五关免战；刘备夜袭后围雒城，张任西门突击，张飞严颜救刘备；吴兰雷铜追黄忠魏延反被截而降。 |
| L128–131 | 张任再诈败围张飞，赵云从江边救援并擒吴懿；孔明与简雍蒋琬到营，凭吴懿情报勘金雁桥。 |
| L132–139 | 孔明布断桥与两岸伏兵，赵云拆桥、黄忠魏延击骑兵、张飞生擒张任。张任拒降，刘备不忍，孔明命斩。不能写成刘备主动命斩。 |
| L146–152 | 刘备厚葬张任；张翼杀刘璝开雒城，刘循逃成都，刘备安民；法正劝降信遭刘璋拒，郑度提焚粮迁民、刘璋不纳，遣费观李严守绵竹并求张鲁援。 |
| L153–160 | 关中支线：马超杀降将韦康，杨阜联姜叙赵昂等反马超；赵月及马超家眷遇害、历城报复，夏侯渊追兵逼马超走。不能以单一复仇概括双方民伤。 |
| L161–169 | 马超转投张鲁，杨柏杨松猜忌；刘璋遣黄权求援，以二十州为酬，阎圃劝阻，回末请缨者尚未揭名，第065回开头才揭马超。 |
