# 第079回《兄逼弟曹植赋诗 侄陷叔刘封伏法》固定单底本全文核读

固定版本：维基文库 [第079回 oldid=2568043](https://zh.wikisource.org/w/index.php?title=三國演義/第079回&oldid=2568043)，正文 L119–170。2026-10-27 从开篇核至回末，以下是情节证据，不冒充异本对校。

| 证据行位 | 因果、责任、时序与人物知情 |
| --- | --- |
| L119–120 | 承078曹彰带兵而来，贾逵问奔丧还是争位，曹彰交兵入城；曹丕受魏王位、改延康，令于禁看高陵壁画羞其樊城降敌，于禁郁愤病死。此是小说具体叙事。 |
| L126–128 | 曹熊未奔丧而自缢；曹植与丁仪丁廙被问罪，许褚赴临淄缚归，丁氏兄弟先被处死。曹丕是政治决定者，不能将处刑归给许褚个人。 |
| L129–144 | 卞氏求情，华歆建议以诗试曹植；曹丕先限七步咏画牛，后令应声咏兄弟而不许直言兄弟，曹植作豆萁诗，曹丕贬其安乡侯。诗与七步情节是小说安排，不能当作已证实的当庭史实。 |
| L146–148 | 成都刘备闻曹丕威逼献帝，先欲伐吴；廖化归责刘封孟达拒援，诸葛亮建议分调。彭羕密信孟达被马超截获，受诱试言后获罪死；孟达恐惧投魏。诸葛亮并非直接处死彭羕者。 |
| L149–160 | 孟达投魏上表，刘备怒；诸葛亮提议命刘封攻孟达，曹丕试孟达诚意，孟达致书招降刘封，刘封斩使拒降。该信及上表在史料中有异文/引书出处，不能自动认作小说逐字同本。 |
| L161 | 刘封战败失上庸、房陵回成都；刘备以拒援及失地罪斩，后知其拒孟达招降而悔。与《刘封传》“赐令自裁”及诸葛亮建议缘由需分层。 |
| L162–170 | 曹丕谯县祭祖、夏侯惇死；李伏许芝以祥瑞说魏当代汉，华歆等请献帝禅位。回末**献帝尚未答应**，受禅发生第080回。 |
