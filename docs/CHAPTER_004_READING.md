# 《三国演义》第004回正文审读：献刀未遂与陈宫离心

- 审读时间：2026-10-20。
- 唯一核读底本：[维基文库《三國演義/第004回》固定修订 oldid=2567966](https://zh.wikisource.org/w/index.php?title=三國演義/第004回&oldid=2567966)。
- 标准回题：「廢漢帝陳留踐位　謀董賊孟德獻刀」。覆盖该修订页首句「且說董卓欲殺袁紹」至回末「畢竟曹操性命如何」；核读全回情节顺序及关键转折。**没有对照其他底本、逐字校异，也没有把小说叙述核实为历史事实。**

## 全文因果顺序

1. **第003回的冲突没有以袁绍之死收尾。** 董卓要杀袁绍，李儒劝止。袁绍离席返冀州；周毖、伍琼建议借授官安抚，董卓遂拜袁绍为渤海太守。这与后文袁绍寄密书策动反董、各镇兴兵构成因果，不可改写为董卓在宴会中已经诛杀袁绍。
2. **废立有正式的暴力与文书两面。** 嘉德殿上李儒宣读废少帝、立陈留王之策；少帝被迫解下玺绶，丁管以象简击董卓而遭杀。陈留王刘协登极；何太后、弘农王与唐妃遭幽禁。此前第003回「玉玺失踪」和本回「解玺绶」不能混成董卓已经寻回传国玉玺。
3. **任官与挟迫并存。** 李儒劝董卓征蔡邕以收人望。蔡邕起初不赴，遭灭族威胁后应召，并在一月内多次升迁；不应写成蔡邕起初即自愿归附。
4. **废帝遇害不在废立当天。** 幽居中的少帝作诗寄怨，董卓闻讯后命李儒入宫；何太后被推下楼，唐妃被绞，少帝被强灌鸩酒。后续董卓阳城屠戮民众，凸显国政失序转为对普通人直接施暴，不宜只以宫廷权谋概括。
5. **伍孚先于曹操行刺，二事不同。** 越骑校尉伍孚怀短刀刺卓未成，吕布助擒，伍孚遇害；董卓此后加强随身卫护。不要把伍孚与主张宽待袁绍的伍琼、被杀的丁管混作一人。
6. **王允设宴借「生日」为掩护。** 袁绍来书请求王允谋卓。群臣哭于宴席，曹操反诘徒哭无益，自请借七星宝刀行刺。曹操假意仕董，利用对方信任接近，并非早已与董卓公开决裂。
7. **七星宝刀并未刺中董卓。** 吕布被差去择马后，曹操试图乘董卓转身取刀；董卓由镜中察觉，曹操仓促改口献刀，借试马逃走。吕布和李儒怀疑，他逃出东门后董卓才发画影缉拿令。所谓「献刀」是行刺失败后的脱身托词。
8. **陈宫有独立判断与行动。** 中牟县令陈宫认出假称客商的曹操，起初拘押，夜里听其反董陈词，主动解缚、弃官同行。陈宫此时因相信其忠义而追随，不能把后续分裂提前到中牟。
9. **吕伯奢家中先是误杀，后来是明知故杀。** 吕伯奢出外沽酒，曹操误听「缚而杀之」为谋害自己，与陈宫杀害其家八口，随后见厨下待宰的猪才发现误会。两人离开后遇吕伯奢携酒食归来，曹操仍主动回身杀他，以防报复。陈宫明确区分误杀与知而故杀，并强烈谴责。
10. **回末留下陈宫是否杀曹操的悬念。** 两人在客店投宿，陈宫心生悔意，欲拔剑杀曹操；正文到此停章，不宜把第五回的结果提前当成第四回已交代的事实。

## 人物动机与可检验冲突

**曹操**：从第003回劝何进不要轻召外兵，到第004回借刀、失败逃亡，体现政治判断与冒险；但吕家两次杀人使他由「讨董救汉」滑向「以他人性命保障自己」。本回的名句「宁教我负天下人，休教天下人负我」属于小说语境，不据此直接声称真实历史曹操讲过同一句话。

**陈宫**：前半回以弃官相救来选择曹操，后半回因吕伯奢之死怀疑其人。两段必须成对读，否则第019回白门楼陈宫的劝谏与旧怨缺少深层前因。**董卓**：既用赦授袁绍的政治手腕，又用废立、禁锢与杀戮建立威权；「只有蛮勇、没有权术」并不符合本回细节。
