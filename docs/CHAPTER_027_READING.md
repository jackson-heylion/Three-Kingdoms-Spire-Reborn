# 第027回《美髯公千里走单骑 汉寿侯五关斩六将》：单底本全文因果核读

核读：2026-10-27。维基文库固定修订 oldid=8186000，https://zh.wikisource.org/w/index.php?title=三國演義/第027回&oldid=8186000 。已从“卻說曹操部下諸將中”连续读至“畢竟關公怎生脫身”；定位依该修订的起止语。未做第二版本文字对校或《三国志》全回史料核证。

1. “卻說曹操部下諸將中”→“曹操自引眾將回城”：承第026回挂印封金。程昱主张追杀，曹操以守信拒绝；张辽先至、曹操赠路资锦袍，关羽拒金、以刀挑袍。不得写成曹操下令追杀或撤销三约。
2. “不說曹操自回”→“廖化拜別”：廖化杀劫持二嫂的杜远并送还车仗；关羽谢其护眷，却拒绝黄巾旧部随行与赠金。不能写成廖化已经加入关军。
3. “雲長將曹操贈袍事”→“胡華書信”：胡华留宿，托信给荥阳从事胡班；此信是后续胡班反对纵火的明确前因。
4. “次日早膳畢”→“保護車仗”：东岭关孔秀因无公文阻行、要留家眷为质；洛阳孟坦假败诱追，韩福暗箭伤关羽左臂，关羽斩二人。需分别记录设诱、暗箭与伤情。
5. “關公割帛束住箭傷”→“住滎陽進發”：汜水关卞喜在镇国寺埋伏，普净以戒刀目示警；关羽识伏斩卞喜，普净因泄谋离寺。
6. “滎陽太守王植”→“感胡班不已”：王植与韩福有姻亲关系，命胡班三更火烧馆驿；胡班读父亲胡华书信后告警开门，王植追击被斩。
7. “行至滑州界首”→“關公所歷關隘五處”：刘延不敢给渡船，秦琪受夏侯惇令守黄河渡口，拒放行被斩。六将为孔秀、孟坦、韩福、卞喜、王植、秦琪；蔡阳不在本回六将之内。
8. “關公於馬上自歎”→“且聽下文分解”：孙乾报刘备已离袁绍、赴汝南，关羽改道；夏侯惇追来是回末悬念，第028回才交锋并放行。
