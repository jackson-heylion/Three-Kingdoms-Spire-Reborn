# 《三国演义》第008回单一底本正文通读：连环计与凤仪亭

审读时间：2026-10-20。固定正文：[维基文库第008回 oldid=5314829](https://zh.wikisource.org/w/index.php?title=三國演義/第008回&oldid=5314829)，题为「王司徒巧使連環計　董太師大鬧鳳儀亭」。核读范围：承接孙坚遗体交涉，到董卓在凤仪亭掷戟未中吕布、出园跌倒的末尾。**仅审理该单一底本的整回故事和因果，尚未做异本文字、毛宗岗评语与正史史料的对勘。**

## 顺序、行动者与因果边界

1. **第007回的桓楷悬念在第008回首段解决。**蒯良建议趁孙坚刚死、孙氏子幼而取江东，刘表因黄祖被俘并顾念交情，最终与孙策以孙坚遗体换回黄祖。孙策归江东葬父、招贤纳士。不能把换尸结果提前归到第007回，更不能说桓楷被杀。
2. **董卓狂妄并非单纯好色。**长安朝廷中他以“尚父”自居，重用宗族、筑郿坞、虐待降卒；宴会中又借张温与袁术私通的指控命吕布杀张温。王允当晚忧惧，先在后园遇貂蝉，除暴谋划由此展开。这里以暴政为初因，而非“争风吃醋”天然导致政治变局。
3. **王允明确提出连环计，貂蝉明确答应参与。**王允告诉貂蝉先许吕布、后献董卓，再利用二人的嫉妒离间。貂蝉应允，但其生活在王允府中的依附关系、风险与权力不平等也在正文中存在。既不能抹去她的主动行动，也不能忽略这一处境。
4. **先用礼物接近吕布，再分别设宴。**王允让人送明珠金冠、称赏吕布英雄之才，宴上以女儿的名义许配貂蝉。几日后趁吕布不在邀请董卓，奉承其有受禅之命，献出貂蝉，当晚送入相府。两次宴请、两套话语、先后顺序是离间的物质条件。
5. **吕布很快察觉承诺冲突。**他当晚追责王允，王允诳称董卓只是替义子迎娶，吕布暂信。吕布随后发现董卓已与貂蝉同寝；貂蝉在窗下、帐后以眼泪及动作表达处境，吕布怨怒加剧。王允谎言与貂蝉行动都不能省略。
6. **李儒曾使冲突暂时缓和。**董卓斥退吕布后，李儒劝告不应为小过失去猛将。董卓次日致歉并赏金帛，吕布谢恩，心却仍牵挂貂蝉。因此游戏的反制或故事可保留“利诱缓冲、冲突暂挂”阶段，不能从初次被逐直接跳到凤仪亭举兵。
7. **凤仪亭与刺董并非同回完成。**董卓上朝，吕布擅往相府见貂蝉。貂蝉诉说遭遇并欲投池，迫使吕布表态；董卓提前回府发现两人，拾画戟掷吕布，吕布格落而走。董卓追出园门时被一人撞倒，此人是谁留待下回。**第008回末尾董卓未死，吕布也尚未完成第009回的政治弑董。**
8. **文本细节不能充当正史证据。**貂蝉、王允、凤仪亭的互动是本小说叙事，人物动机与年龄均为作品所述；游戏测试只约束选定底本的情节顺序，不把演义正文当成《三国志》的史实。
