# 第049回《七星坛诸葛祭风 三江口周瑜纵火》单底本全文因果核读

2026-10-27；固定毛本网络修订：[维基文库 oldid=2568012](https://zh.wikisource.org/w/index.php?title=三國演義/第049回&oldid=2568012)。L 为固定页面正文行号；连续核读 L119–175。**仅单底本；异本文字未对校。**

| 正文位置 | 因果、人物责任与信息边界 |
|---|---|
| L119–128 | 承048周瑜昏厥，鲁肃请孔明问病。孔明写明火攻缺东风，提出七星坛祭风，周瑜准造坛、备守兵。小说以术数借风叙事；不能作为可证气象操控史实。 |
| L129–134 | 孔明祭坛、周瑜与鲁肃候风；黄盖预置火船与走舸，甘宁阚泽控制二蔡，孙权援兵待命。东南风起后周瑜因忌孔明，遣丁奉徐盛水陆追杀；此为同盟内猜忌，不是东吴已与刘备开战。 |
| L140–143 | 诸葛亮预令赵云接应；赵云箭断追船篷索以脱险，未杀徐盛，丁奉徐盛回报。 |
| L145–149 | 周瑜分别遣甘宁、太史慈、吕蒙、凌统、董袭、潘璋并部署韩当周泰等火船后援；孙权令陆逊先发，不能把全役火攻功劳写成诸葛亮独力。 |
| L150–159 | 孔明返夏口调赵云、张飞及糜氏等分路截曹，刘琦守岸；关羽主动请战，孔明提出曹操旧恩风险，双方各立军令状。华容放曹的**抉择与结局在050回**，本回仅派伏兵与预示。 |
| L161–169 | 程昱再警东南风与黄盖船轻载，曹操一度察觉，派文聘拦船；文聘中箭，黄盖火船冲连舰，曹军火起。曹操由张辽护送登岸，张辽射黄盖落水。 |
| L169–175 | 回末黄盖中箭落江，生死悬念留050回；不能在本回写黄盖已死。 |

跨回：048风向疑难 → 049周瑜火船+东风+曹军误判 → 050韩当救黄盖、曹操三路败逃、关羽义释。既有可玩 redcliff 只记录同盟分工与风候；不得新增“孔明独自放火”的第二事件。

未验：另一小说底本逐字差异；祭风术数的历史可证性。史实参见《三国志·周瑜传》陈寿正文、裴注《江表传》分层局部对勘。
