# 第098回《追汉军王双受诛 袭陈仓武侯取胜》固定单底本全文核读

固定底本：[维基文库第098回 oldid=2568061](https://zh.wikisource.org/w/index.php?title=三國演義/第098回&oldid=2568061)，正文 L119–156；2026-10-27逐段从回首核至回末。**单底本全文通读；第二小说底本及史料全回对校未完成。**

| 正文位置 | 叙事因果、人物责任与边界 |
| --- | --- |
| L119–122（回首） | 承097司马懿议退蜀，魏廷令曹真守险待蜀粮尽；郭淮派王双巡小路，孙礼以柴草伪装粮车设火伏。魏方掌握蜀军转运困难，却不知诸葛亮识破诱饵。 |
| L123–124 | 蜀军粮不足一月，诸葛亮识孙礼伪粮，令马岱从上风烧车、马忠张嶷合围，关兴张苞乘魏营出兵袭营，吴班吴懿截归路；魏军分头误判火号而败。战术胜利并未解决蜀军粮短。 |
| L125–128 | 诸葛亮因魏军仍坚守、补给难继决定先撤，留下空营并授魏延后卫计；曹真未及时察觉。王双追击魏延，被营火诱返，魏延伏三十骑斩之。**撤军是主动保存军队，不可写成已攻破陈仓。** |
| L134–136 | 魏延回汉中交军，曹真闻王双死而病归洛阳，郭淮等留守。小说对魏延伏击的细节不等于陈寿正文的战术记载。 |
| L138–140 | 孙权在吴廷受群臣劝进，于黄龙元年称帝；蜀廷有人主张绝交，诸葛亮主张承认吴帝以继续牵制魏。小说遣杨震致贺，史传《吴主传》记蜀遣卫尉陈震，**使者身份有别**。 |
| L141–145 | 郝昭病危，诸葛亮预先潜入陈仓并内应纵火，郝昭惊死；蜀军取陈仓、散关，诸葛亮让郝昭家眷扶柩回魏。须区分097久攻不克、098退兵后再袭得手两个时段。 |
| L146–150（回末） | 蜀军复出祁山，姜维王平分取武都阴平；魏廷得知陈仓失守和吴蜀同盟，曹叡召司马懿，曹真病中让出都督印。下一回099才继续司马懿与蜀军交锋，不得提前记武都阴平已取。 |

跨回：097陈仓攻城失败→098识破伪粮却仍粮尽撤兵、魏延斩王双→吴帝称号与蜀吴再盟→郝昭病重、陈仓被袭、分兵武都阴平→099继续战局。原创选择仅调整粮秣、遗属善后与使节档案，不改变小说战果。

未校：第二小说底本逐字异文；陈仓再袭是否有史传对应；孙权称帝盟书的异本；小说使者杨震与史传陈震的文本演变。局部史证见 CHAPTERS_096_098_HISTORY_SPOTCHECK.md。
