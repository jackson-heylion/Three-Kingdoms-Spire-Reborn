# 第081—083回局部正史核证（非第二小说底本全文校勘）

2026-10-27；小说固定版本：081 oldid=8730381、082 oldid=2568044、083 oldid=8730382。史书固定修订：《三国志》卷36 [oldid=2583383](https://zh.wikisource.org/w/index.php?title=三國志/卷36&oldid=2583383)、卷47 [oldid=2602668](https://zh.wikisource.org/w/index.php?title=三國志/卷47&oldid=2602668)、卷58 [oldid=2131313](https://zh.wikisource.org/w/index.php?title=三國志/卷58&oldid=2131313)。以下仅核明确条文，不代表逐回史实全量核证；第二小说底本全回异文对校 **0/120**。

1. **第081回 L119–128：赵云谏先魏后吴。** 《三国志》卷36《赵云传》裴注引《云别传》（oldid=2583383，赵云传末“孙权袭荆州，先主大怒”）载赵云劝先图关中，刘备不听。应标为**裴注所引《云别传》**，不能冒充陈寿《赵云传》正文直接引语。小说刘备与张飞演武场争论、秦宓囚谏、李意占图，未据此条证成史实。
2. **第081回 L125–138：张飞之死。** 卷36《张飞传》陈寿正文（“先主常戒之”至“飞营都督表报先主”）记张飞暴虐鞭人、刘备曾告诫、临发伐吴遭帐下张达与**范彊**杀害、持首投孙权，刘备见表即知死讯。小说固定页写**范疆**，人物名形差别有真实固定文字证据，但这属于小说与史书对照，**不是两部小说底本异文校勘**。醉卧睁眼、白旗白甲三日死令、星陨、折箭结义不能据陈寿正文确认。卷36正文又记张苞早夭，小说后续武将生涯不能直接当正史。
3. **第082回 L119–125：孙权向魏称臣受封。** 卷47《吴主传》固定修订可核孙权魏吴外交、称臣与封王背景；小说赵咨逐问答、刘晔论伐吴、孙权礼迎九锡仪节与吴方虚实须另行逐句核证，不能因魏吴封号存在就认定每句对白有史证。孙权受封是权宜外交，不代表吴蜀已经和解或魏军实援。
4. **第082回 L126–132 / 第083回 L149–157：陆逊与夷陵。** 卷58《陆逊传》陈寿正文（“黄武元年，刘备率大众来向西界”起）确载孙权授陆逊大都督假节、统诸将五万人，刘备连营、吴班平地诱敌、陆逊拒躁进，孙桓受围而陆逊不救；裴注引《吴书》补陆逊拒战说辞。小说关兴张苞斗将、谭雄射马、崔禹被擒等细节不得据此直接定为史实。**第083回末只写吴军守险与蜀军移林，史书后续火攻属于084的叙事边界**。
5. **第083回 L119–130：黄忠之死有硬性年代冲突。** 卷36《黄忠传》陈寿正文“建安二十四年”后紧接“明年卒”，即220年；小说置于章武二年（222年）东征吴国中箭而亡。必须明确这是小说改写，不可称“史实黄忠在夷陵被马忠射死”。同回甘宁遭沙摩柯射死、潘璋遇关羽显圣被关兴斩、糜芳傅士仁杀马忠求降与范疆张达受刑等尚未完成逐项史证，不能以史书空白判定其绝对不可能。
6. **第083回 L147–163：求和失败与吴将受命。** 卷58正文有陆逊统帅、拒诸将躁进、受困孙桓不救的史证；小说的阚泽全家保举、程秉带首议和、刘备欲斩来使、马良画营图等仍属本轮未核实的细节。玩家选择只影响原创记录、救济资源与隐藏结局，绝不倒改历史人物死生。

待核：完整第二小说版本（影印/版本修订可追溯）、吴主传对应具体句段、甘宁潘璋等死亡年月、刘备伐吴真实兵力与各使者任命、李意神异来源；异本及史料**全回校勘 0/120**。
