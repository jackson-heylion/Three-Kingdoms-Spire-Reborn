# 第011、120回局部史料对勘：小说、陈寿、裴注与唐修《晋书》分层

| 回 | 可访问原文及位置 | 证据界限 |

| 011 北海、太史慈 | [《三国志》卷49《太史慈传》](https://zh.wikisource.org/wiki/三國志/卷49)；[第011回固定正文](https://zh.wikisource.org/w/index.php?title=三國演義/第011回&oldid=2567975) | 太史慈早期事迹应依陈寿正文及裴注分层核实；小说孔融旧惠太史慈母、单骑救北海、关羽斩管亥及刘备再救徐州的完整串联不能直接全部归陈寿正文。 |
