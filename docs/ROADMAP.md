## 本轮新增的行为边界

- X 效果投入现有全部军令，零军令打出合法但不造成X基础收益，不能靠「迅捷」减免 X 费用；
- `Action::PlaySelected` 是新动作类型，兼容旧版 `Action::Play`，抽牌堆/弃牌堆从顶部起按1编号；
- 明确选错卡、编号越界或非选择类卡带上选择参数都会整笔事务回滚；
- 临时牌的 `Card.temporary` 采用 serde 默认 false（老快照仍可读），仅战斗堆中合法，不得进入永久牌组，打出/弃换/回合结束均消耗；
- 特定检索从 draw 堆到 hand，产生 CardTutored 而非 CardDrawn，避免错触发抽牌类军略；复制与生成分别有 CardCopied、CardGenerated 审计事件；
- `tests/bdd.rs` 共41条可执行行为场景，仍非所有高阶组合的穷举验证。

## 测试标准

- 所有新增卡牌必须至少有一个规则回归测试或者卡牌族参数化测试；
- 任何失败 Action 不改变 `Game` 序列化结果、修订号或 RNG；
- 每个游戏场景既能在当前终端继续，也能从序列化快照恢复；
- GitHub macOS CI 和模拟器真实通过才标记完成；
- 社区 Wiki 数据、原作更新版本与项目实际覆盖必须分开写，不得仅以内容总量宣称完全复刻。
