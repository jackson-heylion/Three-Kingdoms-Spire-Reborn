## P1 必须补齐后才能叫“完整单人终端版”

- [ ] **更丰富的地图拓扑**：已具备 7层×3道持久化 DAG、相邻道可达约束和 map 预览；缺分叉与合流变化、特殊地形限制、多幕地图生成概率配置和路线评分。
- [ ] **完成统一事件/触发栈**：本轮已实现8种带递增序号的战斗事件、五职业堆叠持续军略及伤害实际结算追踪；仍欠全类型（抽牌/施加状态/死亡/力量变动）的统一派发、动态订阅、触发优先级、跨战斗持续效果和事件源强类型。
- [ ] **完整关键词及卡牌类别**：攻击/技能/战术/持续、天赋、保留、虚无/消耗、随机生成、检索/选牌、复制、重复触发、代价 X、反弹与反制；当前仅其中部分。
- [ ] **职业深度**：五名武将新增各1张常驻能力卡，已支持与进攻、非攻击、主动弃换、亲兵及损血联动；下一步每人至少2–3个独立流派、与特定Boss机制对抗及非平凡多回合构筑。
- [ ] **药剂、遗物、先贤奖励可组合性审计**：完整事件触发顺序、冲突测试、加成叠加、被动可见性；当前主要为固定直接效果。
- [ ] **敌军行为/内容**：Boss 阶段转换、精英专属规则、异常/召唤/死亡语义、多敌军协同、敌军行为优先级；当前为简化 AI。
- [ ] **进一步的完整剧情深度**：在现有12类通用奇遇、28个带前置条件的演义残卷、25条关系和8项隐藏结局基础上，继续完成全本120回逐回正文审校、主要人物传记与史实对照、更多可互斥抉择、跨幕大型剧情和数值影响。当前不能称全本完成。
- [ ] **长期解锁深化**：当前标准战役已强制逐级解锁，尚欠时间线内容渐进解锁、藏品/挑战成就、完整图鉴详情与丰富自由挑战规则。
- [ ] **TUI**：键盘上下选择、卡牌快捷键、窗口宽度适配、语义化状态颜色和对比度无障碍、全局背包、国际化。
- [ ] **平衡验收**：按难度/职业/奖励池的胜率、死亡原因和软锁统计；无效动作模糊测试；完整故事路线覆盖；对局回放轨迹与崩溃恢复。
- [ ] 完整可复现实验、验收清单、性能目标以及稳定版 1.0 release。

## 测试标准

- 所有新增卡牌必须至少有一个规则回归测试或者卡牌族参数化测试；
- 任何失败 Action 不改变 `Game` 序列化结果、修订号或 RNG；
- 每个游戏场景既能在当前终端继续，也能从序列化快照恢复；
- GitHub macOS CI 和模拟器真实通过才标记完成；
- 社区 Wiki 数据、原作更新版本与项目实际覆盖必须分开写，不得仅以内容总量宣称完全复刻。
