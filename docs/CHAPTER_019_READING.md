# 第019回：下邳决水、献门与白门楼——单底本全回因果核读

- 核读日期：2026-10-26。固定底本：维基文库《三國演義》第019回 oldid=2567981，https://zh.wikisource.org/w/index.php?title=三國演義/第019回&oldid=2567981 。
- 阅读边界：自第018回三寨夹攻结果，到张辽骂曹、救者留待第020回揭晓的回末。下述均为小说叙事，不能据此宣称史实；未对照第二底本、《三国志》或裴注。

## 连续段落定位与人物责任

1. 「却说高顺引张辽击关公寨」至「匹马逃难」：第018回三寨围攻兑现，吕布乘刘备回小沛时守军怕误伤刘备而夺城；刘备弃家出走，吕布听糜竺劝后保全刘备妻小。不能写成小沛破城后吕布杀了刘备家人。
2. 「且说玄德匹马逃难」至「曹操乃令孙乾以金百两」：孙乾劝刘备投曹，途中猎户刘安杀妻供食，刘备事后才知，曹操得知后赏金。该残酷情节属于小说叙述，不把伤害无辜美化为可取行为或史实。
3. 「军行至济北」至「登就关上放起火来」：第018回夏侯惇伤目未愈；曹仁先攻小沛，曹操至萧关。陈登骗吕布、陈宫两头，借箭书、火号使两军夜间误击，陈登主动反间是战局变化的重要原因。
4. 「曹兵望见号火」至「便随操入徐州」：吕布被糜竺拒入徐州，又误信陈登回小沛，发现曹仁已占城；关张与刘备重会，刘备妻小平安，陈珪父子获赏。糜竺声称陈珪已死是城上应答，不能误写成真实死讯。
5. 「且说曹操得了徐州」至「宫出叹曰」：程昱防吕布联袁术，刘备守淮南通道。吕布先拒陈宫趁曹军未定出击，后又因严氏、貂蝉劝阻拒绝内外掎角及截粮计；建议时序有别，不能合并为一次进谏。
6. 「布于是终日不出」至「吕布回到城中」：许汜、王楷求袁术援兵，袁术要先送吕布女儿才发兵；郝萌被张飞擒后供出婚援之谋，曹操斩之。吕布背女突围因顾虑女儿安危而退回城中；袁术援兵并未抵达。
7. 「却说曹操攻城，两月不下」至「乃日与妻妾痛饮」：曹操一度想退，荀攸劝速攻；郭嘉、荀彧议决沂、泗之水，曹军据高地、下邳除东门外水淹。水攻加强围困，但不是吕布被擒的直接动作。
8. 「却说侯成有马十五匹」至「魏续便开门放出」：侯成追回被盗马匹，献酒请示却遭吕布鞭五十；宋宪、魏续因主帅苛罚及围城绝望谋献城，侯成盗赤兔献曹并约白旗。须区分重罚成因与背叛行为本身。
9. 「次日平明」至「操以棺椁盛其尸」：宋宪先盗画戟，与魏续缚吕布，曹军入城；高顺、张辽、陈宫分别被擒。曹操退水安民，高顺沉默被斩，陈宫拒降、曹操安排其家人后陈宫就刑。
10. 「方操送宫下楼时」至「且看下文分解」：吕布求刘备说情，刘备以丁原、董卓旧事警告曹操，吕布被缢死枭首。张辽痛骂曹操，曹操拔剑而旁人阻止；第019回并未揭晓救张辽者姓名，须与第020回接缝核对。
