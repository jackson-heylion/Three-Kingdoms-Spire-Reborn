## 正文行动与因果核查

1. 承接第031回史涣战死，袁尚自恃勇武，未等袁谭援军便出黎阳迎战；张辽击败袁尚，袁尚退回冀州。此战不是袁谭主动挑起兄弟内战。
2. 袁绍闻败后旧病复发，临终只能点头示意；刘夫人询问袁尚能否继位，审配当场拟遗嘱，随后袁绍死亡。遗嘱的形成过程与袁尚即位合法性争议不可省略。
3. 袁绍死后，刘夫人杀害五名宠妾并毁尸；袁尚又杀宠妾家属。这是小说描写的两组不同施害行为，不能归并成曹军入城屠杀。
4. 审配、逢纪拥立袁尚并遣使报丧；袁谭得知父死时正在离开青州的途中，不在冀州继位现场。
5. 郭图主张袁谭尽快接近冀州，辛评警告贸然入城有危险；袁谭采取驻军城外、派郭图探查的折中方案。
6. 袁尚以遗命为由自居继承人，给袁谭车骑将军名号，要求其抵御曹军。**封号不等于袁谭认可继位**。
7. 郭图要求审配、逢纪协助袁谭；袁尚不愿两人离开，只能让二人抽签，最终逢纪赴袁谭营中。不是逢纪自愿投奔袁谭。
8. 袁谭见逢纪愤怒欲杀，郭图因曹军当前劝暂留。此时逢纪未死，后面才有独立的处决触发条件。
9. 袁谭在黎阳出战，汪昭被徐晃斩杀，袁军败退。袁尚只拨五千援军，乐进、李典半途歼灭；援军数少与途中覆灭是两重原因。
10. 逢纪为袁谭写信向袁尚求援，审配判断破曹后袁谭必争冀州，建议不再援助。袁尚采纳后，袁谭才斩逢纪并讨论降曹。
11. 袁尚因细作报告袁谭拟降曹，担心曹袁谭合兵攻冀州，遂留下审配、苏由守城，自率军救援。**拒援与转而救援是两个先后决定**，并非同一时刻自相矛盾。
12. 吕旷、吕翔率袁尚先锋，袁谭得知袁尚亲来后取消降曹议，两军在黎阳成犄角。袁熙、高干随后到场增援。
13. 建安八年春，曹操击败袁氏各部并进抵冀州，袁谭、袁尚入城固守，袁熙、高干在城外虚张声势；曹军久攻不下。
14. 郭嘉指出袁氏废长立幼、各立党羽：急攻时兄弟相救，缓攻则内争。曹操采纳，暂转向荆州；这不是曹操因军事失败而永久放弃河北。
15. 曹军撤离后，袁谭欲借宴会伏杀袁尚；王修用兄弟如左右手的道理劝阻，袁谭斥退。袁尚与审配识破疑谋，先率军出城，两兄弟才正式交战。
16. 袁谭阵前指控袁尚毒杀父亲，这是**交战一方的指控**；本回正文并未提供袁尚毒杀袁绍的客观叙述，事件日志不得当成已证事实。
17. 袁谭战败奔平原，后派岑璧再战，岑璧被吕旷斩杀；袁尚追至平原三面围城。两次失利与围城应分开记录。
18. 郭图提出以降曹诱曹操攻冀州、迫袁尚回师、再夹击袁尚；同时计划利用曹军粮远退去后的空隙自据冀州。**袁谭向曹求援不是无条件真心归附**。
19. 辛毗携袁谭书信抵曹营时，曹操正进攻刘表，刘备为荆州前部。程昱、吕虔、满宠质疑袁谭诚意与改战线成本；荀攸主张抓住袁氏内乱机会。
20. 辛毗进一步从河北军疲、内部诛戮、饥馑和兄弟分裂推演可乘之势，曹操才决定回军攻冀州；刘备担心有诈，没有追击。**荀攸的战略判断与辛毗的形势分析不可互换署名**。
21. 袁尚闻曹军渡河急回鄴，命吕旷、吕翔断后；袁谭追军时劝二吕改投，二吕先降袁谭，随后依袁谭建议转投曹操。
22. 曹操以女许袁谭联姻，又收留并封赏二吕；郭图认为联姻未必真诚，袁谭秘密送两枚将军印，企图让二吕在曹营作内应。
23. 二吕立即把印送给曹操，曹操由此得知袁谭两面打算，开始有杀袁谭之意。**曹操怀疑袁谭的直接新证据是秘密授印**，不能提前写成婚约一成立便必杀袁谭。
24. 曹操先开白沟粮道，再向冀州推进；袁尚采纳审配安排尹楷、沮鹄守外线补给和声援，自己又率军攻平原。曹军先击破尹楷、沮鹄，才加重冀州孤立。
25. 曹洪先围鄴，曹操筑土山、挖地道；东门守将冯礼受审配处罚而投曹，带三百人从地道入城。审配识破并用石封突门，冯礼及随行者死于地道。**第一次地下突袭失败**，并非曹军直接凭地道破城。
26. 袁尚回援选择西山小路，曹操预判其会用火号联络城内。李孚假扮曹军都督入城通报袁尚位置，审配也举火回应；这构成双方可观察的信号链。
27. 李孚建议先遣老弱百姓出降，再以士兵突击；曹操预见此计，命张辽、徐晃伏兵击退出城军。曹操追至吊桥时遭城上弩箭险些射中，不应写成毫无代价的识破。
28. 袁尚援军败退西山，马延、张顗被吕旷、吕翔招降；曹军随后断粮并伏击，袁尚遣阴夔请降，曹操表面接受却夜袭，袁尚弃印绶辎重奔中山。
29. 袁尚退走后曹操再攻冀州，许攸提出决漳河灌城；初掘浅壕使审配轻视，曹军夜间加深，次日灌水且城中断粮。**决水之计发生在袁尚援军崩溃之后**，不是曹操第一次围城就成功水攻。
30. 辛毗在城外展示袁尚遗弃的印绶衣服劝降；审配杀害辛毗家属，审荣因与辛毗相厚且目睹此事而生怨，秘密射书约定献门。城破的近因是审荣开西门，水攻与断粮构成此前压力。
31. 曹操入城前命军民降者免死、不得杀袁氏家眷；审荣开门后辛毗率先入城。审配死战被徐晃生擒，拒绝曹操劝降并坚持面北受刑。其死不能写成投降后被误杀。
32. 曹操因审配忠于旧主而为其安葬，又赦免昔日写檄文辱及曹氏祖父的陈琳，任其为从事；曹操对二人的不同处置须保留动机与时序。
33. 回末曹丕不顾曹操禁入袁绍府的命令，闯入后堂见两名哭泣妇人；她们的后续身份、命运留待第033回，不可提前按后世常识在第032回完成结算。

## 跨回因果链与游戏化设计（尚未实装）

**A. 继位合法性与兄弟内战（031→032→033）**：袁绍未明确稳定交接 → 刘夫人和审配、逢纪推动袁尚继位 → 袁谭不服但曹军当前先合作 → 救援分歧与逢纪被杀 → 曹军撤退后袁谭伏杀计划暴露 → 两兄弟开战。建议分离 `succession_claim`、`fraternal_trust`、`cao_pressure`，不能以单一“袁氏内乱”布尔值抹平阶段。

**B. 袁谭求曹的双重博弈（032→033）**：平原被围 → 郭图主张假借归附求援 → 辛毗论证曹操转兵的收益 → 曹操介入 → 二吕转投曹操 → 袁谭秘密授印暴露其后手 → 曹操生杀意。建议“同盟可信度”与“共同敌人压力”独立计量；双方可以暂时合作却互不信任。

**C. 围鄴多阶段攻防（032战术关卡）**：外围粮道攻防 → 地道突袭失败 → 袁尚举火求援 → 城中假降与反伏击 → 袁尚西山败退、断粮 → 漳河水攻 → 审荣献门。每阶段有前置情报、行动窗口、敌方意图预告与明确状态转移；不能将全部阶段压成一次“决水伤害”。

**D. 反间与事件源事实层（031→032）**：第031回逢纪诬称田丰讥笑，第032回袁谭指控袁尚毒父，均属于**角色声称**；审荣献门和二吕献印则是可观察行动。建议事件源区分 `ClaimMade` 与 `ActionObserved`，对未证实指控不自动触发真实谋杀成就或历史台账。

**E. 审配的双面后果（032→033）**：严惩冯礼导致投敌、却识破地道；严守冀州、拒绝投降，却因杀辛毗家属激化审荣叛变。设计“军纪严厉”兼有防御增益和人心风险，避免把审配简化为纯粹无能或纯粹忠义。

**F. 曹丕闯府的跨回悬念（032→033）**：曹操禁杀袁氏家眷 → 曹丕违令进入府中 → 见妇人哭泣 → 结局留待后回。建议以 `cao_household_protection_order`、`cao_pi_entered_yuan_house` 记录两个可区分事实；不能在第032回自行完成后续婚姻或人物结局。
