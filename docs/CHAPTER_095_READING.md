# 第095回《马谡拒谏失街亭 武侯弹琴退仲达》固定单底本正文核读

固定单底本：[维基文库第095回 oldid=2568058](https://zh.wikisource.org/w/index.php?title=三國演義/第095回&oldid=2568058)，正文 L119–149；2026-10-27从回首至回末核读。**由此前ctext片段抽检升级为固定单底本全文通读；第二小说底本与史料全回校勘未完成。**

| 固定正文位置 | 因果、人物责任、时序及知情边界 |
| --- | --- |
| L119–122（回首） | 承094司马懿复任、张郃前锋；司马懿计划切街亭粮道，诸葛亮闻孟达被杀后委马谡、王平守街亭，明确命当道下寨、画地形图，另布高翔列柳、魏延接应、赵云邓芝箕谷疑兵。小说将统帅部署和前线执行分开。 |
| L123–124 | 马谡拒王平当道设寨及断水警告，执意屯山；只给王平五千人另扎营。当地居民报告魏兵到，王平绘图遣人报诸葛亮。**失街亭不是王平未提醒，也不是诸葛亮命令屯山**。 |
| L125–126 | 司马昭侦得山寨无当道营，司马懿张郃等断汲水路，马谡军乱、降逃；王平接应、魏延一度夺路又被包围，王平再救。马谡本回没有被处斩，责任追究延至096。 |
| L127–128 | 高翔魏延王平试图夜袭夺回街亭、列柳城，郭淮与司马懿先后据地；诸葛亮粮道危局加深，司马懿拟从西城斜谷截撤军。 |
| L129 | 诸葛亮收到王平图本才知马谡弃道上山，随后收到街亭列柳失守实报，自认用人之过；命张翼修剑阁、姜维马岱断后，安排三郡官民和姜维母亲迁往汉中。**迁民与粮草是具体后果，不可只讲空城计**。 |
| L130–131 | 西城仅剩二千五百军，司马懿大军逼近；诸葛亮藏旗、开城门、扮扫街居民、城头操琴，司马懿因其惯常谨慎而疑伏退兵。**这是小说情节，非陈寿正文已证的战役事实**。 |
| L137–139 | 诸葛亮令西城百姓随军入汉中，关兴张苞疑兵阻追、姜维马岱掩护，魏军损失辎重；撤离依靠分兵接应，不是琴声独自救全军。 |
| L141–142 | 赵云邓芝箕谷疑军有序退却，赵云后卫击退苏颙、万政，护送军资不失。小说的具体敌将与交战细节不可与史传混写。 |
| L143–149（回末） | 司马懿复查西城方知无伏，曹真郭淮复得三郡，魏廷谋进一步攻蜀，悬念交096退兵问责与斩马谡。 |

跨回：094孟达失机→095街亭粮道断、王平报图、诸葛亮撤军与西城疑兵→096马谡军法处置。原创玩法选择只改变**水源预警、军令留痕、撤民与军粮**，不改马谡违令、街亭失守或既定退兵。
