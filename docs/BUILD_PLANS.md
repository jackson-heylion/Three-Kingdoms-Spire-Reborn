# 五职业十五组构筑原型（设计验证 ≠ 胜率验收）

该目录由 `src/builds.rs` 驱动，CLI 输入 `builds` 查询角色三条路线、当前四张关键卡收集进度、专门敌方反制及弱点。所有核心与支援卡 IDs 必须存在于所属职业卡池，Rust 单测强制验证，不自动授予玩家。

|---|---|---|

## 验收要求（当前未通过）

这15套是**可取得卡池的设计蓝图**，不是按实战数据证明可通关的成熟构筑。每套还必须进行固定种子和两类以上策略机器人配对测试，收集 0–10 飞升下胜率、成型回合/楼层、商店或奖励取得概率、对抗该套指定 counter_enemy 的失败率、软锁与真人试玩反馈。不能只靠构筑卡牌ID合法就宣称“平衡已完成”。

推荐按“独立模板卡组 vs 自然抽牌”和“指定敌人 vs 常规敌人”四象限固定种子成对比较，结果附脚本、commit SHA 和原始 JSON，避免选择有利种子。当前先提供可追踪、可读的构筑与风险目录，不改默认牌池掉率。
