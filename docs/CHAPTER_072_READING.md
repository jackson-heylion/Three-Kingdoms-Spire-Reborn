# 第072回《诸葛亮智取汉中 曹阿瞒兵退斜谷》固定单底本全文核读

2026-10-27。固定底本：[维基文库 oldid=2568036](https://zh.wikisource.org/w/index.php?title=三國演義/第072回&oldid=2568036)，正文 L119–150 连续核读（回首至「未知曹操性命如何」）。这是单底本叙事审读，**不是**第二小说底本异文对校。

| 原文行 | 因果、责任与信息边界 |
|---|---|
| L119 | 接071徐晃执意渡汉水：黄忠、赵云忍至曹军退动而夹击；徐晃欲杀谏阻者王平，王平烧营转投刘备，提供汉水地理。 |
| L120–123 | 曹操亲争汉水寨；孔明使赵云鼓角虚惊三夜、诱曹退三十里；刘备背水列阵弃军器，曹操虽疑而撤迟，黄忠赵云夹攻。 |
| L124–125 | 张飞魏延断粮、黄忠赵云焚山，许褚醉护粮夜行，被张飞刺伤，粮车尽失；粮道并非只有一次失误。 |
| L126–127 | 曹操再战败退阳平、曹彰援至斜谷，刘封孟达出战、马超吴兰夹攻，曹彰杀吴兰，战局未因援军逆转。 |
| L128 | 曹操进退两难说鸡肋，杨修推断退军、擅令收拾，曹操以乱军心杀之；这不是已经正式发布的退兵令。 |
| L129–136 | 小说追叙杨修解门字、分酥、识梦杀、曹丕曹植争储与答教；这些插叙解释曹操积怨，不能倒置为本回新发生事件。 |
| L142–150 | 曹操再出战、魏延射中其人中、庞德救主，曹操追葬杨修并下令撤军；回末斜谷伏兵追至，生死悬念留073。 |

**衔接**：071徐晃渡汉水→072败渡、王平归刘、斜谷撤军→073曹操退京兆与刘备进位。小说杨修死因、曹彰阵前战果及曹操伤势不得直接当《三国志》事实。正史局部对勘另见 CHAPTERS_072_074_HISTORY_SPOTCHECK.md。未做第二底本对校、全回史料校勘或真人试玩。
