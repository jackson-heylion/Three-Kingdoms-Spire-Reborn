# 第055回《玄德智激孙夫人 孔明二气周公瑾》单底本全文因果核读

2026-10-27。固定小说底本：[维基文库 oldid=2568018](https://zh.wikisource.org/w/index.php?title=三國演義/第055回&oldid=2568018)。连续核对 L119–152；**不冒充第二小说底本对校**。

| 正文位置 | 情节因果、人物责任、时序与知情范围 |
|---|---|
| L119–122 | 承054洞房刀剑悬念：孙夫人命撤兵器，婚礼落实。周瑜因假婚成真再献软困之策，孙权与张昭同意，刘备在东府安逸而迟不回荆州。国太只以为孙权善待新人，不知软禁谋划。 |
| L123–126 | 年终赵云开第二锦囊，假报曹操五十万兵攻荆州，刘备向孙夫人诉思乡与危局；夫人主动愿同行并提出正旦借祭祖出城。军情是锦囊话术，不是已经发生的曹军进攻。 |
| L127–128 | 建安十五年元旦，孙夫人获国太许可祭祖，二人率五百随从离南徐，故意瞒孙权；孙权酒醉至次日才知，先命陈武潘璋追，后命蒋钦周泰持剑追杀妹妹与刘备。不能把追令说成孙夫人授意。 |
| L129–131 | 周瑜预置徐盛丁奉拦路，赵云开第三锦囊，刘备坦言婚姻诱捕真相；孙夫人当面斥二将，二将退让。此处关键行动来自孙夫人，而非赵云单独武力破关。 |
| L132–133 | 陈武潘璋会合前军，再被孙夫人斥退；蒋钦周泰持孙权剑令加紧追赶，追令升级与夫人交涉分属不同环节。 |
| L135–143 | 刘郎浦缺船危机，孔明预置二十余船接应，刘备、孙夫人、赵云与五百人登船；孔明现身后追兵才到。不能把第三锦囊与渡船安排颠倒。 |
| L145–152 | 周瑜亲率水军追到黄州岸边，关羽先伏、黄忠魏延左右出击，吴军败退，周瑜箭疮复裂昏厥；回末只是昏厥，**不能写为第055回已死**，第056回开篇仍有周瑜行动。 |

跨回：054结亲与三锦囊→055归荆；055周瑜昏厥→056救醒、改施假途灭虢。原创孙氏军簿只能记录追令、护卫与军民伤耗，不改变小说人物生死。

未验：第二底本逐字异文、全回史实核证、自然地图多种子与真人试玩。
