# 《三国演义》第007回正文通读：冀州易主、磐河转折、孙坚之死

审读日：2026-10-20。单一底本：[维基文库《三國演義/第007回》固定修订 oldid=2567970](https://zh.wikisource.org/w/index.php?title=三國演義/第007回&oldid=2567970)，题为「袁紹磐河戰公孫　孫堅跨江擊劉表」。核读范围：开篇孙坚被刘表围困后的突围，至回末桓楷试图交换孙坚遗体、蒯良要求先杀来使的悬念。**只审核该固定底本的整回叙事与因果，尚未做毛评本、版本异文和《三国志》《后汉书》史料逐字对校。**

## 本回正文时间线与不可混淆的因果

1. **第006回不是孙坚死亡之回。**第007回开篇，程普、黄盖、韩当救孙坚脱围，孙军折损甚大，孙坚与刘表结怨。这一段承接前回刘表拦截；后半回另起的讨刘表战争才造成孙坚死亡。两次冲突不可压成一场。
2. **冀州政变不是韩馥无缘由自愿让贤。**袁绍在河内缺粮，先收韩馥馈粮；逢纪策划以同攻分地为诱饵使公孙瓒逼冀州，再暗报韩馥，促其迎袁绍“共同治理”。荀谌、辛评力劝韩馥，耿武直言此举引敌入州。韩馥让州后，袁绍给他名义官衔，实际将政务分予田丰、沮授、许攸、逢纪等，韩馥失权出走。
3. **耿武、关纯之死与公孙越之死责任层次不同。**耿武、关纯在袁绍入城时行刺，明确分别被颜良、文丑杀死。公孙越返程遇伏，伏兵自称董卓家将；公孙瓒断定袁绍假扮董军杀弟，这是小说人物对幕后主使的指控，不能写成叙述者直接展示了袁绍下令伏击。
4. **赵云出场并非立刻归刘备。**公孙瓒在磐河桥遭文丑追杀，赵云出场与文丑大战，表明原属袁绍而因其无救民之心改投公孙瓒。此处赵云只入公孙瓒军。后与刘备相见，二人互相敬爱，末了分离。若游戏将「磐河救主」直接叙述为赵云首次投刘备，便提前并错置小说顺序。
5. **磐河战存在明显双向逆转。**袁绍遣麴义带八百弩手及步军伏击，公孙瓒先锋严纲阵亡、帅旗被斩，公孙军大败；麴义冲到后军遭赵云刺死，赵云突入袁军，公孙瓒反击。这不是单凭白马骑兵先手取胜，弩兵与旗帜共同构成阵地崩溃机制。
6. **袁绍本人也不是全程逃窜。**他起初据报捷讯率少量侍从观战，赵云逼近时，田丰建议躲入空墙，袁绍拒绝。卫士阻住赵云，袁绍后援与颜良部跟进，袁军再次过桥追击。刘备、关羽、张飞三人随后赶到迫袁绍退走，双方各有攻守，不是一场单线英雄个人碾压。
7. **停战靠董卓借皇帝名义发诏。**袁绍失利后两军相持月余；李儒建议董卓借天子诏书调停，马日磾、赵岐奉诏宣谕，两军暂和。公孙瓒举荐刘备为平原相。赵云与刘备相惜却分手；不能写作战场结束即正式三家合军、刘赵永远同行。
8. **袁术推动孙坚再战，是袁氏兄弟与荆州补给争执的连锁。**袁术求马于袁绍、借粮于刘表，均遭拒，转而致书孙坚，声称袁绍、刘表密谋江东，并许诺两面分取冀州、荆州。程普提醒袁术多诈；孙坚仍凭个人旧怨进兵。原著没有将袁术指控证实为事实。
9. **孙坚渡江先以诱箭破敌，随后占优势。**孙静劝他顾及刚安定的江东、不要为旧怨轻启大战，孙坚不听，孙策随征。孙坚三日诱使黄祖兵消耗箭矢，收取大量射来之箭，乘顺风反射登岸，继而韩当、程普、黄盖等分兵击败黄祖。孙策射杀陈生、韩当斩张虎；蔡瑁败逃，刘表因姻亲关系不愿惩治。不能把孙坚失败写成渡江即败。
10. **致命败局起于决策孤进和有组织的伏击。**攻襄阳时帅旗被狂风折断，韩当主张暂退，孙坚拒绝。蒯良策划吕公佯装突围，山林预设石弓伏兵与连珠号炮。孙坚不召诸将，仅带三十余骑追出，单骑先入山谷而遭矢石击杀；该底本称享年三十七岁。这里的死亡因果是追击决策、伏击地形和侦察缺失，不应抽象成“天命不佑”。
11. **孙策获得的不是完整胜利。**吕公随后战死，黄盖生擒黄祖，孙策发现父亲遗体落在刘表处。桓楷自请入城，以黄祖换孙坚遗体；刘表初步同意，蒯良在回末建议先杀桓楷。**本回到此悬而未决**，不得把桓楷已经遇害或换尸已经完成当成本回正文事实。

## 跨回与跨幕因果建议（尚未实现为游戏选项）

- **第006回荆州拦路→第007回复仇动员→孙坚阵亡→孙氏继承困局**：宜以「公开袁术密信来源 / 听程普查证 / 追击旧怨」三种互斥选择建模信任、侦察与战术代价，而非为玩家赠送单一无风险奖励。区分《演义》本线已定结局与游戏假设支线。
- **冀州粮援→逢纪外交通牒→韩馥失权→磐河白马与弩阵**：可作为袁绍阵营跨幕政治负债，落实军粮、盟约、军阵反制，而非只在回目里写“袁绍夺冀州”。
- **磐河赵云→刘备平原相→后回再会**：用于角色羁绊的慢变量；前置不允许「磐河即赵云永久入刘备阵营」。适合用盟军临时援护与离队表示。
- **孙坚玉玺线（第006回）与孙坚岘山线（第007回）不强制联因果**：小说直接给出的再战动机是刘表拦截旧怨和袁术来信，不是孙坚已经公开玉玺，所以被刘表杀害。可设计政治怀疑支线，但必须标明原创推演。

## 回合边界、质量与结论

第007回为前6回叙事因果的实质延续，同时明确引入赵云归属、袁绍的政治操纵及孙坚身亡三条后续长链。已经通读固定底本全回并归纳相应场景，但**没有对比不同版本的正文词句、没有逐条用正史核验人物履历，也没有把这些设计建议写入可选择的游戏事件**。
