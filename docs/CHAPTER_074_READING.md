# 第074回《庞令明抬榇决死战 关云长放水淹七军》固定单底本全文核读

2026-10-27。固定底本：[维基文库 oldid=2568037](https://zh.wikisource.org/w/index.php?title=三國演義/第074回&oldid=2568037)，正文 L119–146 从开篇至回末连续核读；非第二底本全回对校。

| 原文行 | 因果、责任与信息边界 |
|---|---|
| L119–121 | 接073先锋悬念：曹操遣于禁率七军、庞德为先锋；董衡质疑庞德旧主及兄在蜀，曹操一度收印，庞德申辩并抬榇明志，贾诩劝戒。 |
| L122–126 | 关平先战庞德，关羽继战；庞德佯拖刀射中关羽**左臂**，关平救父，非关羽在本回末的右臂中箭。 |
| L128–129 | 于禁因忌庞德建功鸣金收军，又不准乘关羽伤病进攻，移七军至罾口川低地，庞德被隔于谷后。 |
| L130–131 | 关羽见低洼及连日秋雨，预备舟筏、堵水口，小说明写主动放水；成何预警于禁而遭斥，庞德拟次日移营已晚。 |
| L131–132 | 洪水夜至，于禁率残兵降；庞德与董衡董超成何死战，董衡董超求降被庞德斩，成何战死；周仓水中擒庞德。 |
| L136 | 关羽收禁候审，庞德拒降被斩并葬，二人结局不同，不能把庞德写成投降。 |
| L137 | 曹仁欲弃樊，满宠劝固守，城中军民填土修城，水退后仍未失城。 |
| L139–146 | 关兴报捷赴成都，关羽攻樊城北门，曹仁令弩射中关羽**右臂**，回末留075刮骨疗毒；本回未发生刮骨。 |

**关键史实边界**：《三国志》卷36写秋雨汉水暴溢、于禁降、庞德死，没有将水患归于关羽主动决堤；卷18《庞德传》写射中关羽额部，与小说左臂不同。史实、小说和游戏原创账簿严格分开。未校第二小说底本及史料全回。
