| L120–122 | 东吴书告曹操夹攻并请保密；董昭主张把消息射入樊城并告关羽，既稳曹仁又促关羽退；徐晃假旗诱关平出偃城、夜袭四冢，关平廖化退。吴方秘密、曹方故意泄密、关军误判分属三条信息链。 |
| L123–126 | 关羽轻信吕蒙病危、陆逊年轻，负右臂伤与徐晃战后遭曹仁夹攻，败退得知荆州失守、傅士仁糜芳降吴，怒至创口裂开；问为何烽火不举才获知白衣商船伏兵。遣马良、伊籍赴成都求援，非已经获得援军。 |
| L127–130 | 曹操奖徐晃解围并留守襄阳；关羽致书吕蒙责盟，吕蒙厚待使者、关军家属并送书信；家属安全消息使关军斗志瓦解。此处民政安抚与离心效果同时成立。 |
| L131–133 | 蒋钦韩当周泰等连环阻击，关军只剩数百，关平廖化救出后退麦城；廖化带关羽求救书突围去上庸，麦城并非尚未被围。 |
| L139–140 | 刘封、孟达据上庸，孟达以兵少、曹吴两强与刘封继嗣旧怨劝拒，刘封以新附民心未定回绝廖化；廖化转赴成都。此为小说内说辞，不是可验证的唯一历史动机。 |
| L141–142 | 诸葛瑾入麦城劝降，关羽拒降，关平欲杀使者但被关羽阻止；孙权问策，吕范卜得敌向西北奔，吕蒙布伏悬念留077。不能提前写关羽已突围或已被杀。 |
