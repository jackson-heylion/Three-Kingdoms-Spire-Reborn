# 第087回《征南寇丞相大兴师 抗天兵蛮王初受执》固定单底本正文核读

固定底本：[维基文库第087回 oldid=2568051](https://zh.wikisource.org/w/index.php?title=三國演義/第087回&oldid=2568051)，正文 L119–149。2026-10-27 按该固定修订从回首至回末核对。**单底本全文通读，不代表第二小说底本异文或史料全回对校。**

| 正文锚点 | 情节因果、责任及信息边界 |
| --- | --- |
| L119–121（回首） | 承086南方雍闿孟获警报：诸葛亮因永昌被围奏请南征，后主担心魏吴，诸葛亮列举李严、马超及留守安排；王连反对丞相亲征、忧瘴疫，未被采纳。关索自称荆州失陷后养伤归队，属小说人物线索，不能当作已获史证。 |
| L122–130 | 雍闿、高定、朱褒分兵，鄂焕被魏延、张翼、王平擒获；诸葛亮放还并设反间，高定因疑雍闿杀之，又令鄂焕杀朱褒，三路军平。**小说将杀雍闿设计成诸葛亮诱导，高定承担直接杀害责任；《吕凯传》陈寿正文另载诸葛亮到南前雍闿已被高定部曲杀，须严格分层。** |
| L131–133 | 王伉迎军、举吕凯守永昌之功，吕凯献《平蛮指掌图》；马谡携诏到军中并提出攻心重于攻城的策略，诸葛亮采纳。小说把具体图名、对白和军令连成一线，不能反推为陈寿逐字记载。 |
| L134–140 | 孟获遣金环三结、董荼那、阿会喃三洞迎敌；诸葛亮激赵云魏延探路，张嶷张翼、王平马忠与关索分路设伏。金环三结被杀，董荼那与阿会喃被擒后释放，尚未被孟获杀害（死亡发生于088）。 |
| L141–149（回末） | 孟获追王平、关索，赵云堵路、魏延伏兵**第一次擒孟获**；诸葛亮释放被迫从军者、问孟获是否心服，孟获否认，诸葛亮放其归去。第一擒并非七擒全结，088承接渡泸水再战。 |

跨回：086结盟及南征筹备→087永昌解围、攻心方针与初擒→088泸水暑毒、第二第三擒→089西洱河与毒泉、第四第五擒→090继续南中征战。游戏可改原创军民责任账、卡牌和资源，不改小说固定死生、擒放次数和战果。
