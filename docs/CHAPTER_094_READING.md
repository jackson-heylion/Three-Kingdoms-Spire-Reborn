# 第094回《诸葛亮乘雪破羌兵 司马懿克日擒孟达》固定单底本正文核读

固定单底本：[维基文库第094回 oldid=2568057](https://zh.wikisource.org/w/index.php?title=三國演義/第094回&oldid=2568057)，正文 L119–146；2026-10-27从回首至回末核读。**单底本全文通读；异本及史料全回校勘未完成。**

| 固定正文位置 | 因果、人物责任、时序及知情边界 |
| --- | --- |
| L119–122（回首） | 承093郭淮求援；曹真允以和亲利诱西羌彻里吉，雅丹越吉率小说所谓十五万铁车军袭蜀后方。韩祯报西平关，诸葛亮遣关兴张苞马岱，初战因铁车受挫，关兴被围。数字、称谓和族群叙述属于小说，不得当作史实。 |
| L123 | 关兴遇险，小说写关羽显圣指路，张苞亦称受其指引来救；这是小说神异叙事，不可将超自然援救写成可证战场事实。 |
| L124–125 | 诸葛亮带姜维等赴援，预判大雪、用空寨诱铁车深入覆雪陷坑；关兴斩越吉、马岱生擒雅丹。诸葛亮解缚、归还羌俘与车马，使其归国；**战术胜利之后仍有真实的俘虏处置责任**。 |
| L126–127 | 曹真郭淮误以为蜀军因羌援而退，追击中曹遵被魏延杀、朱赞被赵云杀；魏廷闻败后钟繇荐司马懿，曹叡复其职。小说此前反间罢官不等于史传已证事实。 |
| L128–135 | 李丰持李严转交孟达来书，诸葛亮忧司马懿复职会破孟达举事，反复告诫谨密、不要轻信一月往返的估算；孟达自恃地远，低估司马懿急行军。 |
| L136–137 | 申仪家人、李辅、邓贤告密；司马懿不待奏请即发兵，梁畿先持檄迷惑孟达，途中徐晃来援，截获诸葛亮密信。告密与军令速度是败因之一，不是单纯孟达勇怯。 |
| L138–139 | 申耽申仪假意响应、李辅邓贤献城，徐晃在小说中被孟达射中额头当晚死；孟达被申耽杀。**徐晃史传记太和元年病笃而卒，不记孟达射死**。 |
| L140–146（回末） | 司马懿向曹叡说明先发制人的理由，荐张郃为先锋，二人准备迎蜀军；下回095街亭战略由此展开。 |

跨回：093魏军求援→094羌兵败、归还俘虏→司马懿获用与孟达败亡→095魏军逼街亭。游戏原创选择仅审计俘虏遣返、密信保密与军民损失，不让玩家改变孟达、徐晃小说结局。
