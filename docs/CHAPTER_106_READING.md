# 第106回《公孙渊兵败死襄平 司马懿诈病赚曹爽》单底本全文通读

固定来源：[维基文库第106回 oldid=7909163](https://zh.wikisource.org/w/index.php?title=三國演義/第106回&oldid=7909163)，正文 L119–142。2026-10-28从回首核至回末。状态：**单底本全文通读**；第二小说底本与史料全回校勘未完成。

| 正文锚点 | 责任、时序与知情边界 |
| --- | --- |
| L119–120（回首） | 承105毌丘俭告急，追述公孙氏辽东世系、孙权使节被杀、公孙渊自立燕王。贾范、伦直反对称王而被杀；怪异征兆为小说/传闻，不可当作确证灾变。 |
| L121–122 | 曹叡令司马懿率四万征辽东；司马懿佯弃辽隧营地逼卑衍杨祚回救襄平，首山交战后公孙渊闭城。四万与时间估计属本回叙事，不等于每段战术都有史传对应。 |
| L123–127 | 秋雨围城、粮船补给，裴景和仇连请移营，仇连被斩；司马懿暂纵樵牧、等城中粮尽，曹叡拒撤军并续运粮。流星预示属小说神异，不能把预言当战术因果。 |
| L128–129 | 公孙渊两次议降失败，王建、柳甫被杀；父子夜逃被擒斩，襄平陷落，司马懿诛公孙宗族并称安民。**杀戮与安民告示同时存在**，玩家不可只记平叛功绩。 |
| L130–132 | 时间跳至魏明帝病重：小说写毛后索命为病因，曹叡先拟曹宇辅政，刘放孙资转荐曹爽，司马懿回朝共同受托；曹芳继位。**病因神异与宫廷政治必须分层**。 |
| L133–136（回末） | 曹爽掌禁军、何晏等专权，司马懿退居称病；李胜探病受骗，曹爽随曹芳出城谒高平陵，司马懿动兵。**第107回才发生洛水政变、曹爽失权与被诛**。 |

跨回：105公孙渊叛报→106辽东围城/屠戮→曹叡托孤曹芳→司马懿诈病→107高平陵事变。游戏用后继曹魏档案审阅围城粮雨、宗族处置与托孤交接，不让已故曹操参与战事。
