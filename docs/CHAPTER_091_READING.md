# 第091回《祭泸水汉相班师 伐中原武侯上表》固定单底本正文核读

固定单底本：[维基文库第091回 oldid=7909162](https://zh.wikisource.org/w/index.php?title=三國演義/第091回&oldid=7909162)，正文 L119–174；2026-10-27从回首至回末连续核读。**单底本全文通读，未完成第二小说底本与史料全回校勘。**

| 锚点 | 因果、责任、时序、知识边界 |
| --- | --- |
| L119–137（回首） | 承090班师泸水受阻；孟获说旧俗杀49人祭水，诸葛亮拒绝再杀生人，以面裹肉作人头祭物，董厥读祭文，记蜀兵与南人亡者；风浪止、渡泸水。祭文和鬼魂散去属小说宗教/神异叙事，不能据此推断馒头历史起源或真实水文因果。王伉吕凯守四郡，孟获返治，刘禅迎军，死者家属获抚恤。 |
| L138–139 | 叙曹丕与甄氏、郭氏、曹叡关系；曹丕病重托曹真陈群司马懿等，曹休入宫；曹丕卒、曹叡继位。猎鹿故事的史料层级待区分，不能将宫廷私事全当陈寿正文。 |
| L140–150 | 蜀细作报司马懿领雍凉兵；马谡提出伪造谋反告示离间，曹叡听群臣意见，曹真反对贸然杀司马懿，曹叡最后罢其职。此为小说因果链，不能直接据此称司马懿史实因诸葛亮离间而被免。 |
| L151–164 | 诸葛亮向刘禅呈《出师表》，包含开张圣听、内外同法、任贤、三顾与先帝托孤、南方已定北定中原。表文有独立史料传本，**小说引录与历史文献应分层核对**。 |
| L165–167 | 刘禅担忧远征、谯周天象谏止，诸葛亮配置留守与前军将吏；赵云争当前锋，邓芝愿同往，北伐军启程。与卷44蒋琬传所记留府供给可作局部对照。 |
| L168–174（回末） | 魏廷接到蜀军入境报告，夏侯楙请兵报父仇，王朗谏其未历战，曹叡仍委其统兵；军赴长安，悬念交092。 |

跨回：090泸水阻渡→091拒杀祭亡与军属抚恤→曹魏继位/蜀魏外交军报→《出师表》及前锋任命→092子午谷争论、赵云战阵。游戏只能改变**档案保存、粮草与责任兑现**，不得改曹丕病卒、司马懿小说被免或北伐出师。

未校：第二小说底本全回异文、祭祀与馒头起源、甄后与曹叡史传细节、反间榜文真实性、出师表异文和北伐出师年份细节。
