# 第090—092回局部史料核证（不是全回异本/史料校勘）

固定小说版本：090 [oldid=2568053](https://zh.wikisource.org/w/index.php?title=三國演義/第090回&oldid=2568053)、091 [oldid=7909162](https://zh.wikisource.org/w/index.php?title=三國演義/第091回&oldid=7909162)、092 [oldid=2568054](https://zh.wikisource.org/w/index.php?title=三國演義/第092回&oldid=2568054)。固定史料：陈寿《三国志》[卷35 oldid=2115776](https://zh.wikisource.org/w/index.php?title=三國志/卷35&oldid=2115776)、[卷44 oldid=12068919](https://zh.wikisource.org/w/index.php?title=三國志/卷44&oldid=12068919)。**仅核以下具体段落，不将局部史证记为全回完成。第二小说底本异文全回对校及史料全回校勘均为0/120。**

1. **090 L128–147 六七擒与地方治理。** 卷35陈寿正文记「三年春，亮率众南征，其秋悉平」；裴松之注引《汉晋春秋》才记七纵七禽、孟获服从与不留外官兵的三条理由。小说细化为木鹿驱兽、盘蛇谷藤甲火攻、兀突骨死亡、诸葛亮自责及第七擒归服。**不能说陈寿正文记载藤甲三万人焚死**，也不能据小说“誓不再反”认定历史永久无叛乱。
2. **091 L119–137 祭泸水。** 小说拒绝49人头祭、用面肉代祭并抚恤双方亡者；卷35相关南征概述未记此祭及馒头创制。神异风浪与食品起源仍须独立证据，原创玩法只记战亡抚恤和渡河责任。
3. **091 L151–167 出师表与北伐。** 卷35陈寿正文保存《出师表》并记诸葛亮屯汉中；可对照其「五月渡泸，深入不毛」「今南方已定」及任贤、开张圣听。小说将反间司马懿、谯周天象和前锋请战串成连贯叙事，不得把这些全部归入陈寿正文。
4. **092 L119 子午谷。** 卷35裴注引郭冲说诸葛亮曾用魏延万人异道的建议；裴松之随即质疑，并引《魏延传》魏延每欲请精兵万人、异道会潼关而不许。小说写五千人走子午谷、十日至长安、诸葛亮拒绝。**三者不能混为同一无争议方案**。
5. **092 L119–151 首次北伐时序。** 卷35陈寿正文记建兴六年春，赵云邓芝为箕谷疑军，诸葛亮亲率主力攻祁山，南安、天水、安定三郡响应；小说写赵云斩韩德父子、安定南安计取、姜维于回末识破诈信。史书不据此证实韩德五将与夏侯楙被擒。
6. **092 L143–151 姜维尚未归蜀。** 卷44《姜维传》陈寿正文记太守闻蜀军至而疑姜维，夜逃上邽，姜维被拒城外后才诣诸葛亮；裴注引《魏略》对细节另有不同叙述，且明确「此语与本传不同」。小说092只到姜维识破伪信，不能把093归降提前，更不能把两种史料说法合并为一个已核定经过。

未校：真实第二小说底本全篇异文、裴注引书可靠性、史料中南中族群和地理考证、曹叡继位宫廷逸事的完整史源；不得以游戏原创选择替代原著/史实。
