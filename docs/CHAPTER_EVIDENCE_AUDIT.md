# P1 文学审读证据一致性检查（2026-10-24）

运行：python3 scripts/analyze_chapter_evidence.py --json

该工具只验证审读证据的元数据，不证明原文已读、文本结论正确、异本已校勘或剧情已经实装。

## 当前主干基线

- 120回均有台账行；001–011共11回登记为单底本通读，076、084、095共3回仅片段核查。
- 25回有已合并的审读材料，其中012–016、032–040共14回尚未登记；第033回只有10项摘要，不能当成完整异本校勘。
- 0/120回完成异本与《三国志》裴注的逐段史料对校。

## 检查边界

脚本拒绝章节编号缺漏/重复、来源URL不匹配、错误审读状态、已登记但无固定oldid、文件oldid与台账不符，以及已登记却无审读文件。001/002共享一份双回审读文档。已合并的文件只计“材料存在”，不自动升级台账状态。

JSON结果始终标注 collation_verified_by_this_tool=false、gameplay_verified_by_this_tool=false。测试覆盖正常/错误台账及实际仓库结构；现有CI会自动发现 tests/test_analyze_chapter_evidence.py。

后续须逐回核对14份材料与固定底本，确认因果准确后再更新TSV及章节库存。此增量不修改游戏数值、存档格式或正式1.0验收状态。
