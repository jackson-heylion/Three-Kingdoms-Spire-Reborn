# 《三国演义》第039回单底本因果审读：江夏余波、登楼求计与博望初战

- 回目：荆州城公子三求计，博望坡军师初用兵。
- 固定底本：维基文库《三國演義/第039回》，`oldid=2567999`，https://zh.wikisource.org/w/index.php?title=三國演義/第039回&oldid=2567999
- 阅读范围：本回从黄祖败逃到诸葛亮预告曹操再举大军，按叙事顺序核查；本记录属于**单底本正文通读与游戏改编审查**，不是异本校勘、史实考证或已上线剧情的验收。
- 边界：第038回末黄祖尚未被擒，苏飞为俘虏；第039回才完成黄祖之死、苏飞获赦。第039回末博望初战已胜，曹操大军南下的应对之计尚未展开。

## 一、逐段人物行动与因果核查（30项）

1. 孙权进攻夏口后，黄祖自知守不住，弃江夏往荆州逃；不能将其结局提前写入第038回。
2. 甘宁预判黄祖走东门，先在门外埋伏；追击是有路线判断的行动，不是随机遇敌。
3. 黄祖以往日待遇辩解，甘宁反指其轻慢旧功；两人言辞均属于人物立场，不能直接写成客观评价。
4. 程普追来，甘宁担心争功，射杀黄祖并取首级；需区分甘宁的动机与黄祖已死的事实。
5. 孙权准备以黄祖首级祭父孙坚，军事胜利连接孙氏家族旧怨。
6. 张昭判断江夏孤城难守，建议撤军回江东，以逸待劳；孙权采纳。击败黄祖不等于立即长期占有江夏。
7. 苏飞被押时托人向甘宁求救；他仍活着，并未因黄祖之死自动获释。
8. 孙权本欲将苏飞与黄祖同斩祭父；甘宁提出旧恩、愿舍官爵为苏飞请命。
9. 孙权担心苏飞获赦后逃走；甘宁愿以自身性命作保。赦免的条件与风险承诺须保留。
10. 孙权赦免苏飞，只以黄祖首级祭奠；这是甘宁请命和孙权裁决共同作用的结果。
11. 凌统因父凌操曾被甘宁射死，席间拔剑寻仇；其愤怒不是凭空生成。
12. 孙权以昔日各为其主劝止；并未消除凌统的私人仇恨。
13. 孙权令甘宁领兵与战船往夏口镇守，以空间分离缓和冲突；同时加封凌统，关系仍存隐患。
14. 东吴造船、分守江岸、孙权屯柴桑、周瑜练水军，构成战后防御准备；不能写成江东立刻发动荆州总攻。
15. 刘备获悉黄祖被杀、孙权屯柴桑；刘表随后召其入荆州，诸葛亮推断可能为商议复仇，推断不等于确证。
16. 诸葛亮先建议刘备向刘表说明襄阳遇害旧事，并避免仓促应允攻吴；考虑曹操南下威胁。
17. 刘表表示知道蔡瑁谋害之事并已宽恕；刘备主动淡化蔡瑁责任，不代表事件从未发生。
18. 刘表因黄祖遇害商议报复；刘备以曹操可能南下为理由劝慎战。
19. 刘表病老，提出身后以荆州相托；刘备不愿乘人之危，诸葛亮与刘备对此判断不同。
20. 刘琦向刘备求救，称继母不容；这是刘琦对自身处境的陈述，尚不能将全部幕后行动当作已证实事实。
21. 诸葛亮顾忌卷入家事、泄密招祸而拒答；刘备私下指导刘琦如何再次求计。
22. 刘备托病令诸葛亮代访，刘琦在后堂与宴席两次求计均未成功；第三次才诱其登楼。
23. 刘琦撤梯封路、以自尽相逼，诸葛亮才提出避祸之策；此计并非无条件自愿授出。
24. 诸葛亮借申生、重耳典故说明内外之势，建议刘琦请求出镇江夏；典故是劝说逻辑，不是未来安全的保证。
25. 刘琦奏请出镇，刘表犹豫，刘备出言支持，最终刘表派刘琦率三千人守江夏。计策须经两次政治决策才落地。
26. 曹操议南征，夏侯惇主张先攻新野；荀彧与徐庶劝不可轻敌，夏侯惇轻视诸葛亮。双方情报并非一致。
27. 刘备以师礼待诸葛亮，关羽张飞不服；诸葛亮指出刘备兵少、提议募民兵三千并操练，先补军力才迎敌。
28. 夏侯惇军到，诸葛亮向刘备借剑印取得号令权，布置赵云诈败、刘备接应、关张伏击粮道、关平刘封放火等多路任务。
29. 赵云多次诈败诱敌，韩浩提出伏兵警告；夏侯惇不听。于禁李典识破火攻地形后再警告，但因军队已深入狭道而来不及阻止。
30. 火攻成功后，赵云反击、关羽截粮、张飞击杀夏侯兰，曹军溃退；关张服膺诸葛亮。诸葛亮随即预告曹操可能亲征，下一回的应对不能在此提前结算。

## 三、可落地的游戏改编方案

**新事件：博望军令（诸葛亮，第一幕，第039回）**

- 触发条件：玩家为诸葛亮、已取得 `longzhong_plan`，且本次战役尚未见过 `bowang`。
- 决策：`依剑印分兵诱敌、护住粮道与民兵`（置 `bowang_fire`，奖励一张 `huogong`）或 `抢功急进、只求先破敌锋`（得金币，不置旗）。
- 必须保留赵云诱敌、关平刘封纵火、关张两翼配合、夏侯惇轻敌与于禁李典警告过晚的因果；不可把“孔明一人施法点火”当作军事事实。
- 第一幕旗标可以与第二幕 `redcliff_wind` 共同触发新增隐藏结算 `two_fires`。它只表示用火策略的责任回响，不表示博望坡火攻与赤壁之战是同一作战条件。
- `longzhong` 的来源章节应为**038**，而不是现有 `src/lore.rs` 的037。对应 `Bond` 与彩蛋章节索引也须同步调整；保持原有 `id/flag` 不变以兼容旧存档。

**暂不实装**：刘琦江夏出镇与苏飞获赦各自独立分支；目前没有已验证的跨阵营行动系统，不能将文档当作可玩事件。

## 四、验收条件（12项）

1. 第037回仅两次空访，第038回才完成第三顾、隆中对与出山。
2. `longzhong` 的 `chapter`、相关羁绊、既有彩蛋章号统一为38，旧 `longzhong_plan` 仍有效。
3. 第039回事件只在诸葛亮、第一幕、已有 `longzhong_plan` 时出现。
4. 未选择承责方案不写入 `bowang_fire`。
5. 同一战役事件只触发一次；已见 `bowang` 后不可重复领取奖励。
6. 无 `bowang_fire` 或无 `redcliff_wind` 时不结算 `two_fires`。
7. 同时具备两旗时结算一次；已解锁彩蛋后不重复发奖。
8. 剧情新增卡牌 `huogong` 必须存在于 `card_spec`，奖励能真实进入牌组。
9. 既有 `longzhong_plan`、`redcliff_wind`、`star_lantern` 的旧彩蛋可达性不受破坏。
10. 第038回黄祖与苏飞未结算的状态不能被第039回故事倒写到上一回。
11. 不将第039回结尾的曹操再攻、诸葛亮应对计策当作已发生事件。
12. Rust 单测、完整仓库 Cargo 测试和最新提交的 macOS/Linux CI 均通过后，才把本次代码标记为已验证；真人体验和异本校勘仍独立未验收。
