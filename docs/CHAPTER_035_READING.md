# 《三国演义》第035回单底本因果审读：南漳访贤、新野用兵

## 全回人物行动与因果核查

1. 赵云发现刘备不在襄阳宴席，又听说蔡瑁率军西去，才带原有三百人追出西门；此时他不知道刘备已越檀溪。
2. 赵云当面质问蔡瑁，蔡瑁以宴会守卫为由辩解；赵云因证据不足，没有贸然交战，不代表相信蔡瑁无辜。
3. 赵云在溪边见对岸水迹，推测刘备可能跃溪，但找不到人；又担心城内埋伏，先回新野。推测不得写成确证。
4. 刘备已过檀溪，向南漳行去；他把生还解释为天意，是人物信念，不是可验证的超自然机制。
5. 牧童凭来客描述的体貌特征认出刘备；刘备确认身份后，牧童才引见司马徽。二人并非早已约定相见。
6. 牧童介绍司马徽与庞德公、庞统交游及二人叔侄关系；这为刘备后续荆襄访贤建立社交线索。
7. 刘备在庄前听琴，司马徽由琴声变化猜测有英雄在旁。小说高人识人的描写，不等于客观侦测能力。
8. 刘备初称偶然经过，司马徽指出其逃难处境后，刘备才讲襄阳之事；司马徽的判断在叙事上先于刘备坦白。
9. 司马徽认可关羽、张飞、赵云的勇武，指出的是缺少善用这些武将、统筹局势的谋士；不能写成三将无能。
10. 刘备列举孙乾、糜竺、简雍等文臣，司马徽仍认为不足以经纶济世；问题从“是否有人”转为“是否有人能统筹全局”。
11. 司马徽以荆襄童谣解读刘表家业衰落和刘备未来；童谣是小说人物的预言性解释，不可作为已发生的客观结果。
12. 司马徽提及伏龙、凤雏，称得其一可安天下，却不说具体姓名；刘备获得寻访方向，不等于直接得到两人效忠。
13. 夜间来客“元直”自述见刘表后失望：刘表能辨善恶却不能真正任贤去恶。批评指向执行能力，而非完全不知贤愚。
14. 司马徽对元直说英雄就在眼前；刘备隔室听见，猜测此人可能是伏龙或凤雏。刘备的猜测不等于真实身份已揭晓。
15. 次晨元直已离开，司马徽拒绝告知姓名，也不肯亲自出山；刘备仍未得到军师，后续“单福”登场必须保留信息差。
16. 赵云寻至司马徽庄，提醒新野可能遭袭；刘备随他回程，途中才遇关羽、张飞。赵云先找到刘备，关张随后会合。
17. 回新野后，孙乾建议致书刘表申诉，刘备采纳；刘表获悉蔡瑁谋害之事，直接信息来源是孙乾带来的书信。
18. 刘表怒欲斩蔡瑁，蔡夫人求情；孙乾又以刘备在荆州能否安居劝止。蔡瑁获释并非刘表认定其无罪。
19. 刘表派刘琦随孙乾赴新野致歉；刘琦趁宴诉说继母蔡氏威胁，刘备只劝谨慎尽孝，本回未给出有效避祸方案。
20. 刘琦离别时，刘备再提的卢救命；刘琦归功于刘备福泽。两种解释体现人物信念，不能倒推“妨主”确有超自然效力。
21. 刘备返城听见布衣人高歌求明主，主动邀其入衙；来人自称“单福”，说是故意歌唱以引刘备注意。
22. 单福先说的卢妨主，建议转赠仇敌以转移灾厄；刘备拒绝损人利己。单福随后表明这是试探品德，而非真正建议害人。
23. 单福引用新野民谣佐证刘备善政，刘备才拜其为军师、整顿兵马；招贤来自试探与信任，不只是水镜推荐。
24. 曹操遣曹仁、李典、吕旷、吕翔领三万兵屯樊城，意在威慑荆襄、探查虚实；吕氏兄弟为求立功，主动请五千兵先攻刘备。
25. 单福面对探马报告，提出关羽侧击、张飞截后、刘备与赵云正面迎敌的部署；其作用是协调兵力与路线，而非无条件数值增益。
26. 赵云在正面刺死吕旷；吕翔败逃，先遭关羽截击，再被张飞刺死。两名吕将的死因和执行者不可互换。
27. 新野军追击俘获大量败兵；刘备回城重待单福、犒赏三军。军师初战建立威望，成为后续战事的前提。
28. 李典劝曹仁按兵上报、等待大军，理由是刘备不可轻视；曹仁因报仇和轻敌拒绝，并以“怀二心”施压。
29. 李典原想守樊城，却被曹仁强迫同往；曹仁遂率二万五千军再攻新野。本回停在二次进攻开始，战果留待第036回。

## 跨回可玩责任链（仅设计，未实装）

1. **第034→035回襄阳脱险**：赵云只知溪边水迹，刘备知亲历，蔡瑁公开否认。让玩家在信息不完整时决定先搜救或对质，不允许“全知视角”提前定罪。
2. **刘表继嗣危机**：刘表先欲惩蔡瑁，后因权力平衡赦免；刘琦求助却暂未获有效方案。该悬案可延伸至刘表身后荆州继承，不得本回结清。
3. **访贤与信任**：司马徽指出缺战略统筹但不直接交人；单福以赠马害人试探刘备。建议把拒绝损人作为后续军师信任旗标，而非固定战力加成。
4. **身份信息差**：元直夜访、水镜拒答、单福自报姓名是三次不同信息披露；玩家可推测，但刘备视角不得提前确认。
5. **新野三路伏击**：单福布阵，赵云斩吕旷、关羽截吕翔、张飞斩吕翔分阶段发生；设计为可预告战术，不可一次结算两名敌将自动死亡。
6. **曹仁与李典责任分叉**：李典主张谨慎并非胆怯；曹仁以“怀二心”逼其同行。记录军令服从与风险警告，为第036回后果埋下前提。
