# 第092回《赵子龙力斩五将 诸葛亮智取三城》固定单底本正文核读

固定单底本：[维基文库第092回 oldid=2568054](https://zh.wikisource.org/w/index.php?title=三國演義/第092回&oldid=2568054)，正文 L119–151；2026-10-27按固定修订核读回首至回末。**单底本全文通读，异本及史料全回校勘未完成。**

| 锚点 | 因果、责任、时序、知识边界 |
| --- | --- |
| L119（回首） | 承091赵云邓芝为前锋；诸葛亮祭马超，魏延请精兵走子午谷突袭长安，诸葛亮认为风险过大，选陇右大路。**子午谷方案是提议而非已实施路线**；与裴注郭冲故事和《魏延传》不完全一致。 |
| L120–127 | 夏侯楙派韩德父子为先锋；赵云先杀韩瑛、韩琪、韩琼，擒韩瑶，随后杀韩德，合计五将，不能误称开战第一阵已杀五人。邓芝随军接应。 |
| L128–132 | 程武建议设伏，赵云追敌深入被围，邓芝力不能救；张苞杀薛则、关兴杀董禧来援，赵云得出并再战，夏侯楙退南安。赵云不是独自破全部围军。 |
| L134–137 | 诸葛亮假借夏侯楙心腹裴绪送信，诱安定崔谅出兵，关兴张苞截援、魏延乘虚取安定；崔谅投降并被送去劝南安。 |
| L138–142 | 崔谅与杨陵反设城中伏杀，诸葛亮识破；关兴张苞先入斩二人，王平擒夏侯楙，南安被取。**“智取三城”回题不代表天水已得**。 |
| L143–151（回末） | 天水马遵收到假裴绪军报，姜维指出来使不明、无公文、围城出使可疑，阻止太守出城；姜维只在此回末提出反计，**归蜀发生在093以后，不能提前记为已降**。 |

跨回：091任命赵云邓芝→092魏延提议未获准→赵云破韩德父子及获救→安定、南安得手→天水姜维识破诈信→093继续交锋。正史《诸葛亮传》记建兴六年三郡响应、赵云邓芝在箕谷为疑军、主力攻祁山；**小说具体先后和“三城”结局不可等同史实**。

未校：第二小说底本逐字异文、韩德父子与夏侯楙军事细节的史实、子午谷计具体来源版本、南安天水地理与史传时序。
