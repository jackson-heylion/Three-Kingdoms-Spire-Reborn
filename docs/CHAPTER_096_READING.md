# 第096回《孔明挥泪斩马谡 周鲂断发赚曹休》固定单底本全文核读

固定底本：[维基文库第096回 oldid=2568062](https://zh.wikisource.org/w/index.php?title=三國演義/第096回&oldid=2568062)，正文 L119–143；2026-10-27逐段从回首读至回末。**单底本全文通读；第二小说底本异文、史料全回对校未完成。**

| 正文位置 | 回首至回末的行动、责任与知情边界 |
| --- | --- |
| L119–120（回首） | 承095魏廷拟追蜀，孙资劝曹叡守险，司马懿赞同；诸葛亮在汉中清点退军，赵云、邓芝后卫带回军资，赵云拒绝独领重赏，主张冬季普赐。这不是街亭获胜。 |
| L121–123 | 王平先陈自己曾反复劝马谡当道筑寨、分兵救援的完整军情，诸葛亮再审马谡违令；蒋琬赶到请求留人未获准，小说明确马谡被斩、诸葛亮为不听刘备用人告诫而哭。**处斩在096，不在095。** |
| L126–128 | 诸葛亮为马谡收殓并按月给家属禄米，自上表请求贬三等；刘禅采纳，仍令其行丞相事。诸葛亮拒以姜维归附掩饰失地失军，改整训、减兵与备粮。责任不能只落在马谡身上。 |
| L129–131 | 魏廷料蜀军可能走陈仓，命郝昭筑城；另一边曹休接周鲂诈降七事，贾逵提出警告。此时魏方不知道周鲂真实身份，不能把曹休失败写成事先知情。 |
| L132–134 | 吴廷由孙权、陆逊、朱桓、全琮部署三路；周鲂假欲自刎并断发示忠，曹休采信，斥退贾逵，周鲂秘密通报陆逊。小说断发细节与史料须另分层。 |
| L135–136 | 曹休在石亭发现吴兵才知受骗，魏军伏击计划反被陆逊、朱桓、全琮先发制人破坏；曹休弃辎重退夹石，先前被斥的贾逵断后设疑旗救出。失败责任包括情报误判与拒谏。 |
| L137–143（回末） | 陆逊收降卒与军资，孙权迎赏周鲂；吴方决定以石亭胜报联蜀伐魏，遣使西去。097从曹休败亡、吴使抵蜀接续，不可把此处已发信写成诸葛亮已出师。 |

跨回：095街亭失守与赵云护退→096军法、主帅自贬及石亭诱敌→097吴使促北伐、赵云去世与陈仓受阻→098陈仓粮道和吴蜀外交后果。原创玩法只审计军法与家属、石亭战俘及谍报，不改小说马谡、曹休命运。
