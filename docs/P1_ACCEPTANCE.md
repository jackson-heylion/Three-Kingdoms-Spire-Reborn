## 本轮新增的关键鲁棒性边界

1. 新开战役的成功 `Game::apply(Action)` 记录完整动作；无效动作全回滚、没有日志污染。`Game::verify_action_replay()` 由种子/武将/模式/Run ID 重演，并精确比较JSON快照。不等同完整事件流重建；旧V2存档缺历史仍可读但不能声称已重放验证。
2. 本地终端版所有原子写入更新 `.bak`。主存档不合法但 `.bak` 可读时，损坏文件被改为 `.corrupt`，正常备份恢复为主存档；备份也损坏则拒绝假成功。
3. 玩家在 `tks --tui` 的互动上下键只选择菜单动作；输入 `:` 可进入原命令系统，复杂指定检索仍可以用 `play N TARGET SELECTION`，不复制另一套战斗规则。
4. 复杂资源组合矩阵以真实规则 `Game::apply` 和 `Game::to_json/from_json` 测试，覆盖行动拒绝的原子性、事件严格递增，以及单局升维/回放；它不代表已经测试所有持续军略的可能堆叠。

## 使用与复验

```bash
cargo run --release --bin tks -- --tui
cargo run --release --bin tks -- --plain
# 进入战役后：
# inventory / codex / achievements / history / verify / map
cargo test --all-targets
cargo run --release --bin tks-sim -- 1000
```

查看 GitHub Actions 成功运行的 `tks-cli-macos-14` 或 `tks-cli-ubuntu-latest` 压缩包。本表为如实划定交付边界，不能用表内“部分”或“候选包”替代正式完整单人终端版的承诺。

### 精英阶段机制增量

五类精英（校尉、战象、禁卫、虎将、灵兽）在首次半血时各自获得不同的二阶段能力。二阶段仅触发一次，特殊行动遵循下回合意图预告，友军护阵只作用于存活单位；新增阶段审计事件及固定种子单测，验证阶段存档、一次性转换和特殊意图。此增量**不等于**完成复杂召唤/死亡优先级与全构筑 Boss 反制验收。

### 终端输入/平台增量

TUI 菜单增加 TTY 宽度检测及 Unicode 列宽裁剪；冒号命令补 UTF-8 汉字输入和多列退格。限制挑战中已禁用的营寨选项不再展示为可点击项。新增高对比度主题，Linux 保存目录适配 XDG 并兼顾旧目录迁移。增加终端显示宽度和菜单可选项回归；全面中英文国际化、屏幕阅读器实机和整页动态布局仍未验收。

### P1 召唤顺序和审计事件（2026-10-16）

张角、袁绍、左慈召援新增 `FoeSummoned` 强类型事件和递增序号；新援军**本回合不会立即执行任何行动**，待下个回合向玩家展示意图后再行动。原有敌军仍按原顺序出手。战场上限4名单位，满编情况下不产生伪召唤事件，并明确给出失败提示。Rust 回归覆盖三类Boss、存档恢复、行动顺序与满编。动态外部监听器、跨战斗规则等仍未完成。

### 药剂状态统一结算增量（2026-10-16，待本 PR CI 验证）

毒药与弱化药改用 `apply_foe_status` 统一状态入口，保证 `StatusApplied` 可审计、毒药触发「七擒余毒」一次且不会重复递归、弱化药逐个活目标饱和计算。所有药剂使用均记录 `PotionUsed`，序号先于药效事件。CLI `events` 显示审计记录，TUI 明示目标范围；增加 Rust、BDD、跨平台 CLI 烟测。**这是矩阵中的一条真实优先级边界，不是全部组合审计通过。**
