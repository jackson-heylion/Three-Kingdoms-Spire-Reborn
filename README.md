# 三国登塔录 · Three Kingdoms Spire Reborn

以 Rust 1.99.1 Stable 编写的原创三国题材文字版卡组构筑 Roguelike。参考经典爬塔卡牌游戏的通用玩法框架，采用原创角色机制、卡牌命名、敌人、奇遇与背景，不复制《杀戮尖塔 2》专有的成套卡牌文字、故事或美术。

> **当前状态：增强版单人终端 Alpha。不是《杀戮尖塔 2》全部内容的完成品。**
> 核心机制与内容已扩展，已经提供可下载的macOS/Linux终端版构建和方向键交互菜单，但**尚未完成全部P1，不能作为1.0完整单人终端版发布**。逐项证据与缺口见 [P1验收表](docs/P1_ACCEPTANCE.md)、[功能对照表](docs/FEATURE_MATRIX.md) 和 [路线图](docs/ROADMAP.md)。

## 安装与运行

仅面向 macOS 终端提供正式操作路径（CI 同时检查 Linux）。

```bash
# 如未安装 Rust，请先访问 https://rustup.rs/
git clone https://github.com/jackson-heylion/Three-Kingdoms-Spire-Reborn.git
cd Three-Kingdoms-Spire-Reborn
cargo run --release --bin tks
# 真实终端下使用方向键/jk/数字、回车、t切目标、:输入高级指令
cargo run --release --bin tks -- --tui
# 管道脚本兼容模式
cargo run --release --bin tks -- --plain
```

**新增职业持续能力**：关羽「桃园义阵」攻击触发护甲、诸葛亮「卧龙筹策」每回合第一次非攻击牌回复军令并抽牌、孙尚香「飞羽随形」主动弃换时自动攻击、曹操「屯田补给」补充存活亲兵体力、吕布「饮血方天」在真实损血后增强怒气。事件带单调序号，结算可在终端用 `events` 观察；该记录为最多80项的近期审计，不是全部战局重放日志。

**新增战斗关键词**：`保留`（回合结束仍留在手牌）、`虚无`（若到回合末未打出则消耗）。新增「待命伏兵」「惊鸿一掠」两张示范牌，终端手牌标记 `[保留]` 和 `[虚无]`。战斗统一事件派发增加抽牌、结算、状态施加和敌军阵亡；「察势观星」抽牌格挡、「七擒余毒」施毒强化、「斩将凯歌」斩将回复军令。原有五个能力同样改为订阅相应战斗事件，所有事件写入有序快照。

**新增六统帅招式与协同 AI**：张角「雷咒」伤血后施加虚弱；孙坚「虎袭」两段（第二阶段三段）连击；董卓「暴政」伤害兼掠夺军资；袁绍「盟军列阵」为存活军团提供护甲，第二阶段增强友军；司马懿「暗度陈仓」减少下一回合军令并混入诅咒，对一回合连续打出4张以上牌的策略额外反制；左慈「幻身遁甲」回复体力并布置护甲，对连续5张以上出牌的战术作出回应。军中校尉、谋士及禁卫在有存活友军时会施加协同护阵。全部敌军意图会在回合开始预告，`events` 命令显示 `EnemyTechnique` 结算。半血触发二阶段（一次性）仍然存在，且新增的护甲不会被同一转换流程意外清空。详见 [Boss 行为与应对指南](docs/BOSS_TACTICS.md)。

**P1终端可靠性迭代（2026-10-16）**：新战役成功动作记入 `Game.action_history`，游戏内 `verify` 可从种子回放全部成功操作、比对战斗与剧情快照；旧V2存档继续可读但无法补齐历史。自动保存轮转 `save.bak`，主档损坏时保留 `save.corrupt` 并从备份恢复。三幕地图加入随机分叉、合流、断道、辎重+12金、险地最多-3体力和三层路径风险评分；增加真实终端上下键UI（`--tui`）、13成就、图鉴、全局背包、新X遗物「玄机炉」；17遗物×12赐福×10药剂2040种组合通过状态回归。双平台CI提供 `tks-cli-macos-14` / `tks-cli-ubuntu-latest` 压缩包，**不是1.0发行签名包**。详见 [P1验收表](docs/P1_ACCEPTANCE.md)。

**十条原创职业流派与正常战役奖励（2026-10-16）**：五名武将各提供两条卡牌流派，终端用 `doctrine` 查看，`doctrine <英文代码>` 明确偏向，`doctrine auto` 根据已拥有的至少两种不同职业专属牌自动判断。战后先正常随机生成三张卡，仅当未出现流派契合卡时，以70%概率替换其中**最多一张**为本武将流派未拥有卡牌，其余选择保持随机，不赠送起始牌。仅在地图/营寨可更换，不能利用战斗后换流派重刷奖励；老存档不改变原始种子序列。新增 `--natural-drafting 15` 的495局自然构筑实验，高飞升45局中偏向弃换组的弃换流派成型率45/45，偏向连段组连段流派成型率45/45；这只表示拥有至少两种对应卡牌，不等于成熟卡组或人类胜率。此外，从第40回合开始逐步增加粮尽负担，避免双方无法分出胜负。详见 [流派引导与实测](docs/DOCTRINE_DRAFTING_2026-10.md)。

**资源统计与分流派试验（2026-10-16）**：战役中可使用 `metrics` 查看亲兵**实际扣除敌方血量**的伤害、亲兵替英雄吸收的伤害、统御额外军令和孙尚香弃换/连段触发。保存24回合轻量诊断轨迹，追加到兼容旧 V2 的 JSON 存档。新增孙尚香等张数弃换/连段/标准三种起始牌组的495局固定种子实验，不影响普通开局。根据220局曹操资源统计，将统御触发门槛从3层改为4层，保持+1军令/+5护甲：每完整回合额外军令1.07→0.73，但战术机器人仍220/220胜；详见 [新报告](docs/COMBAT_RESOURCE_FINDINGS_2026-10.md)。

**职业平衡试验（2026-10-16）**：新增按五名武将 × 飞升0–10分层、同种子配对的简单/战术双策略自动模拟，每个分层20种子，总计2200局；报告按职业、难度、战败遭遇输出，并将 JSON 保存至 GitHub Actions artifacts。基于固定样本进行首次定向调整：孙尚香每3次攻击的抽牌被动追加3护甲，合法主动弃换时得2护甲；曹操初始亲兵自动攻击3→2，保持亲兵护卫和升级机制。孙尚香战术策略测试220局胜场180→192；曹操仍220/220，**不能宣称已经平衡，更不是人类玩家胜率**。详见 [平衡试验结果](docs/BALANCE_FINDINGS_2026-10-16.md) 与 [方法](docs/BALANCE_METHODOLOGY.md)。

**新增高级卡牌机制**：X 费用牌消耗当前全部军令，零军令允许发动但无基础 X 效果，迅捷附魔不减少 X；升级提升每点军令的伤害或格挡。诸葛亮「星盘识阵」可以从抽牌堆指定检索攻击牌（不算作抽牌），孙尚香「飞羽映射」可从弃牌堆复制一张可用牌，曹操「募军敕令」生成临时招架，关羽与吕布分别有 X 重击；中立卡另加入 X 格挡与临时突刺生成。临时牌仅存在当前战斗，打出、主动弃换或回合结束均消耗，不会进入永久牌组。原有 `play N TARGET` 仍可用，会自动选牌堆顶最靠前的合格牌；`play N TARGET SELECTION` 则允许明确指定。命令 `piles` 查看抽牌与弃牌堆从顶部开始的编号。

**三国叙事**：参考毛宗岗本120回目录建立章回索引，新增28则有前置条件的原创演义奇遇、25条关系羁绊、8项需完成整条选择链的隐藏结局。场景选择与战斗资源、金钱、体力、后续事件、JSON存档关联。支持 `lore`、`bonds`、`chapter N` 查询文学出处。未完成120回全文逐回审校，详见 [小说资料审定](docs/NOVEL_STUDY.md)。

**可玩内容**：五名武将各自的战斗资源与被动体系、112 张原创卡牌、31 类敌人（包含替代精英和六名关底敌军）、10 种药剂、16 种遗物、12 类分支事件、12 种先贤赐福、三幕 21 层连通三路战役地图、6名关底统帅的二阶段变化、敌人意图、单/群体伤害、护甲、虚弱、易伤、中毒、武勇、反击、亲兵扛伤与自动攻击、弃换触发、牌组抽弃/消耗、特殊任务牌探索变形、升级与附魔、军市和营寨、战功簿与每日挑战、标准难度逐级解锁和自由挑战难度。

每次成功动作保存完整快照，包括手牌、弃牌堆、RNG、职业资源和敌军意图。失败指令会回滚完整状态，不改变随机数或修订号。V1 快照可迁移到 V2。

## 存档

macOS `~/Library/Application Support/ThreeKingdomsSpireReborn/`

- `save.json`：当前游戏与回合状态（跨界面共享协议基础）。
- `chronicle.json`：长期战功、发现记录与难度解锁进度。
- `settings.json`：明暗主题偏好。

```bash
cargo run --bin tks -- --plain
cargo run --bin tks -- --save-dir ./custom-saves
```

**注意**：当前没有多进程写锁，暂时不要同时启动两个终端窗口操作同一存档。原生 App、响应式 HTML 和本机会话协调服务均属二期，尚未实现。

## 选牌与 X 费用的操作示例

持有「星盘识阵」时，先输入 `piles` 查看抽牌堆。假设需要抽牌堆自上而下的第 2 张攻击牌，可执行 `play 1 1 2`（1 表示当前手牌编号，第二个 1 为敌方目标占位，2 为所选牌堆编号）。若选择无效，规则引擎会拒绝操作，并保持能量、手牌、牌堆、RNG 和存档修订号不变。复制类牌同样使用此选择机制，但选择来源为弃牌堆。

X 卡使用 `play 1 1`，不需要额外提供 X 数值，自动投入当前剩余军令。

## 机器平衡抽样

```bash
# 简单机器人回归（1000局）
cargo run --release --bin tks-sim -- 1000
# 五英雄×11飞升×20种子×双机器人：2200局，输出JSON
cargo run --release --bin tks-sim -- --balance 20 ./balance.json
# 孙尚香标准/弃换/连段等规模起始牌组，11飞升×15种子×3构筑
cargo run --release --bin tks-sim -- --sun-archetypes 15 ./sun-archetypes.json
# 自然起始牌，战法偏好/自动形成：另495局
cargo run --release --bin tks-sim -- --natural-drafting 15 ./natural.json
```

策略对照是规则机器人实验，不是对真人胜率的估计。勿单凭一个策略机器人产生的胜率对所有职业做大幅改动。

## 技术边界

- `src/lib.rs`：唯一权威规则状态机与 `Game::apply(Action)`，含操作事务回滚、随机数和存档。
- `src/content.rs` / `src/items.rs`：原创卡牌、敌军、遗物、药剂、战役赐福。
- `src/progression.rs`：长期战功与图鉴。
- `src/main.rs`：Mac 终端呈现与输入。
- `src/bin/tks-sim.rs`：自动对局和确定性回归模拟。

二期统一用同一 Rust 核心驱动 SwiftUI 与 WASM/HTML，协调服务保证单写者与修订号冲突检测。详情见 [架构](docs/ARCHITECTURE.md)。

### 自由挑战、时间线与藏品（P1 增量）

在终端输入 `timeline` 查看解锁路线和挑战藏品，`modifier` 查看已解锁难度。先以 `custom guanyu 42 0` 新开自由挑战，再用 `modifier no_rest on`、`modifier iron_legion on`、`modifier thin_supplies on` 选择可叠加规则；`off` 关闭。必须在进入第一层之前设置。标准战役与每日挑战禁止使用修饰符；自由挑战获胜记录独立藏品但不解锁标准飞升。旧存档在未设置时保持旧机制。每条规则在 `src/challenges.rs` 有明确说明，持续效果由游戏核心执行而非界面模拟。

**精英战二阶段（P1 增量）**：校尉、战象、禁卫、虎将、灵兽半血阶段各有独立强化及后续可预告行动；玩家在下一次敌方行动前可先看到三连虎袭、强化护甲、诡术或援军护阵。阶段转换与近期结算事件可通过 `events` 检查。

### 终端兼容性与辅助操作

TUI 浅色主题将当前敌军目标使用深橙色高亮（保留 ▶ 光标，不再使用低对比亮黄），战斗 HUD 将当前武将核心资源（关羽战意、诸葛谋略、孙尚香连段、曹操统御、吕布怒气）始终显示在敌军列表前，包括数值为0时；其他非零资源仍会显示，窄屏按 Unicode 字符宽度分行。TUI 遇到「驿道奇遇」会显示剧情前提和具体选择；按 `?` 直接打开完整可滚动操作帮助（`:help` 同样可用），按 `i` 可打开只读全文视图，`j/k` 或方向键滚动、`n/p` 翻页、`i`/回车/`q` 返回主界面。长菜单选项、战报和命令反馈都能在全文视图完整阅读，窄屏省略会提示 `i全文`。全文视图不会执行选择或写入存档。TUI 菜单宽度按当前 TTY 列数裁剪，裁剪按 Unicode 显示单元计算（不截断汉字字节）；`:` 高级命令允许直接输入中文附魔名称，退格按字符列宽擦除。终端提供 `theme highcontrast` 高对比主题；在屏幕阅读器或自动化下推荐 `--plain`，不会清屏。Linux 默认使用 `$XDG_DATA_HOME/ThreeKingdomsSpireReborn` 或 `~/.local/share/ThreeKingdomsSpireReborn`，首次升级仍能找到旧版 macOS 风格目录中的现有存档；macOS 继续使用 Application Support。该改进并不构成完整人工无障碍与双语验收。
